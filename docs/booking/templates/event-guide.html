참가 신청

회차 선택 → 인원 → 지정 좌석 → 예약자 정보 → 확인 순서로 진행합니다. 예제에서는 실제 결제나 문자 발송을 하지 않습니다.

입장 안내

시작 10분 전 도착을 가정한 예제입니다. 예약 번호로 내 예약에서 내용을 확인하며 실제 QR 입장 검증 기능은 없습니다.

준비물

노트북과 웹 브라우저를 준비하는 실습형 행사입니다. 실제 자료 배포나 외부 계정 연동은 하지 않습니다.

접근성

좌석 배치도는 키보드 화살표와 Space·Enter로 고를 수 있습니다. 휠체어석은 글자와 아이콘으로 구분합니다.

취소·환불

이용 7일 전까지 100%, 3일 전까지 70%, 1일 전까지 50%, 당일 0% 환불 기준입니다. 최종 환불액은 내 예약의 취소 확인 화면에서 계산합니다.

가상 행사

행사·연사·장소·신청 정보는 모두 시연용입니다. 배경 사진은 실제 행사장이나 연사를 촬영한 사진이 아닙니다.
