    날짜는 모두 한국 시간으로 셉니다 — 브라우저 시간대가 달라도 “오늘”·“지난 시간”·“며칠 전”이 같습니다. 테마는 다른 확장과 같은 규칙(저장값이 없으면 시스템)이고, <html data-catui-theme-lock>이 있으면 건드리지 않습니다(이 문서 사이트가 그렇습니다).

    템플릿 · 메뉴

    • templates/booking/pages/이름.html — 머리 주석 <!-- title: 내 예약 | nav: mine | layout: blank -->. nav는 머리 메뉴의 현재 위치입니다.
    • templates/booking/menu.json — top(머리 메뉴 — 본체 .Catui_hnav-item, 글자만) · foot(바닥글 링크). 없는 화면은 메뉴에서 빠집니다.
    • npm run build → docs/booking/templates/. 검사: 정의 안 된 클래스·없는 아이콘·id 중복·label·화면 링크·h1·안 쓰인 클래스·역할 없는 span의 aria-label·키보드 격자가 아닌 곳의 role="grid"·JSON 문법, CSS의 hex·없는 토큰·본체 클래스 재정의.

    JSON 모의 데이터

    templates/booking/data/*.json → docs/booking/templates/data/. 실서비스는 같은 모양의 API를 만들고 catui.booking.dataBase = '/api/booking/'만 바꿉니다. 금액·남은 자리·순번은 저장하지 않고 원자료에서 계산합니다.

    데이터 파일
    파일내용 · 계산
    services.json서비스 6개 — kind(slot 시간·seat 좌석·room 숙박), 가격·어린이 가격(또는 할인), 이용 시간·간격·정원·최대 인원, 회차(times), 배치도(map), 옵션(per: person·person-night·once)
    branches.json지점 영업시간(open·close)·휴게시간(breaks)·휴무 요일(closed, 0=일)
    slots.json예약 현황 — people(시간마다 찬 인원) · seats(회차마다 예약된 좌석) · rooms(객실 기간). 남은 자리 = 정원 − 합
    seats.json배치도 — 줄마다 cells 글자(s 좌석 · w 장애인석 · t 테이블 · _ 통로), 등급(grades)·테이블 인원(cap)
    rooms.json객실(기준·최대 인원, 1박 요금, 추가 인원 요금, 객실 수) · 공휴일(holidays — 그 전날 밤이 주말 요금)
    reservations.json내 예약 — 금액은 저장하지 않고 서비스·좌석·객실 원자료로 계산, 상태(예정·지난·취소)는 “지금”으로 판단
    staff.json · schedule.json직원 · 관리자 일정 블록(직원·날짜·시작·끝·상태) — 겹침은 booking.layout이 계산
    waitlist.json대기 신청 — 순번은 회차마다 신청 시각 순으로 계산

    기억하는 상태

    catui.data('booking')(localStorage "catui:booking") 한 곳에 theme, 진행 중 예약 draft(단계 사이), 이 브라우저에서 저장·변경한 예약 saved, 취소 기록 cancelled, 대기 신청 wait·상태 waitState, 일련번호 seq를 둡니다. 저장한 예약은 남은 자리 계산에도 들어갑니다.
