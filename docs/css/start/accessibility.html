접근성 기준

대비·포커스·목표 크기·모션 기준과 실측값.

대비

본문 4.5:1, 큰 글자·UI 3:1(WCAG AA)을 지킵니다. 밝은 color-brand·info·orange·danger는 배경·장식·차트 전용이고, 밝은 배경 위 텍스트·포커스에는 AA 보정색 --Catui_color-brand-strong(#0E7A63)을 씁니다.

대비 실측
조합대비
text-primary / 흰색10.98
흰 글자 / brand-strong (primary 버튼)5.27
badge success · info · warn · danger4.76 ~ 5.05
text-secondary / 흰색4.6 ~ 4.9
text-tertiary / 흰색 — placeholder·비활성 전용2.50

지켜야 할 것

  • 색만으로 의미를 전하지 않습니다 — 상태 pill은 점 + 글자, 오류는 색 + 문장.
  • 모든 상호작용 요소에 :focus-visible 링(2px, offset 2)이 보입니다.
  • 컨트롤 최소 높이 28px (WCAG 2.2 목표 크기 24px 충족).
  • prefers-reduced-motion에서 전환·애니메이션을 끕니다.
  • 아이콘 svg에는 aria-hidden="true", 아이콘만 있는 버튼에는 aria-label.
  • 숨긴 input은 display:none이 아니라 .Catui_clip으로 — 키보드로 닿아야 합니다.
  • 페이지당 h1은 하나, 현재 메뉴는 aria-current="page".

상호작용 기본값

  • 눌림: 버튼은 1px 내려앉고, 페이지 번호·메뉴 항목·목록 링크·필 탭·리액션은 배경이 한 단계 진해집니다.
  • 전환: 호버 색·배경·테두리·그림자 변화는 120ms로 부드럽게 바뀌고, 모션 줄이기 설정에서는 꺼집니다.
  • 누르는 영역: 캐러셀 점처럼 작게 보이는 대상도 실제로 누르는 영역은 28px 이상입니다.
  • 고대비 모드(Windows 등 forced-colors): 배경색으로만 그린 체크박스·토글·칩·선택 카드·배지·진행 막대에 테두리와 시스템 강조색을 써서 상태가 보이게 합니다.

규칙은 src/css/foundation/interaction.css 한 곳에 모여 있어, 새 컴포넌트를 만들면 여기 목록에 선택자를 더합니다.
