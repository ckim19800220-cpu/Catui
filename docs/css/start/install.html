설치와 빌드

배포 파일 연결, 스코프 루트, 소스에서 빌드하기.

배포 파일

배포 파일
파일용도
dist/catui.min.css압축 스타일 (페이지에는 이 파일을 링크)
dist/catui.css읽기 쉬운 원본 결합본
dist/icons.svgLucide 아이콘 스프라이트 239개 (목록은 아이콘)

페이지에 연결

<link rel="stylesheet" href="dist/catui.min.css">

<!-- 관리 화면 -->
<div class="Catui_app"> … </div>

<!-- 공개 홈 -->
<div class="Catui_site"> … </div>

<!-- 아이콘 -->
<svg class="Catui_icon Catui_i16" aria-hidden="true"><use href="dist/icons.svg?v=2#Catui_ic-search"></use></svg>

리셋과 글꼴은 .Catui_app·.Catui_site 안에서만 적용됩니다. 외부 스프라이트는 file://에서 막히므로 정적 서버(npm run dev)로 여세요.

소스에서 빌드

npm install
npm run build        # CSS·아이콘·JS·문서 전부
npm run build:css    # CSS와 아이콘만
npm run dev          # http://127.0.0.1:8766/docs/

CSS 소스는 src/css/에 컴포넌트마다 한 파일이고, 결합 순서는 src/css/index.json입니다. 새 파일을 만들면 이 목록에 넣어야 빌드가 통과합니다.
