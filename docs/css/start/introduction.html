    소개

    Catui CSS의 특징과 문서 구성.

    Catui CSS란

    Catui는 한국어 관리 화면과 공개 홈을 위한 CSS 키트입니다. 견본 명세(assets/spec/design_m.html)의 토큰 618개를 --Catui_* 변수로 옮겼고, 모든 컴포넌트가 이 토큰만 사용합니다.

    • CSS만으로 동작 — 모달·탭·드롭다운·트리도 체크박스·radio·details로 동작합니다. 스크립트는 선택 사항(catui.js)입니다.
    • 충돌 없는 이름 — 클래스·변수·아이콘 id가 전부 Catui_로 시작해 기존 사이트 CSS와 섞이지 않습니다.
    • 접근성 기준 — 텍스트 대비는 WCAG AA를 충족하고, 포커스 링과 최소 높이 28px 컨트롤을 제공하며, 모션 줄이기 설정을 따릅니다.
    • 미니멀 시각 원칙 — 1px 반투명 잉크 테두리, 작은 모서리(2~10px), 떠 있는 층에만 쓰는 얕은 그림자와 유리 효과. 라이트·다크 모두 같은 대비로 선명합니다(시각 원칙).

    바로 써 보기

    위 마크업은 dist/catui.min.css를 링크하고 루트에 .Catui_app 또는 .Catui_site를 두면 그대로 보입니다. 자세한 설정은 설치를 보세요.

    문서 구성

    기초색상·타이포·간격·아이콘·유틸리티 토큰 레이아웃12열 그리드, 관리 셸, 공개 홈 컴포넌트버튼부터 명령 팔레트까지 44쪽 고급 입력업로드·범위·별점·태그·날짜 등 12쪽 데이터 뷰트리·달력·간트·칸반 등 9쪽 차트라인·도넛·막대·게이지·레이더·본문
