    CSS시작이름과 스코프

    이름과 스코프

    Catui_ 접두사, 스코프 루트, 토큰 3층 규칙.

    소스src/css/foundation/reset.css

    접두사

    공개 클래스·CSS 변수·아이콘 심볼 id는 모두 Catui_로 시작합니다. 호스트 페이지의 .btn이나 --color-brand와 겹치지 않습니다.

    이름 규칙
    종류형식예
    클래스Catui_컴포넌트-부분-변형Catui_btn-primary
    CSS 변수--Catui_분류-이름--Catui_color-brand-strong
    아이콘 idCatui_ic-이름Catui_ic-search

    스코프 루트

    • .Catui_app — 관리 화면 (사이드바·탑바 셸)
    • .Catui_site — 공개 홈
    • .Catui_layer — catui.js가 body에 붙이는 오버레이 루트 (레이어·드롭다운·토스트)

    리셋·타이포는 이 세 루트 안에서만 적용되고, 루트 밖 DOM에는 영향을 주지 않습니다. body나 * 선택자로 전역 스타일을 넣지 마세요.

    루트 안과 밖 비교

    이 문서 자체가 이미 .Catui_site 안에서 그려지므로 "루트 밖" 모습은 미리보기로 보일 수 없습니다. 같은 마크업을 루트 안·밖에 두었을 때의 차이를 코드로 설명합니다.

    <!-- ① 루트 밖: 호스트 페이지 그대로 -->
<p>안내 문단</p>                    <!-- 브라우저 기본 위아래 여백(1em), 호스트 글꼴 -->
<button class="Catui_btn Catui_btn-md Catui_btn-primary" type="button">저장</button>
                                    <!-- 버튼 모양은 나오지만 box-sizing·글꼴 상속 리셋이 없어
                                         호스트 CSS에 따라 크기·글꼴이 달라질 수 있음 -->

<!-- ② 루트 안: Catui 리셋·타이포 적용 -->
<div class="Catui_site">             <!-- 관리 화면이면 .Catui_app -->
  <p>안내 문단</p>                  <!-- 여백 0, --Catui_font-ui · 13px · 줄 높이 1.55 · keep-all -->
  <button class="Catui_btn Catui_btn-md Catui_btn-primary" type="button">저장</button>
                                    <!-- border-box, 글꼴 상속 — 견본과 같은 크기 -->
</div>
    루트 안과 밖의 차이
    항목루트 밖루트 안 (.Catui_app · .Catui_site · .Catui_layer)
    글꼴 · 크기 · 줄 높이호스트 페이지 값--Catui_font-ui, 본문 토큰
    p · h1~h4 · ul 여백브라우저 기본 여백0, 목록 기호 없음 (간격은 레이아웃 클래스가 정함)
    링크 a파란 밑줄글자색 상속, 밑줄 없음
    button · input브라우저 기본 글꼴글꼴·색 상속, button은 바탕·테두리·안쪽 여백도 0
    box-sizing호스트 설정border-box

    그래서 Catui 클래스는 반드시 루트 안에서 씁니다. 기존 페이지 일부에만 넣을 때는 그 부분을 <div class="Catui_site">로 감싸면 바깥은 그대로 두고 안쪽만 견본대로 보입니다(.Catui_app·.Catui_site는 min-height:100vh와 페이지 바탕을 가지므로 작은 조각이면 높이를 따로 정하세요). 레이어·토스트는 catui.js가 body 끝에 .Catui_layer를 만들어 같은 리셋을 받습니다.

    토큰 3층

    • L1 팔레트·타이포·간격·반경·그림자 원본 값
    • L2 파생 값 (brand-ghost, focus-ring 등)
    • L3 컴포넌트 토큰 (--Catui_btn-h-md 등) — L1·L2를 var()로만 참조

    새 값이 필요하면 견본 명세에 토큰을 먼저 추가하고 src/css/foundation/tokens.css에 옮긴 뒤 컴포넌트에서 참조합니다. 컴포넌트 CSS에 hex 값을 직접 쓰지 않습니다.
