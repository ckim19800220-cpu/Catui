    라인 차트

    SVG 영역·선·보조선·축과 범례.

    소스src/css/charts/line.csssrc/css/charts/legend.css

    • MUST 선 1.5, 색은 series 토큰만
    • SHOULD 면적은 brand 12%, grid는 divider
    • NEVER 한 차트에 5색 초과 시리즈 금지

    예제

    범례 단독

    범례만 따로 써도 됩니다. 세로 .Catui_legend는 b 값이 오른쪽 끝으로 붙어 숫자 열이 맞고, .Catui_legend-row는 이름 바로 뒤에 값이 붙어 한 줄로 흐릅니다. 색 견본은 .Catui_s1~5, 이름과 값을 글자로 함께 써서 색만으로 구분하지 않습니다.

    사용법

    .Catui_chart SVG(grid/area/series/axis), 범례 .Catui_legend, 도넛 .Catui_donut.

    접근성

    • SVG에 role="img"와 추이를 설명하는 aria-label.
    • 시리즈는 색과 선 모양(실선·점선)으로 구분하고 범례를 둡니다.

    클래스

    소스 CSS에서 자동으로 모은 목록입니다.

    • src/css/charts/line.css.Catui_chart
    • src/css/charts/legend.css.Catui_legend .Catui_legend-row .Catui_s1 .Catui_s2 .Catui_s3 .Catui_s4 .Catui_s5
