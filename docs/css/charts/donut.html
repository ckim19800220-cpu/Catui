  • SHOULD seg-1 → seg-5 순서, 중앙엔 총합만
  • NEVER 세그먼트 사이 간격·외곽선 금지

예제

사용법

.Catui_donut(지름 132) 안에 .Catui_donut-hole(구멍 78)에 총합과 .Catui_donut-label을 둡니다. 조각 비율은 기본 45·25·12·10·8%이며, 다르면 background의 conic-gradient만 덮어씁니다(색은 --Catui_donut-seg-1~5). 범례 .Catui_legend는 도넛 옆에 두고 퍼센트를 글자로 함께 씁니다.

접근성

  • role="img" + 항목별 비율을 담은 라벨, 범례에 퍼센트 글자.
  • 중앙에는 총합만.
