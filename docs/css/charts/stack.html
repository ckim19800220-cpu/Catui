누적·세그먼트

비율 누적 막대와 점 단위 세그먼트.

예제

사용법

.Catui_stack에 <i> 조각을 최대 5개까지. 점 단위 세그먼트는 .Catui_segbar + i.Catui_seg-on.

접근성

  • role="img" + 항목별 비율 라벨, 범례를 함께.
  • 5개를 넘는 항목은 '기타'로 묶습니다.

클래스

소스 CSS에서 자동으로 모은 목록입니다.

  • src/css/charts/stack.css.Catui_stack .Catui_segbar .Catui_seg-on
