미디어 객체·임베드

그림 + 본문 가로 배치, 16:9 영상·지도 임베드.

미디어 객체

임베드 (영상·지도)

사용법

.Catui_media = media-fig(그림) + media-body(media-title·media-text) + 선택 media-side. 본문이 길어도 그림 폭은 줄지 않습니다. 임베드는 .Catui_embed(16:9, -4x3) 안에 iframe·video를 넣습니다.

접근성

  • iframe에는 내용을 알 수 있는 title을 줍니다.
  • 제목이 옆에 있으면 그림은 장식(alt="")으로 둡니다.
