    CSS컴포넌트카드

    카드

    머리·본문·꼬리로 된 면. 링크 카드는 호버 그림자가 붙습니다.

    소스src/css/components/card.css

    • MUST 헤더 52px · 푸터 44px 고정
    • SHOULD 패딩 20 · 반경 8 · shadow-xs 기본
    • NEVER 카드 안에 md 이상 그림자를 중첩하지 않는다

    머리 · 본문 · 꼬리

    링크 카드 · 그리드

    이미지 카드 · 가로 카드

    사용법

    .Catui_card 안에 .Catui_card-h(52px)·.Catui_card-b(패딩 20)·.Catui_card-f(44px). 머리 오른쪽 도구는 .Catui_card-tools. a.Catui_card는 호버 시 그림자가 붙습니다.

    접근성

    • 카드 전체가 링크면 안에 다른 링크·버튼을 넣지 않습니다.
    • 카드 안에 md 이상 그림자를 겹치지 않습니다(위계가 흐려짐).

    클래스

    소스 CSS에서 자동으로 모은 목록입니다.
