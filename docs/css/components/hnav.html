    CSS컴포넌트가로 내비게이션

    가로 내비게이션

    화면 위 가로 메뉴 바: 알약형·밑줄형·어두운 바, 아이콘·카운트·드롭다운·오른쪽 영역, 가로 스크롤.

    소스src/css/components/hnav.css

    기본 (알약형)

    하위 메뉴 (드롭다운)

    하위 메뉴는 드롭다운의 details.Catui_dd를 그대로 넣고, 메뉴 칸 모양은 summary.Catui_hnav-item으로 맞춥니다. 열리면 화살표가 뒤집힙니다. 여러 열이 필요하면 메가 메뉴를 씁니다.

    밑줄형

    어두운 바

    가로 스크롤

    한 줄을 유지하고 넘치는 항목은 가로로 밀어서 봅니다. 스크롤 상자가 바깥을 자르므로 드롭다운은 넣지 마세요(기본형은 넘치면 다음 줄로 내려갑니다).

    사용법

    nav.Catui_hnav 안에 a를 나열하고 현재 항목에 aria-current="page"를 줍니다. 버튼·드롭다운 칸은 .Catui_hnav-item, 오른쪽으로 미는 영역은 .Catui_hnav-end. 변형: .Catui_hnav-line(밑줄형), .Catui_hnav-dark(어두운 바), .Catui_hnav-scroll(한 줄 가로 스크롤). 화면 안 보조 탭은 보조 탐색, 세로 메뉴는 세로 내비게이션, 공개 홈 머리 메뉴는 공개 홈의 .Catui_site-nav를 씁니다.

    접근성

    • nav + aria-label로 이름을 붙이고, 한 화면에 메뉴가 여럿이면 이름을 서로 다르게 합니다.
    • 현재 위치는 색·배경(밑줄형은 밑줄)과 aria-current="page"를 함께 씁니다.
    • 카운트는 숨김 글자로 무엇의 개수인지 보충합니다. 아이콘만 있는 버튼에는 aria-label.
    • 포커스 링은 항목 안쪽에 그려 가로 스크롤형에서도 잘리지 않습니다.
