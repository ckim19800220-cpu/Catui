    사용법

    표 위에는 .Catui_toolbar(검색·필터 왼쪽, .Catui_toolbar-end 오른쪽), 행을 선택하면 그 자리에 .Catui_bulkbar를 보입니다. 긴 설정 폼은 끝에 .Catui_actionbar를 두면 스크롤해도 아래에 붙습니다.

    접근성

    • 도구 모음은 role="toolbar" + 이름. 선택 개수는 바뀔 때 aria-live로 읽힙니다.
    • 저장 바가 마지막 입력을 가리지 않도록 폼 끝에 둡니다.
