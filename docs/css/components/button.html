    CSS컴포넌트버튼

    버튼

    주요·보조·고스트·위험 4가지 변형과 sm 28 / md 34 / lg 40 세 높이.

    소스src/css/components/button.css

    • MUST 높이는 sm/md/lg 3단만
    • SHOULD 한 화면에 primary는 1개
    • NEVER 비활성을 opacity로 대체하지 않는다

    변형

    한 화면에 primary는 하나만 둡니다. 나머지 동작은 secondary·ghost, 되돌릴 수 없는 동작은 danger입니다.

    크기

    아이콘과 상태

    아이콘 버튼 · 전폭 · 버튼 그룹

    .Catui_btn-icon은 크기 클래스와 함께 쓰면 높이와 같은 폭의 정사각이 됩니다(아이콘만 있으면 aria-label 필수). .Catui_btngroup은 맞닿은 모서리를 지우고, 선택 상태는 aria-pressed="true"로 표시합니다.

    사용법

    .Catui_btn에 변형 Catui_btn-primary/secondary/ghost/danger와 크기 Catui_btn-sm/md/lg를 겹칩니다. 페이지 이동은 <a>, 동작은 <button type="button">을 씁니다.

    접근성

    • 아이콘만 있는 버튼에는 aria-label, 아이콘 svg에는 aria-hidden="true".
    • 비활성은 disabled(또는 aria-disabled="true")로 표시하고, 왜 쓸 수 없는지 문장으로 연결합니다. 투명도로 흉내 내지 않습니다.
    • 흰 글자 / primary 대비 5.27:1, danger 5.44:1 (AA 통과).

    클래스

    소스 CSS에서 자동으로 모은 목록입니다.

    • src/css/components/button.css.Catui_btn .Catui_btn-sm .Catui_btn-md .Catui_btn-lg .Catui_btn-primary .Catui_btn-secondary .Catui_btn-ghost .Catui_btn-danger .Catui_btn-icon .Catui_btn-block .Catui_btngroup
