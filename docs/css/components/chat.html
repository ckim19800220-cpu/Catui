채팅

상대·나 말풍선, 날짜 구분, 입력 줄.

대화

사용법

.Catui_chat 안에 .Catui_chat-msg(말풍선 -bubble + 시간 -time), 내 메시지는 .Catui_chat-me(오른쪽·브랜드 색), 날짜 구분 -day, 아래 입력 줄 -input. 긴 공개 토론은 스레드가 맞습니다.

접근성

  • 대화 영역은 role="log"라 새 메시지가 차례로 읽힙니다.
  • 말한 사람은 숨김 글자로 앞에 붙이고, 시간은 time datetime. 내 말풍선 흰 글자 대비 5.27:1.
