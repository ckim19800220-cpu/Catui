사용법

.Catui_list 안에 .Catui_list-item(40px 이상), 오른쪽 값은 .Catui_list-meta. 행 전체가 링크·버튼이면 a/button.Catui_list-item, 현재 항목은 aria-current. 테두리 없이 쓰려면 .Catui_list-flush. 키-값은 dl.Catui_dl, 기능 목록은 ul.Catui_checklist.

접근성

  • 목록은 ul/ol/nav로 만들어 항목 수가 읽히게 하고, 묶음에 aria-label.
  • 링크 행에는 키보드 포커스 링이 안쪽에 그려집니다.
