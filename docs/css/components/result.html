소스src/css/components/result.css

결과 상태

사용법

.Catui_result = 아이콘 원 -icon(또는 큰 숫자 -code) + -title + -text + 버튼. 색은 -success·-danger·-warning. 목록이 비었을 때는 빈 상태가 맞습니다.

접근성

  • 완료는 role="status", 실패는 role="alert"로 바로 알립니다.
  • 다음 행동(버튼)을 항상 하나 이상 둡니다. 404 숫자는 장식이라 숨기고 제목에 뜻을 씁니다.
