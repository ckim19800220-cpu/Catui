사용법

이 클래스들은 catui.js layer가 붙입니다. 마크업만으로 쓰는 모달·드로어는 모달·드로어를 보세요. 큰 창은 area: 'xl', 화면 전체는 'full', 최대화는 maxmin: true, 옮기기 move, 크기 조절 resize, 토스트 위치는 position: 'tr'|'tc'|'bc'|'br'입니다.

접근성

  • 대화상자는 네이티브 <dialog>라 포커스 가두기·Esc·포커스 복귀가 기본입니다. 최대화 버튼은 aria-pressed와 이름("최대화"/"원래 크기")이 바뀝니다.
  • 말풍선은 role="tooltip"이며 대상의 aria-describedby에 잠시 연결됩니다. 사진 보기는 ←→·Home·End, 탭은 ←→로 이동합니다. 끌어 옮기기는 꾸밈이며 키보드 사용에는 필요 없습니다.
  • 동작 버튼이 있는 토스트는 5초 동안 보이고, 마우스·키보드 포커스가 들어오면 멈춥니다.
