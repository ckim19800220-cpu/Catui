    소스src/css/components/dropdown.css

    • MUST 항목 높이 32px
    • SHOULD danger 항목은 구분선으로 분리해 맨 아래

    기본 메뉴

    그룹 · 비활성 · 너비

    떠 있는 메뉴 (dd-float)

    .Catui_dd-float는 dropdown.render()·datePicker가 body > .Catui_layer에 붙이는 화면 고정(position:fixed, z-index 60) 메뉴입니다. 위치는 스크립트가 버튼 아래(공간이 없으면 위)에 메뉴가 놓이도록 계산합니다. 예제는 모양만 보이려고 position:static으로 두었습니다.

    선택형 메뉴 (listbox)

    값을 하나 고르는 목록은 부모에 role="listbox", 항목에 role="option"을 줍니다. 고른 항목 aria-selected="true"는 바탕색과 왼쪽 강조선, 못 고르는 항목 aria-disabled="true"는 옅은 글자로 보입니다. 이 모양은 자동완성처럼 포커스가 입력 칸에 남는 목록을 위한 것이라, ↑↓ 이동·선택은 catui.js autocomplete·dropdown이 붙입니다. 명령을 실행하는 메뉴는 위의 버튼(role="menuitem")을 씁니다.

    작은 메뉴 (dd-sm)

    .Catui_dd-sm은 메뉴 최소 너비를 --Catui_dropdown-w-sm으로 줄입니다. 너비 클래스가 없으면 메뉴는 여는 버튼(details)과 같은 너비가 되므로, 아이콘 버튼처럼 좁은 버튼에는 dd-sm이나 dd-lg를 붙여 너비를 정합니다.

    사용법

    details.Catui_dd > summary(버튼) + .Catui_dd-menu > .Catui_dd-item. 구분선 .Catui_dd-sep, 그룹 라벨 .Catui_dd-group, 너비 .Catui_dd-sm/lg. 메뉴는 흐름 안에 있으므로 겹쳐 띄우려면 감싼 요소에 위치를 주거나 catui.js dropdown을 씁니다.

    접근성

    • summary 안에 버튼·링크를 넣지 않습니다. 아이콘만 있는 summary에는 aria-label을 줍니다.
    • catui.js가 있으면 바깥 클릭·Esc로 닫히고 summary로 포커스가 돌아갑니다. 키보드 메뉴(↑↓)가 필요하면 dropdown.render.
    • 위험 항목은 구분선 아래 맨 끝, 비활성 항목은 disabled와 이유를 글자로.
