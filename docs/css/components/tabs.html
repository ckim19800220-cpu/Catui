    탭·세그먼트

    native radio로 전환하는 탭과 세그먼트. 스크립트 없이 동작합니다.

    소스src/css/components/tabs.csssrc/css/components/segment.css

    • MUST 활성 탭은 색 + 2px indicator 쌍
    • SHOULD 전환은 native radio
    • NEVER 색 변화만으로 활성을 나타내지 않는다

    탭

    세그먼트

    세로 탭

    아이콘 · 숫자 · 새 소식

    균등 분할 탭

    가로 스크롤 탭 줄

    카드형 탭

    알약형(둥근 배경) 탭은 하위 내비게이션의 .Catui_pills을, 값만 고르는 버튼 묶음은 위의 세그먼트를 씁니다.

    사용법

    탭은 input[type=radio].Catui_clip → label.Catui_tab → .Catui_panel 순서를 반복합니다. 같은 name끼리 묶이고 :checked 형제 셀렉터로 패널을 보입니다. 세그먼트는 패널 없이 값만 고를 때 씁니다. 이벤트·추가·삭제는 catui.js tabs.

    • .Catui_tab 안에 아이콘(Catui_i16)·.Catui_count·.Catui_dot을 글자와 함께 넣을 수 있습니다(간격 자동).
    • .Catui_tabs-full — 탭들이 줄 폭을 똑같이 나눠 가운데 정렬합니다. 탭 2~4개, 짧은 글자에 씁니다.
    • .Catui_tabs-scroll — 탭 줄을 한 줄로 두고 넘치면 가로로 스크롤합니다. radio 구조에서는 탭만 따로 스크롤할 수 없으므로 패널 없는 링크형 탭 줄(<nav> 안 a.Catui_tab, 현재 쪽은 aria-current="page") 또는 catui.js가 그리는 [role=tablist] 줄에만 씁니다. 탭 모양을 그대로 쓰는 링크 줄이며, 쪽 이동 전용 밑줄 메뉴는 .Catui_subnav도 있습니다.
    • .Catui_tabs-card — 탭을 테두리 상자로 그리고 선택한 탭을 패널 상자와 이어 붙입니다. radio 구조 그대로 씁니다.

    접근성

    • radio 그룹이라 Tab으로 들어가 화살표 키로 이동합니다(스크립트 불필요).
    • 활성 탭은 색과 2px 밑줄을 함께 표시합니다 — 색만으로 구분하지 않습니다.
    • 세그먼트 묶음에 role="radiogroup" + aria-label.
    • 탭 안 숫자는 .Catui_clip 숨김 글자로 "무엇이 몇 개"인지, 새 소식 점은 "새 소식 있음"을 함께 적습니다 — 점 색만으로 알리지 않습니다.
    • 링크형 탭 줄(.Catui_tabs-scroll)은 <nav aria-label>로 감싸고 현재 쪽에 aria-current="page"를 줍니다. 스크롤 영역이 바깥을 잘라 내므로 포커스 외곽선은 탭 안쪽에 그립니다.
    • 카드형 탭(.Catui_tabs-card)도 활성 탭을 테두리·면 색·글자 색 세 가지로 구분합니다.
