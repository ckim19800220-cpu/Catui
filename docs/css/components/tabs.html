탭·세그먼트

native radio로 전환하는 탭과 세그먼트. 스크립트 없이 동작합니다.

  • MUST 활성 탭은 색 + 2px indicator 쌍
  • SHOULD 전환은 native radio
  • NEVER 색 변화만으로 활성을 나타내지 않는다

탭

세그먼트

세로 탭

사용법

탭은 input[type=radio].Catui_clip → label.Catui_tab → .Catui_panel 순서를 반복합니다. 같은 name끼리 묶이고 :checked 형제 셀렉터로 패널을 보입니다. 세그먼트는 패널 없이 값만 고를 때 씁니다. 이벤트·추가·삭제는 catui.js tabs.

접근성

  • radio 그룹이라 Tab으로 들어가 화살표 키로 이동합니다(스크립트 불필요).
  • 활성 탭은 색과 2px 밑줄을 함께 표시합니다 — 색만으로 구분하지 않습니다.
  • 세그먼트 묶음에 role="radiogroup" + aria-label.
