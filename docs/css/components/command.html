명령 팔레트

그룹별 명령 목록과 키 힌트.

  • MUST 행 높이 36px, 그룹 라벨 10px uppercase
  • SHOULD kbd 힌트 우측, 하단 힌트 고정
  • NEVER 선택 행을 2개 이상 동시에 표시하지 않는다

명령 팔레트

키 표시

사용법

.Catui_cmdk(폭 560) 안에 검색 줄 .Catui_cmdk-search, 그룹 details.Catui_cmdk-grp, 행 .Catui_cmdk-row(36px), 선택 행 .Catui_cmdk-row-on(하나만), 하단 힌트 .Catui_cmdk-hint. 키는 .Catui_kbd. 열기·필터·키보드 이동은 스크립트로 붙입니다(예: layer.open 안에 넣기).

접근성

  • 검색 입력과 목록을 aria-controls·aria-activedescendant로 잇고, 선택 행은 하나만.
  • 하단 힌트 줄에 키 사용법을 항상 보입니다.
