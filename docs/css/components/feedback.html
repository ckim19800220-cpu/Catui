접근성

  • 배너는 아이콘 + 문장으로 알립니다. 즉시 알려야 하는 실패만 role="alert".
  • 빈 상태에는 이유와 다음 행동(버튼)을 함께 둡니다.
  • 스켈레톤 영역에 aria-busy="true". 반짝임은 모션 줄이기 설정에서 멈춥니다.
