체크·라디오·토글

실제 input은 .Catui_clip으로 숨기고 .Catui_cbx·.Catui_radio·.Catui_tgl이 그립니다.

  • MUST 체크·라디오 16px, 토글 34×20
  • SHOULD 라벨과 같은 행, 간격 8px
  • NEVER on 색을 L1에서 직참조하지 않는다

체크박스 · 라디오

토글

사용법

실제 input은 .Catui_clip으로 숨기고 바로 뒤의 .Catui_cbx·.Catui_radio·.Catui_tgl이 상태를 그립니다. 묶음은 fieldset.Catui_choices + legend.

접근성

  • input을 display:none으로 숨기지 않습니다 — 키보드·스크린리더가 닿아야 합니다.
  • 토글은 role="switch"로 켬/끔이 읽히게 합니다.
  • 체크·라디오 16px, 토글 34×20, 라벨 전체가 누르는 영역입니다.
