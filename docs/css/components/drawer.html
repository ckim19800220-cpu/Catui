드로어

오른쪽에서 여는 320px 패널.

  • MUST 폭 320, 우측 고정, 반경 0
  • SHOULD 전이는 transform만
  • NEVER 스크림을 중첩하지 않는다

사용법

모달과 같은 체크박스 구조에서 .Catui_drawer-toggle + aside.Catui_drawer를 씁니다. 폭 320px, 오른쪽 고정, 반경 0. 스크립트로 열려면 layer.open({ type: 'drawer' }).

접근성

  • CSS만으로는 Esc·포커스 가두기가 안 됩니다. catui.js가 같은 마크업에 붙이고, layer.open({ type: 'drawer' })는 dialog로 기본 제공합니다.
  • role="dialog" + aria-modal + 제목 연결, 닫기 버튼 생략 금지. 스크림을 겹치지 않습니다.

클래스

소스 CSS에서 자동으로 모은 목록입니다.
