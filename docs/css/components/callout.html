    CSS컴포넌트안내 상자

    안내 상자

    본문 속 참고·팁·주의·위험 상자.

    소스src/css/components/callout.css

    4종

    사용법

    .Catui_callout = 아이콘 + .Catui_callout-title + 내용. 색은 기본(참고)·-tip·-warn·-danger. 화면 위쪽에 잠깐 알리는 상태 메시지는 배너, 사라지는 알림은 토스트를 씁니다.

    접근성

    • 본문 속 보조 정보이므로 role="note". 종류는 색과 함께 제목 글자(참고·주의 등)로 알립니다.

    클래스

    소스 CSS에서 자동으로 모은 목록입니다.

    • src/css/components/callout.css.Catui_callout .Catui_icon .Catui_callout-title .Catui_callout-tip .Catui_callout-warn .Catui_callout-danger
