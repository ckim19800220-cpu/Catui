진행

6색 구간을 bar-1 → bar-6 순서로 쓰는 진행 막대.

  • MUST 트랙 높이 6px
  • SHOULD 6색은 bar-1 → bar-6 순서
  • NEVER 그라디언트나 새 색을 추가하지 않는다

사용법

.Catui_prog 트랙(6px) 안에 <i class="Catui_pc1~6">를 너비로 넣습니다. 색은 pc1부터 순서대로 쓰고, 그라디언트나 새 색을 만들지 않습니다.

접근성

  • 값이 바뀌는 진행은 role="progressbar" + aria-valuenow/min/max, 고정 표시는 role="img" + aria-label.
  • 퍼센트 글자를 막대 옆에 함께 보입니다.
