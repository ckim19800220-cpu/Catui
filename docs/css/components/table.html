    CSS컴포넌트표

    표

    헤더 40px·행 46px, 지브라, 정렬 표시, 행 메뉴.

    소스src/css/components/table.css

    • MUST 헤더 40px · 행 46px
    • SHOULD 지브라, 상태는 pill로만
    • NEVER 정렬 화살표를 비활성 열에 붙이지 않는다

    기본 표

    행 메뉴 · 빈 상태

    변형 · 선택 행 · 머리 고정

    좁은 화면 카드형

    창 폭을 767px 이하로 줄이면 머리 줄은 숨고(화면 낭독기에는 남음) 각 칸 앞에 data-label 값이 라벨로 붙습니다.

    사용법

    .Catui_table-wrap(가로 스크롤) 안에 table.Catui_tbl. 숫자 열은 .Catui_num, 정렬 중인 열 머리만 .Catui_sort + aria-sort. 정렬·선택·페이지를 스크립트로 붙이려면 catui.js table.

    접근성

    • 표마다 <caption>(보이지 않게 하려면 .Catui_clip), 머리 칸은 th scope="col".
    • 행 메뉴 버튼 이름에 어느 행인지 넣습니다 (예: "김하늘 주문 메뉴").
    • 정렬 화살표는 정렬 중인 열에만 붙입니다.
