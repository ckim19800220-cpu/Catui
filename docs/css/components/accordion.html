아코디언

테두리로 묶인 펼침 목록과 카드형 펼침 상자.

아코디언

카드형 펼침 상자

사용법

.Catui_accordion 안에 details > summary + .Catui_accordion-body를 쌓습니다. 화살표는 CSS가 그리고 열리면 뒤집힙니다. 하나만 열리게 하려면 catui.js가 있는 페이지에서 data-catui-collapse="accordion"(collapse). 단독 상자는 details.Catui_details. 간단한 질문 목록은 질문(접기).

접근성

  • 네이티브 details/summary라 Enter·Space로 열고 닫히며, 열림 상태가 읽힙니다.
  • summary 안에 버튼·링크를 넣지 않습니다.

클래스

소스 CSS에서 자동으로 모은 목록입니다.

  • src/css/components/accordion.css.Catui_accordion .Catui_details .Catui_accordion-body .Catui_details-body
