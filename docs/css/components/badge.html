    CSS컴포넌트배지·카운트

    배지·카운트

    상태 pill(soft·solid), 사각 badge, 카운트, 점.

    소스src/css/components/badge.css

    • MUST 상태 pill은 soft 배경 + 실색 텍스트
    • SHOULD 카운터는 brand 실색, 높이 18px
    • NEVER pill 안에 pill을 중첩하지 않는다

    상태 pill

    solid · 사각 badge · 카운트

    외곽선 pill

    표·카드처럼 이미 색이 많은 곳에서 눈에 덜 띄게 표시할 때 씁니다. 상태 색은 soft 변형(Catui_pill-success 등)의 글자색을 그대로 따릅니다.

    버튼과 카운트

    메뉴 항목 끝의 카운트는 앱 셸 메뉴·세로 내비게이션, 탭 안 카운트는 탭을 보세요.

    사용법

    상태 표시는 soft pill이 기본입니다. solid는 한 화면에서 꼭 눈에 띄어야 하는 표식에만, 사각 .Catui_badge는 표 안 짧은 꼬리표에 씁니다. 카운트는 브랜드 실색 18px입니다.

    • .Catui_pill-outline — 배경을 지우고 글자색 계열 1px 테두리를 그립니다. soft 상태 변형과 겹쳐 쓰고, solid 변형(흰 글자)과는 함께 쓰지 않습니다.
    • 버튼 안 .Catui_count는 글자 뒤에 둡니다. 카운트가 브랜드 실색이라 primary 버튼보다 secondary·ghost 버튼과 어울립니다. 아이콘 모서리에 띄우려면 .Catui_indicator로 감쌉니다.

    접근성

    • 색만으로 상태를 구분하지 않습니다 — 항상 글자를 함께 씁니다.
    • 숫자만 있는 카운트에는 무엇의 개수인지 숨김 글자(<span class="Catui_clip">읽지 않음 </span>3<span class="Catui_clip">건</span>)로 보충합니다. 역할 없는 span의 aria-label은 화면 낭독기가 읽지 않습니다.
    • pill 안에 pill을 넣거나 높이를 늘리지 않습니다.
    • 외곽선 pill도 테두리 색만으로 상태를 구분하지 않고 글자로 상태를 적습니다.
    • 버튼 안 숫자는 .Catui_clip 숨김 글자로 "무엇이 몇 개"인지 보충합니다. 아이콘만 있는 버튼은 숨김 글자에 이름과 개수를 함께 쓰고, 보이는 숫자는 aria-hidden="true"로 중복 낭독을 막습니다.
