  • MUST 상태 pill은 soft 배경 + 실색 텍스트
  • SHOULD 카운터는 brand 실색, 높이 18px
  • NEVER pill 안에 pill을 중첩하지 않는다

상태 pill

solid · 사각 badge · 카운트

사용법

상태 표시는 soft pill이 기본입니다. solid는 한 화면에서 꼭 눈에 띄어야 하는 표식에만, 사각 .Catui_badge는 표 안 짧은 꼬리표에 씁니다. 카운트는 브랜드 실색 18px입니다.

접근성

  • 색만으로 상태를 구분하지 않습니다 — 항상 글자를 함께 씁니다.
  • 숫자만 있는 카운트에는 무엇의 개수인지 aria-label을 줍니다.
  • pill 안에 pill을 넣거나 높이를 늘리지 않습니다.
