    스레드

    깊이 가이드가 있는 댓글과 리액션.

    소스src/css/views/thread.css

    • MUST 깊이 가이드 2px + 들여쓰기 28
    • SHOULD 이름 13/600 + 시각 11 같은 baseline
    • NEVER 리액션 칩에 아이콘 없는 숫자만 두지 않는다

    예제

    사용법

    .Catui_thread-item + 답글은 .Catui_thread-kids 가이드선, 반응은 .Catui_react(-on).

    접근성

    • 리액션 버튼은 aria-pressed로 눌림 상태를 알리고, 아이콘과 숫자를 함께 씁니다.
    • 답글 들여쓰기는 깊이 가이드 선과 함께 보입니다.
