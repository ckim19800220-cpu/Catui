달력

월간 격자, 오늘·주말·다른 달·일정 칩.

  • MUST 오늘은 원형 + inverse, 다른 달 날짜는 tertiary
  • SHOULD 이벤트 칩 하루 최대 2개, 주말은 muted
  • NEVER 셀을 1px divider 외 장식으로 나누지 않는다

예제

사용법

.Catui_cal > Catui_cal-top/dows/week. 셀 상태는 Catui_cal-today/sel/out/weekend, 일정은 .Catui_cal-event(-info/-warn/-3).

접근성

  • 달력 전체에 aria-label="2026년 9월", 오늘은 색과 함께 숨김 글자로도 알립니다.
  • 일정 칩은 하루 2개까지, 나머지는 "+n".
