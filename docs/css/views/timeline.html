타임라인

단일 색 도트와 상태 pill로 된 활동 기록.

  • MUST 선 2px, 도트 10px brand
  • SHOULD 우측 상태는 pill로만
  • NEVER 도트 색을 상태별로 바꾸지 않는다

예제

사용법

.Catui_atl > .Catui_atl-item + .Catui_atl-main. 선과 점은 ::before/::after.

접근성

  • 목록 의미(role="list"/listitem)로 순서를 전합니다.
  • 상태는 pill(점 + 글자)로, 도트 색으로 구분하지 않습니다.

클래스

소스 CSS에서 자동으로 모은 목록입니다.

  • src/css/views/timeline.css.Catui_atl .Catui_atl-item .Catui_atl-main
