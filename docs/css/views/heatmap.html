히트맵

brand 단일 색조 5단계 농도.

  • MUST 농도는 heat-1..5, 0은 neutral-100
  • SHOULD 범례는 적음 → 많음 순
  • NEVER 단계마다 다른 색상 금지 — brand 단일 색조

예제

사용법

.Catui_heat-grid에 셀 i.Catui_heat-1~5를 채웁니다. 범례는 .Catui_heat-legend.

접근성

  • 색 농도만으로 값을 전하지 않습니다 — 칸마다 title, 전체 요약 aria-label.
  • 범례는 적음 → 많음 순.
