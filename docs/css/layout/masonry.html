벽돌·벤토·쌓임

높이가 다른 카드 벽돌 배치, 크기가 다른 칸 벤토 격자, 스크롤하면 쌓이는 카드.

벤토 격자

쌓이는 카드

사용법

벽돌은 CSS 다단(columns)이라 읽는 순서가 위→아래, 왼쪽 열→오른쪽 열입니다. 순서가 중요한 목록에는 그리드를 쓰세요. 벤토는 grid-auto-flow:dense로 빈칸을 채우므로 화면 순서와 소스 순서가 다를 수 있습니다. 쌓이는 카드는 자식마다 style="--i:0,1,2…"로 겹치는 간격을 주고, 위 여백은 --Catui_fx-top입니다.

접근성

  • 세 배치 모두 CSS만 바꾸며 마크업 순서는 그대로 읽힙니다. 키보드 이동 순서도 소스 순서입니다.
  • 벤토에서 중요한 내용은 소스 앞쪽에 두어 화면 리더에서도 먼저 읽히게 합니다.
