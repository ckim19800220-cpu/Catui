관리 셸

사이드바 200px·탑바 56px·본문으로 이루어진 관리 화면 골격입니다. 991px 이하에서 사이드바가 56px 레일로 접힙니다.

접근성

  • 사이드바는 nav aria-label, 현재 메뉴는 aria-current="page".
  • 991px 이하 레일에서는 라벨이 숨으므로 항목에 아이콘과 함께 숨김 라벨(.Catui_clip)이 남아 있어야 합니다.
  • 첫 요소로 건너뛰기 링크(.Catui_skip)를 둡니다.
