    부품 따로 쓰기

    위 셸에 들어 있는 부품을 하나씩 떼어 복사할 수 있게 나눴습니다. 사이드바 부품은 색·글자 크기 토큰(--Catui_sidebar-*)과 summary 모양을 .Catui_side에서 받으므로 그 안에 둡니다. 예제에서는 높이를 줄이려고 min-height만 덮어썼습니다.

    그룹 제목 .Catui_group, 항목 a.Catui_item(아이콘 + .Catui_item-label), 개수 .Catui_count(오른쪽 끝), 접는 하위 메뉴 details.Catui_nest > summary.Catui_item. 현재 항목은 aria-current="page"(또는 .Catui_item-active)로 왼쪽 막대가 붙습니다.

    사이드바 맨 아래에 두는 줄입니다. 이름은 b, 역할은 span(작은 옅은 글자). 991px 이하 레일에서는 글자가 숨김 처리되고 아바타만 남습니다.

    .Catui_topbar-search는 남는 폭을 차지하되 최대 320px, .Catui_top-actions는 margin-left:auto로 오른쪽 끝에 붙고 안의 아이콘은 --Catui_topbar-icon(20px) 크기가 됩니다. 767px 이하에서는 검색이 다음 줄 전폭으로 내려갑니다.

    접근성

    • 사이드바는 nav aria-label, 현재 메뉴는 aria-current="page".
    • 991px 이하 레일에서는 라벨이 숨으므로 항목에 아이콘과 함께 숨김 라벨(.Catui_clip)이 남아 있어야 합니다.
    • 첫 요소로 건너뛰기 링크(.Catui_skip)를 둡니다.
