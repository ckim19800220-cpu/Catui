맨 위로

쿠키 동의

사용법

둘 다 실제로는 화면에 고정(position:fixed)됩니다. 예제는 미리보기 안에 보이도록 position:static으로 두었습니다. 맨 위로 버튼은 href="#본문-id" 링크로 만들면 스크립트 없이 동작하고, 스크롤 후에만 보이게 하려면 data-catui-totop="400"을 달면 catui.js page가 처리합니다. 쿠키 띠는 동의 후 스크립트로 닫습니다.

접근성

  • 맨 위로 버튼에 aria-label, 쿠키 띠는 role="region" + 이름.
  • 고정 요소가 본문 마지막 내용이나 다른 버튼을 가리지 않도록 아래 여백을 둡니다.
