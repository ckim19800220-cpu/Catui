섹션 머리·공지 띠

소제목(eyebrow)·제목·설명 묶음과 페이지 맨 위 공지 띠.

섹션 머리

공지 띠

머리 + 동작 · 공지 띠 변형

.Catui_section-head-row는 제목 묶음과 버튼을 양 끝에 둡니다(767px 이하 세로). 공지 띠 색은 -brand(진한 브랜드)·-soft(연한 브랜드), 닫기는 .Catui_announce-close입니다.

사용법

섹션 맨 위에 .Catui_section-head(.Catui_eyebrow + 제목 + .Catui_lead)를 둡니다. 제목은 문서 구조에 맞는 h2·h3로 쓰고 모양은 .Catui_h1로 맞춥니다. 공지 띠 .Catui_announce는 헤더 위에 한 줄만 둡니다.

접근성

  • 소제목은 꾸밈 글자이므로 제목 태그로 쓰지 않습니다.
  • 공지 띠는 role="region" + 이름으로 찾을 수 있게 하고, 닫기 버튼을 두면 이름을 붙입니다.
