팀·프로필

사진·이름·역할·소개·링크가 있는 팀 소개 카드.

소스src/css/blocks/people.css

팀 카드

가로 프로필

연락처 페이지·작성자 소개처럼 한 줄에 정보를 넣을 때 .Catui_profile-row를 씁니다.

사용법

article.Catui_profile = 사진 .Catui_profile-photo(88px 원형) + -name + -role + -bio + 링크 -links. 여러 명은 .Catui_grid-3으로 배치합니다.

접근성

  • 사진 alt는 이름, 아이콘 링크 이름에는 누구의 무엇인지 넣습니다 (예: "김하늘 메일").

클래스

소스 CSS에서 자동으로 모은 목록입니다.

  • src/css/blocks/people.css.Catui_profile .Catui_profile-photo .Catui_profile-name .Catui_profile-role .Catui_profile-bio .Catui_profile-links .Catui_profile-row
