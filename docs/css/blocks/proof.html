카드형 숫자 · 큰 후기

숫자 출처·기준은 .Catui_statband-note로 함께 밝힙니다. 대표 후기 하나는 .Catui_testi-lg로 가운데 크게, 별점은 .Catui_testi-stars(전체에 점수 라벨).

사용법

로고는 .Catui_logos 안에 이미지(높이 28px) 또는 글자로, 숫자는 .Catui_statband(자동 열), 후기는 figure.Catui_testi(인용 + 사람)입니다.

접근성

  • 로고 이미지에는 회사 이름을 alt로 줍니다.
  • 후기는 blockquote + figcaption으로 누가 말했는지 연결합니다.
