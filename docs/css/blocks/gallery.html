캡션 겹침 · 작성자 아바타

캡션은 figure > figcaption이면 그림 아래쪽에 겹쳐 보입니다(흰 글자 + 어두운 그라디언트). 글 정보 맨 앞의 아바타 뒤에는 구분 점이 붙지 않습니다.

사용법

.Catui_gallery(160px 격자) 안의 링크·figure에 이미지를 넣습니다. 강조 칸은 .Catui_gallery-wide(2칸 폭)·-tall(2칸 높이). 글 정보는 .Catui_meta 안에 항목을 나열하면 사이에 점이 들어갑니다.

접근성

  • 갤러리 링크마다 이미지 alt가 링크 이름이 됩니다.
  • 날짜는 time datetime으로 기계가 읽을 수 있게 합니다. 확대 효과는 모션 줄이기에서 꺼집니다.

클래스

소스 CSS에서 자동으로 모은 목록입니다.

  • src/css/blocks/gallery.css.Catui_gallery .Catui_gallery-wide .Catui_gallery-tall .Catui_meta .Catui_av
