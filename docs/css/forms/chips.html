    선택 칩

    checkbox·radio로 만든 필터 칩.

    소스src/css/forms/chips.css

    여러 개 선택 (checkbox)

    하나만 선택 (radio)

    사용법

    fieldset.Catui_chips 안에 input.Catui_clip + label.Catui_chip를 짝으로 둡니다. 체크 아이콘은 선택됐을 때만 보입니다. 지울 수 있는 값 목록은 태그, 한 줄 값 고르기는 세그먼트를 씁니다.

    접근성

    • 실제 checkbox·radio라 Tab·Space·화살표 키가 그대로 동작합니다. 묶음 이름은 legend.
    • 선택은 색·굵기·체크 아이콘을 함께 바꿔 색만으로 구분하지 않습니다.

    클래스

    소스 CSS에서 자동으로 모은 목록입니다.

    • src/css/forms/chips.css.Catui_chips .Catui_chip .Catui_icon
