    CSS고급 입력별점

    별점

    radio 그룹으로 만든 별점.

    소스src/css/forms/rating.css

    입력

    읽기 전용

    사용법

    .Catui_rating 안에 input.Catui_clip + 별 label을 1점부터 차례로 둡니다. 선택한 별까지 켜집니다. 문구 표시·지우기·읽기 전용 생성은 catui.js rate.

    접근성

    • fieldset + legend로 묶고, 각 별 label에 "n점" 이름을 줍니다.
    • radio 그룹이라 화살표 키로 고릅니다. 읽기 전용은 role="img"로 점수만 읽힙니다.

    클래스

    소스 CSS에서 자동으로 모은 목록입니다.

    • src/css/forms/rating.css.Catui_rating .Catui_icon
