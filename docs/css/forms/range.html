    CSS고급 입력범위

    범위

    트랙·썸을 토큰으로 그린 range와 눈금.

    소스src/css/forms/range.css

    기본

    눈금 · 양 끝 · 비활성

    사용법

    input[type=range].Catui_range는 트랙·썸을 토큰으로 그립니다. 눈금은 .Catui_range-ticks(<i> 개수 = 단계 수), 양 끝 숫자는 .Catui_range-scale. 값 표시·화면 낭독기 문구는 catui.js slider가 자동으로 맞춥니다.

    접근성

    • label과 연결하고, 단위가 있으면 aria-valuetext로 읽히게 합니다.
    • 눈금·양 끝 숫자는 장식이므로 aria-hidden.

    클래스

    소스 CSS에서 자동으로 모은 목록입니다.

    • src/css/forms/range.css.Catui_range .Catui_range-scale .Catui_range-ticks
