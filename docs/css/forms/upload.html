업로드

label이 숨긴 file input을 감싸는 끌어 놓기 영역.

소스src/css/forms/upload.css

업로드 영역

올린 파일 목록 · 오류

사용법

label.Catui_upz가 숨긴 file input을 감싸 영역 전체를 누를 수 있습니다. 끌어 놓기·검사·진행률·목록은 catui.js upload가 처리합니다.

접근성

  • label이 file input을 감싸 영역 전체가 눌립니다(키보드는 input이 받음).
  • 형식·용량 제한을 힌트 문장으로 미리 알리고, 오류는 role="alert" 문장으로.

클래스

소스 CSS에서 자동으로 모은 목록입니다.

  • src/css/forms/upload.css.Catui_upz .Catui_icon .Catui_upz-title .Catui_upz-hint
