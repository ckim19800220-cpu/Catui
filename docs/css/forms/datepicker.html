사용법

.Catui_dp > 월 이동 머리줄 .Catui_dp-head(이전·월·다음) + 요일 .Catui_dp-dows + 격자 .Catui_dp-grid. 칸 상태는 dp-out(다른 달)·dp-today·dp-sel·dp-range·dp-dis. 입력 칸에 붙는 팝업과 키보드 이동은 catui.js datePicker.

접근성

  • 날짜 칸은 버튼으로 만들고 "10월 3일, 선택됨"처럼 전체 날짜를 이름으로 줍니다.
  • 선택 불가 날짜는 aria-disabled, 선택 상태는 aria-pressed.
