    CSS기초색상

    색상

    팔레트·상태·차트 시리즈 토큰.

    쓰는 법

    색은 항상 변수로 씁니다. 텍스트·포커스는 AA를 넘는 brand-strong·text-primary/secondary를, 배경·장식은 brand·*-soft를 씁니다.

    팔레트 토큰

    토큰 ^color-
    변수값견본
    --Catui_color-brand#26B99A
    --Catui_color-brand-hover#1FA188
    --Catui_color-brand-soft#E6F7F3
    --Catui_color-info#3498DB
    --Catui_color-info-soft#EAF4FB
    --Catui_color-purple#9B59B6
    --Catui_color-purple-soft#F5EBF8
    --Catui_color-amber#F1C40F
    --Catui_color-amber-soft#FEF7E0
    --Catui_color-orange#E67E22
    --Catui_color-danger#E74C3C
    --Catui_color-danger-soft#FDECEA
    --Catui_color-page-bg#F7F8FA
    --Catui_color-surface#FFFFFF
    --Catui_color-surface-muted#FAFBFC
    --Catui_color-bordervar(--Catui_line)
    --Catui_color-dividervar(--Catui_line-soft)
    --Catui_color-navy-900#243444
    --Catui_color-navy-800#2A3F54
    --Catui_color-navy-700#334B63
    --Catui_color-navy-500#5A7184

    --Catui_color-text-primary#2C3E50
    --Catui_color-text-secondary#66727E
    --Catui_color-text-tertiary#9AA5B1

    --Catui_color-neutral-100#F2F4F6

    차트 시리즈

    차트는 시리즈 5색을 순서대로 씁니다. 한 차트에 5색이 넘지 않게 합니다.

    토큰 ^chart-series-
    변수값견본
    --Catui_chart-series-1var(--Catui_color-brand)
    --Catui_chart-series-2var(--Catui_color-info)
    --Catui_chart-series-3var(--Catui_color-purple)
    --Catui_chart-series-4var(--Catui_color-amber)
    --Catui_chart-series-5var(--Catui_color-neutral-300)
