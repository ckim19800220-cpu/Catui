섹션 띠

사용법

연한 배경은 Catui_bg-surface/muted/page/brand-soft/info-soft/warning-soft/danger-soft. 진한 배경 Catui_bg-brand·bg-dark·bg-gradient-dark는 글자색을 함께 바꾸고, 안의 도입문·보조 글자·링크도 따라 바뀝니다. 이미지는 style="--Catui_bg-img:url(…)" + .Catui_bg-image, 글자를 올릴 때는 .Catui_overlay를 겹칩니다. 공개 홈 섹션은 .Catui_band로 여백을 맞춥니다.

접근성

  • 진한 배경 위 글자는 흰색 계열로 바뀌어 대비 AA를 넘습니다. 이미지 위 글자는 반드시 겹침과 함께 씁니다.
  • 패턴 배경 위에는 긴 글을 두지 않습니다(읽기 방해).
