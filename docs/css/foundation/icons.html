아이콘

Lucide 스프라이트 사용법과 목록.

쓰는 법

기본 24px, Catui_i12/16/18/20으로 줄입니다. 선 두께는 1.5, 색은 currentColor입니다. 장식 아이콘은 aria-hidden="true", 아이콘만 있는 버튼은 aria-label을 줍니다.

아이콘 추가

src/icons/allow.json에 Lucide 이름(케밥 표기)을 넣고 빌드합니다. 없는 이름이면 빌드가 실패합니다. 라이선스: Lucide ISC.
