아이콘

아이콘 스프라이트(Line 01 · CC0, 저작권 표시 불필요) 사용법과 목록.

쓰는 법

기본 24px, Catui_i12/16/18/20으로 줄입니다. 선 두께는 1.5, 색은 currentColor입니다. 장식 아이콘은 aria-hidden="true", 아이콘만 있는 버튼은 aria-label을 줍니다.

아이콘 추가

src/icons/allow.json에 이름(케밥 표기)을 넣고 빌드합니다. 빌드는 아래 순서로 원본을 찾고, 없으면 실패합니다.

  1. src/icons/svg/이름.svg — Catui 원본(직접 그림)
  2. src/icons/line01/파일.svg — Line 01 1,178개. 이름이 다르면 src/icons/map.json에 대응을 적습니다(예: "x": "close").

새 Line 01 아이콘을 받으려면 node scripts/fetch-line01.mjs. 원본은 24×24 선 아이콘이어야 하고, 스크립트·이벤트 속성·외부 참조가 있으면 빌드가 막습니다. 선 굵기는 1.5로 통일합니다.

라이선스

Line 01 아이콘은 제작자 Andreas Dittes가 CC0 1.0(퍼블릭 도메인)으로 공개한 원본입니다. 상업적 사용·수정·재배포가 자유롭고 저작권 표시가 필요 없습니다. Line 01에 없는 일부는 Catui가 직접 그린 원본입니다. 따라서 배포물에 별도 제3자 고지가 필요 없습니다. (CC0는 "iconsforfree" 이름·로고의 상표권은 주지 않습니다.)
