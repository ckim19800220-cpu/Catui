    CSS기초시각 원칙

    시각 원칙

    1px 잉크 테두리, 미니멀 모서리 단계, 층에만 쓰는 그림자·유리, 대비 기준과 빌드 검사.

    소스src/css/components/glass.css

    여덟 가지 원칙

    Catui의 화면은 가는 선이 윤곽을 맡고, 그림자는 떠 있는 층에만, 유리는 겹쳐 뜨는 층에만 쓰는 미니멀 방식입니다. 라이트·다크 어느 쪽에서도 같은 대비가 나오도록 선을 고정 회색이 아닌 반투명 잉크로 정의합니다. 원칙은 src/css/foundation/tokens.css 머리 주석과 같고, 일부는 빌드 검사가 강제합니다.

    시각 원칙
    원칙규칙빌드 검사
    1. 선은 1px모든 컴포넌트 테두리는 hairline 1px. 2px 이상은 포커스 링·활성 표시줄(탭 밑줄·옆 막대·진행)·상태 표식만예 — border:2px 이상은 같은 줄에 /* 굵은선 허용: 이유 */ 또는 굵기 토큰
    2. 잉크 테두리선 색은 글자색(text-primary)을 반투명으로 섞은 --Catui_line* — 어떤 바탕 위에서도 같은 대비hex 금지 검사(확장)
    3. 모서리 단계xs 2 · sm 4 · md 6 · lg 8 · xl 10. 버튼·입력 4, 카드·메뉴·토스트·모달 6. pill은 배지·토글·아바타·칩만예 — border-radius에 토큰이 아닌 길이 금지(0·50% 허용)
    4. 그림자는 층만윤곽은 선이 맡고, 그림자는 떠 있는 층(메뉴·토스트·모달)에 얕고 짧게. 다크는 위쪽 1px 밝은 inset—
    5. 유리는 떠 있는 층만상단 바·메뉴·메가 메뉴·토스트·아래 고정 줄·대화상자 덮개. 본문 카드·표·폼·모달 패널에는 쓰지 않음예 — backdrop-filter를 쓰면 같은 파일에 @supports not 폴백 + prefers-reduced-transparency
    6. 대비글자 4.5:1(큰 글자 3:1), 비텍스트(입력 테두리·포커스·상태 표식) 3:1시각 QA(전 쪽 대비 측정)
    7. 상태는 색 + 형태색만으로 알리지 않음 — 아이콘·글자·굵기·막대를 함께—
    8. 간격 4px 격자--Catui_space-*만 사용—

    선 — 반투명 잉크 hairline

    네 단계 선 토큰을 씁니다. 공개 이름 --Catui_color-border·--Catui_card-border·--Catui_input-border·--Catui_divider-color·--Catui_tab-border 등은 그대로이고, 값만 이 토큰으로 이어집니다.

    토큰 ^line
    변수값견본
    --Catui_linecolor-mix(in srgb, var(--Catui_color-text-primary) 14%, transparent)
    --Catui_line-strongcolor-mix(in srgb, var(--Catui_color-text-primary) 24%, transparent)
    --Catui_line-softcolor-mix(in srgb, var(--Catui_color-text-primary) 8%, transparent)
    --Catui_line-controlcolor-mix(in srgb, var(--Catui_color-text-primary) 56%, transparent)
    --Catui_line-control-hovercolor-mix(in srgb, var(--Catui_color-text-primary) 74%, transparent)
    --Catui_line-w1px
    선 대비 실측 (면 · 페이지 · 연한 면)
    토큰라이트 섞음라이트 대비다크 섞음다크 대비
    line-soft8%1.158%1.24
    line14%1.28 (이전 1.22)12%1.39 (이전 1.34)
    line-strong24%1.5422%1.91
    line-control — 입력·체크·토글 꺼짐56%3.06 ~ 3.1342%3.42 ~ 3.59
    line-control-hover74%4.89 ~ 5.0662%5.71 ~ 6.29

    카드·표의 선은 글자·면 색 차이가 경계를 함께 알려 주므로 3:1 대상이 아닙니다. 입력 칸처럼 테두리만으로 컨트롤을 알아보는 곳은 line-control로 WCAG 1.4.11(비텍스트 3:1)을 지킵니다.

    모서리 — 미니멀 단계

    이전 단계(xs 4 · sm 6 · md 8 · lg 12)보다 한 단계씩 줄였습니다. 컴포넌트 반경 토큰(--Catui_btn-radius·--Catui_card-radius·--Catui_modal-radius 등)은 이 단계를 참조하므로 이름을 바꿀 필요가 없습니다.

    그림자 — 층(elevation)만

    평면 요소(카드·표·폼)는 선으로 끝나고 그림자는 거의 없습니다(xs). 화면 위에 겹쳐 뜨는 층만 md(메뉴·토스트·팝오버)·lg(모달·드로어·명령 팔레트)를 씁니다. 다크에서는 어두운 바탕에 그림자가 묻히므로 위쪽 1px 밝은 inset으로 층을 드러냅니다.

    토큰 ^shadow-
    변수값견본
    --Catui_shadow-xs0 1px 0 rgba(16,24,40,.03)
    --Catui_shadow-sm0 1px 2px rgba(16,24,40,.05)
    --Catui_shadow-md0 4px 10px -2px rgba(16,24,40,.08),0 2px 4px -2px rgba(16,24,40,.05)
    --Catui_shadow-lg0 12px 24px -6px rgba(16,24,40,.14),0 4px 8px -4px rgba(16,24,40,.06)

    유리 — 떠 있는 층만

    • 쓰는 곳: .Catui_topbar·.Catui_site-header(흐림은 ::before 층 — 안쪽 메뉴의 흐림과 position:fixed 기준을 깨지 않게), .Catui_dd-menu(JS 메뉴 .Catui_dd-float 포함), .Catui_mega-panel, .Catui_toast, .Catui_actionbar, 확장의 고정 머리·아래 탭 줄, 대화상자 덮개(.Catui_scrim·::backdrop — 2px 젖빛 흐림).
    • 쓰지 않는 곳: 본문 카드·표·폼·말풍선(작은 글자) — 뒤 내용이 비치면 읽기가 나빠집니다. 모달·드로어·명령 팔레트 패널도 불투명 면입니다 — 어두운 덮개 위에 반투명 면을 겹치면 회색으로 탁해지므로, 유리 효과는 덮개 흐림이 맡습니다.
    • 불투명도: 작은 층 --Catui_glass-bg 82%, 글자가 많은 바 --Catui_glass-bg-strong 92%. 뒤가 남색(navy-900)이어도 본문 글자 7.5:1 이상이 남는 값입니다.
    • 폴백: @supports not (backdrop-filter…)이면 불투명 면, prefers-reduced-transparency: reduce이면 불투명 + 흐림 없음, forced-colors이면 시스템 색 Canvas.
    토큰 ^glass-
    변수값견본
    --Catui_glass-bgcolor-mix(in srgb, var(--Catui_color-surface) 82%, transparent)
    --Catui_glass-bg-strongcolor-mix(in srgb, var(--Catui_color-surface) 92%, transparent)
    --Catui_glass-bordervar(--Catui_line)
    --Catui_glass-blursaturate(140%) blur(12px)

    포커스 링

    굵은 선이 허용되는 첫 번째 자리입니다. outline:var(--Catui_ring);outline-offset:var(--Catui_ring-offset) — 2px, 브랜드 강조색(면 위 3:1 이상), :focus-visible에만.

    토큰 ^ring
    변수값견본
    --Catui_ring-w2px
    --Catui_ring-offset2px
    --Catui_ringvar(--Catui_ring-w) solid var(--Catui_color-focus-ring)
    토큰 ^accent-w
    변수값견본
    --Catui_accent-w3px

    빌드 검사

    npm run build가 본체(src/css)·확장(src/admin·community·shop·docskit·booking)·문서(docs-src/assets) CSS 전부를 scripts/lib.mjs의 visualErrors로 검사하고, 어기면 파일·줄과 함께 실패합니다.

    /* 실패 */  .x{border:2px solid var(--Catui_line)}
/* 통과 */  .x{border-bottom:var(--Catui_tab-indicator-w) solid transparent}
/* 통과 */  .x[aria-pressed="true"]{border-width:2px}   /* 굵은선 허용: 선택 상태(색+굵기) */
/* 실패 */  .x{border-radius:12px}
/* 통과 */  .x{border-radius:var(--Catui_radius-md) var(--Catui_radius-md) 0 0}
/* 실패 */  .x{backdrop-filter:blur(8px)}   ← 같은 파일에 @supports not · prefers-reduced-transparency 없음
