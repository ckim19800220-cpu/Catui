CSS · 기초

간격·반경·그림자

4px 배수 간격, 반경, 그림자, 컨트롤 높이 토큰.

간격

간격은 4px 배수 10단계입니다. 컴포넌트 안은 작은 단계, 컴포넌트 사이는 --Catui_grid-gap(20), 화면 가장자리는 --Catui_content-pad(24)를 씁니다.

토큰 ^space-
변수값견본
--Catui_space-14px
--Catui_space-28px
--Catui_space-312px
--Catui_space-416px
--Catui_space-520px
--Catui_space-624px
--Catui_space-732px
--Catui_space-840px
--Catui_space-948px
--Catui_space-1064px

반경

토큰 ^radius-
변수값견본
--Catui_radius-xs4px
--Catui_radius-sm6px
--Catui_radius-md8px
--Catui_radius-lg12px
--Catui_radius-pill999px

그림자

카드는 xs, 드롭다운·팝오버는 md까지. 카드 안에 md 이상 그림자를 겹치지 않습니다.

토큰 ^shadow-
변수값견본
--Catui_shadow-xs0 1px 1px rgba(16,24,40,.04)
--Catui_shadow-sm0 1px 2px rgba(16,24,40,.06),0 1px 3px rgba(16,24,40,.04)
--Catui_shadow-md0 4px 12px rgba(16,24,40,.08)
--Catui_shadow-lg0 12px 32px rgba(16,24,40,.12)

컨트롤 높이

토큰 ^control-h-
변수값견본
--Catui_control-h-sm28px
--Catui_control-h-md34px
--Catui_control-h-lg40px
