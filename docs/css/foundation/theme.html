CSS · 기초

다크 모드

data-catui-theme="dark" 한 줄로 바꾸는 다크 테마와 대비 실측.

켜는 법

<html data-catui-theme="dark">를 주면 전체가 다크 테마가 됩니다. 이 문서 오른쪽 위의 별 버튼으로 바로 바꿔 볼 수 있습니다.

<html lang="ko" data-catui-theme="dark">

<!-- 시스템 설정을 따르려면 (head 안, 깜빡임 방지) -->
<script>
  if (matchMedia('(prefers-color-scheme: dark)').matches) document.documentElement.setAttribute('data-catui-theme', 'dark');
</script>

미리보기

동작 원리

  • 토큰이 모두 :root에 있으므로, 다크에서는 원본 색 토큰(면·글자·테두리·중립·연한 상태색·남색·코드)과 hex로 고정된 상태 글자색만 다시 정의합니다. 컴포넌트 토큰은 자동으로 따라옵니다(src/css/foundation/theme-dark.css).
  • 글자용 브랜드 --Catui_color-brand-strong은 다크에서 밝아지고, 흰 글자를 올리는 채움 --Catui_color-brand-fill은 그대로입니다. 새 컴포넌트에서 흰 글자 위 배경에는 brand-fill, 글자·테두리·포커스에는 brand-strong을 씁니다.
  • 상태 글자색을 배경으로 쓰는 solid pill은 다크에서 어두운 글자로 뒤집힙니다.
