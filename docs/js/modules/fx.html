    catui.js모듈fx 효과

    fx 효과

    텍스트·스크롤·커서·화면 기능·배경 효과 46종 · 효과 등록·일시정지·조합 놀이터 (모션 줄이기·키보드·접근성 대응).

    효과 모음

    텍스트·스크롤·커서·화면 기능·배경 효과 46종을 의존성 없이 붙입니다. 반복해서 움직이는 효과는 공용 프레임 티커 하나로 돌아, 화면 밖·숨은 탭·페이지 일시정지 중에는 계산하지 않습니다. 함수로 호출하거나 data-catui-fx 속성만 붙여도 되고, 모두 { destroy() }로 원래대로 돌아갑니다. 모션 줄이기 설정에서는 최종 상태를 바로 보입니다. 효과의 종류는 React Bits 같은 애니메이션 모음이 다루는 범주를 참고했고, 코드는 Catui용으로 새로 작성했습니다.

    함께 쓰기 · 충돌

    한 요소에 data-catui-fx="spotlight border glare noise tilt magnet"처럼 여러 효과를 붙일 수 있습니다. 서로 지우는 조합은 fx가 미리 막습니다.

    fx 조합 규칙
    경우처리
    덧칠 효과 여러 개 (spotlight·aurora·border·glare·edge·noise)효과마다 전용 레이어에 그려 함께 보임
    움직임 여러 개 (tilt·magnet·press·dock·reveal·버튼 눌림)transform·translate·scale을 나눠 써서 합쳐짐
    글자를 다시 쓰는 효과끼리 (split·count·type·scramble·rotate·focus·circle·glitch)먼저 붙은 하나만 적용, 나머지는 건너뛰고 콘솔 경고
    글자 채움끼리 (shiny·gradient·stroke), 애니메이션 속성끼리 (shiny·gradient·circle·pulse)〃
    배경 캔버스끼리 (particles·waves·dotgrid·ripplegrid), 흐르는 띠끼리 (marquee·velocity)〃
    hold와 클릭 효과 (ripple·spark)〃 — hold 버튼은 클릭을 항상 막고 catui:hold로만 실행
    같은 효과를 두 번새로 만들지 않고 처음 핸들을 돌려줌

    효과 등록 · 일시정지

    새 효과는 fx.register로 추가합니다. 반복 갱신은 kit.frame(공용 티커)을 쓰면 화면 밖·숨은 탭·일시정지에서 저절로 쉬고, slots를 주면 내장 효과와 겹칠 때 충돌 검사를 받습니다.

    API

    fx API
    함수 · 속성옵션설명
    fx.reveal(el) · revealy · delay · once화면에 들어오면 아래에서 떠오르며 나타남 (data-catui-delay)
    fx.split(el) · splitby: 'char'|'word' · stagger글자·단어가 흐림에서 차례로 또렷해짐 (data-catui-by)
    fx.count(el) · countto · from · duration · decimals · prefix/suffix숫자가 올라감, 천 단위 구분 (data-catui-to)
    fx.type(el) · typewords · speed · pause · loop타자기로 단어를 차례로 쓰고 지움 (단어는 |로 구분)
    fx.scramble(el) · scrambleduration · chars · hover무작위 글자에서 원문으로 해독
    fx.tilt(el) · tiltmax커서 쪽 3D 기울기 (마우스 환경만)
    fx.spotlight(el) · spotlight—커서 따라 브랜드 빛, 포커스에도 켜짐
    fx.magnet(el) · magnetstrength커서 쪽으로 살짝 끌림 (마우스 환경만)
    fx.spark(el) · sparkcount클릭 위치에 불꽃 조각
    fx.particles(el) · particlescount · link점과 선 배경 (canvas 사용)
    shiny · gradient—빛이 지나가는 글자 · 흐르는 그라디언트 글자 (글자 자체는 AA 브랜드 색)
    fx.rotate(el) · rotatewords · interval단어가 위로 밀려 바뀜 (단어는 |로 구분)
    glitch—앞뒤 색 복제가 잠깐 어긋나는 글리치
    border · glare—테두리를 도는 빛 · 호버·포커스 시 광택
    ripple—누른 지점에서 퍼지는 물결
    fx.marquee(el) · marqueespeed(초)자식들이 끝없이 흐름. 복제본은 화면 낭독기·탭에서 제외, 마우스·포커스에서 멈춤
    fx.dock(el) · dockscale · radius커서와 가까운 항목일수록 커짐 (마우스 환경만)
    aurora · fx.waves(el)lines · amplitude오로라 그라디언트(CSS) · 물결 선(캔버스) 배경
    fx.hold(el) · holdduration(ms) · onHold길게 누르면 실행. 진행 막대, Space·Enter 지원, catui:hold 이벤트, 떼면 취소
    fx.swipe(row) · swipe—.Catui_fx-swipe-front를 밀면 -actions가 드러남. Tab 포커스로도 열리고 Esc로 닫힘. 핸들의 close()로 닫기
    fx.list(ul) · list—항목 차례 등장, ↑↓·Home·End 이동, Enter·Space 선택(catui:select)
    fx.indicator(nav) · indicator—현재 항목(aria-current·aria-pressed·aria-selected·checked) 표시가 미끄러짐. pressed 묶음은 하나만 눌림. 항목을 바꾼 뒤 핸들의 update()로 다시 맞춤
    fx.flip(card) · flip—[data-catui-flip] 버튼으로 앞뒤 전환, 안 보이는 면은 inert, catui:flip. 핸들의 toggle()로 뒤집기
    fx.check(svg)—완료 체크를 그림 (.Catui_fx-check). 다시 그리려면 돌려받은 핸들의 replay() — 같은 요소에 다시 호출하면 처음 핸들을 돌려줄 뿐 다시 그리지 않음
    pulse · press—좋아요 토글(aria-pressed) + 톡 튀기 · 영역 안 버튼·토글·라디오·칩에 눌림 탄성
    fx.circle(el) · circleradius (data-catui-radius)글자를 원형으로 배치해 천천히 회전
    fx.focus(el) · focusinterval단어를 차례로 또렷하게, 나머지는 흐림
    velocityspeed스크롤 속도만큼 빨라지는 흐르는 띠
    stroke · edge · noise—외곽선 글자(장식용 큰 제목) · 아래 가장자리 흐림 · 그레인 질감
    dotgrid · ripplegridgap · reach커서에 반응하는 점 격자 · 퍼지는 물결 격자 (캔버스)
    fx.cursor(el) · cursortype: 'glow'|'ring' (data-catui-cursor)요소 위에서만 따라다니는 빛·고리 (마우스 환경만)
    fx.flap(el) · flapchars · stagger · speed(ms)출발판처럼 칸마다 글자가 넘어가다 왼쪽부터 원래 글자에 멈춤. 화면 낭독기는 원문 한 번
    fx.rise(el) · risedistance(화면 높이 배수, 기본 0.6)요소가 올라오는 만큼 단어가 차례로 또렷하게 떠오름 (--Catui_fx-k 0→1)
    fx.mesh(el) · meshcols · rows · reach격자 점이 커서에 밀렸다 용수철처럼 돌아오는 캔버스 배경. 모션 줄이기면 반듯한 격자
    fx.orbit(el) · orbitcount · speed(초, 한 바퀴)점이 테두리(둥근 모서리 포함)를 따라 돎. SVG 레이어, 크기 변화에 맞춤. 모션 줄이기면 멈춘 점
    halftone—내용 위 반점 덮개가 마우스·포커스(:focus-within)에 걷힘 (CSS 레이어)
    fx.depth(el) · depthstagger(ms) · once화면에 들어오면 단어가 뒤에서 앞으로 세워지듯 나타남(CSS 3D). 화면 낭독기는 원문 한 번
    fx.echo(el) · echocount(1~6, 기본 3)마우스·포커스 시 같은 글자가 몇 겹 퍼지며 사라짐. 복제는 aria-hidden — 링크·버튼처럼 포커스되는 요소에 쓰면 키보드로도 보임
    zap—짧은 빛 조각이 테두리(둥근 모서리 포함)를 따라 달리는 방전 테두리. SVG 레이어, 모션 줄이기면 멈춘 점선
    fx.replay(el, [이름])—붙어 있는 효과(또는 그 이름만)를 처음부터 다시. 효과가 replay를 가지면 그것을, 아니면 같은 옵션으로 다시 적용. 이전에 받은 핸들도 계속 유효
    fx.pause() · fx.resume() · fx.paused()—페이지 전체 움직임 일시정지 — <html data-catui-paused>를 켜고 끔. 공용 티커·캔버스·CSS 애니메이션이 함께 멈춤
    fx.register(이름, fn, { slots }) · fx.unregister(이름)fn(el, o, kit) → { destroy() } 또는 null사용자 효과 추가. kit = { frame, onView, pointer, reduced }. 등록하면 fx.이름()과 data-catui-fx="이름"을 모두 쓰고, slots로 내장 효과와 같은 충돌 검사를 받음. 해제는 그 효과만 걷어 냄(내장 효과는 해제 불가)
    fx.names()—쓸 수 있는 효과 이름 목록 (등록한 효과 포함). fx.list(ul)은 차례 등장 효과입니다.
    catui:fx-conflict 이벤트—같은 자리를 쓰는 효과를 겹쳐 건너뛸 때 요소에서 발생. detail = { effect, with, slots }
    fx.bind(영역)—data-catui-fx="이름 이름"을 찾아 연결. 옵션은 data-catui-옵션으로도 줌(예: data-catui-speed="60" · data-catui-hover="true" · data-catui-interval="1500"). catui.init(영역)이 함께 처리하고, DOM에서 빠진 요소의 효과는 자동 정리됨. 이번에 연결한 것만 푸는 해제 함수를 돌려줌
    이전canvas 캔버스다음util 도구
