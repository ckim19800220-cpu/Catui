    site 홈페이지 도구

    헤더·현재 위치·공지 띠·쿠키 동의·카운트다운·요금 전환·라이트박스·구독·로고 흐름·읽기 막대·공유.

    헤더 · 모바일 메뉴 · 현재 위치

    실제 페이지에서는 헤더가 화면 위에 고정됩니다(예제는 position:static). 스크롤하면 그림자가 생기고, data-catui-header="hide"면 내릴 때 숨었다가 올리면 다시 보입니다(메뉴가 열렸거나 헤더 안에 포커스가 있으면 숨지 않음). 좁은 화면의 메뉴는 링크를 누르거나 바깥을 누르거나 Esc로 닫힙니다. data-catui-spy 내비게이션은 지금 보고 있는 섹션 링크에 aria-current="location"을 붙입니다 — 이 문서를 스크롤해 보세요.

    공지 띠 닫기 기억

    닫으면 브라우저에 기억해 다음 방문에도 보이지 않습니다. data-catui-days를 주면 그 기간이 지난 뒤 다시 보입니다. 이벤트 site.on('dismiss(키)').

    쿠키 동의

    선택을 저장하고 띠를 숨기며, 다음 방문에는 띠가 나오지 않습니다. 분석 스크립트는 site.consent()?.value === 'all'일 때만 불러오거나 catui:consent 창 이벤트를 받아 시작하세요.

    카운트다운

    안에 data-catui-unit="d|h|m|s" 칸이 있으면 그 칸만 채우고, 없으면 "2일 05:00:00"처럼 글자로 채웁니다. 숫자는 매초 읽지 않도록 숨기고, 화면 낭독용 이름은 분 단위로만 바꿉니다. 끝나면 data-catui-done 문구와 end(필터) 이벤트.

    요금 월간 · 연간 전환

    고른 주기에 맞춰 data-catui-monthly·data-catui-yearly 값으로 글자를 바꾸고, data-catui-billing-show 요소를 보이거나 숨깁니다. 이벤트 billing(필터) { value }.

    갤러리 라이트박스

    사진을 누르면 layer.photos로 크게 보고 ←→로 넘깁니다. 링크 그대로라 스크립트가 없어도 원본이 열리고, Ctrl·⌘·Shift+클릭은 새 탭 등 브라우저 기본 동작을 따릅니다.

    구독 폼

    form 모듈이 검증하고 보낸 뒤, 성공하면 폼을 완료 문구(.Catui_subscribe-done)로 바꾸고 그 문구로 포커스를 옮깁니다. 실패하면 토스트로 다시 시도를 안내합니다.

    로고 흐름

    한 벌을 복제해 끊김 없이 흐르고(복제는 화면 낭독기·키보드 제외), 마우스·포커스가 들어오면 멈춥니다. 5초 넘게 움직이므로 정지 버튼을 함께 둡니다. 모션 줄이기에서는 흐르지 않고 원래 배치 그대로입니다.

    읽기 진행 막대 · 공유

    이 문서 맨 위의 얇은 막대가 읽은 만큼 찹니다(data-catui-readbar에 본문 선택자, 비우면 문서 전체). 공유 버튼은 휴대폰 등에서는 기기 공유 창을, 지원하지 않으면 주소를 복사하고 알립니다.

    자주 쓰는 사용 예

    이미 불러온 분석 스크립트는 동의를 거두어도 그 페이지에서는 계속 돌므로, "쿠키 설정 다시 하기"(site.resetConsent()) 뒤에는 새로 고침을 안내하세요.

    API

    site API
    속성 · API설명
    .Catui_site-header[data-catui-header[="hide"]]스크롤 그림자(data-catui-scrolled) · hide면 내릴 때 숨김(data-catui-hidden) · 모바일 메뉴 바깥 클릭·링크·Esc로 닫기
    [data-catui-spy]안의 #섹션 링크 중 보고 있는 것에 aria-current="location"
    .Catui_announce[data-catui-dismiss="키"][data-catui-days]닫기 기억 · 이벤트 dismiss(키)
    .Catui_cookie[data-catui-cookie] + [data-catui-consent="all|necessary|…"]site.consent() → { value, at } | null · site.resetConsent() · 이벤트 consent · 창 이벤트 catui:consent
    [data-catui-countdown="날짜"][data-catui-done] · site.countdown.render({ elem, date, doneText, end })data-catui-unit="d|h|m|s" 칸 채우기 · 이벤트 end(f)
    [data-catui-billing] + data-catui-monthly/yearly · data-catui-billing-show · site.billing(영역, 값)요금 전환 · 이벤트 billing(f)
    [data-catui-lightbox]안의 a[href]를 layer.photos로
    form[data-catui-subscribe="완료 문구"]form 모듈 done이면 완료 문구로 교체
    .Catui_logos[data-catui-marquee="초"] · site.marquee.render({ elem, seconds })로고 흐름 + 정지 버튼
    .Catui_readbar[data-catui-readbar="선택자"] > i읽기 진행 (--Catui_read 0~1)
    [data-catui-share](+ -title · -text · -url) · site.share(버튼)Web Share → 주소 복사 · 이벤트 share { method, url }
