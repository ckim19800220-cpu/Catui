catui.js · 모듈

carousel 캐러셀

스크롤 스냅 캐러셀에 현재 표시·이전/다음·점·자동 넘김(정지 버튼)·키보드.

끊김 없는 순환 + 자동 넘김

마지막 장에서 다음으로 가면 처음으로 되감지 않고 이어서 1번이 나옵니다(양 끝에 복제 슬라이드를 두고, 복제에 닿으면 같은 그림인 진짜 위치로 순간 이동). 복제는 inert·aria-hidden이라 키보드·화면 낭독기에는 보이지 않습니다. 마우스를 올리거나 포커스가 들어오면 잠시 멈추고, 정지 버튼으로 끄면 다시 켤 때까지 멈춥니다. 모션 줄이기·숨은 탭에서는 넘기지 않습니다. 데스크톱은 마우스로 끌어서도 넘깁니다.

여러 장 보기 (반응형)

폭이 600px 이상이면 2장, 900px 이상이면 3장을 한 번에 보여 주고, 폭이 바뀌면 다시 배치합니다. 순환은 여러 장일 때도 끊김 없이 이어집니다.

페이드 전환

슬라이드를 한 칸에 겹치고 현재 장만 서서히 보입니다. 손가락·마우스로 좌우로 밀어도 넘어갑니다. 모션 줄이기에서는 전환 없이 바로 바뀝니다.

스크립트로 만들기

순환을 끄면 처음·끝에서 이전·다음 버튼이 잠깁니다.

세로 방향

위아래로 넘기고(↑↓ 키, 마우스 끌기, 손가락), 순환·여러 장·가운데 정렬도 가로와 똑같이 동작합니다. wheel을 켜면 휠 한 번에 한 장씩 넘기고, 순환이 꺼진 상태에서 끝에 닿으면 페이지 스크롤로 넘겨 줍니다.

미리보기(썸네일) · 내용 높이 맞추기

미리보기는 슬라이드의 첫 이미지(또는 data-catui-thumb)로 만들고, 현재 장을 테두리로 표시하며 자동으로 가운데로 스크롤합니다. autoHeight는 사진마다 높이가 다를 때 트랙 높이를 현재 장에 맞춥니다.

가운데 정렬 · 여러 장씩 이동

현재 장을 가운데 두고 양옆을 살짝 보여 줍니다(순환도 끊김 없음). 여러 장 보기에서 step: 2면 한 번에 두 장씩 넘깁니다.
