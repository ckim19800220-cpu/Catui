datePicker 날짜

날짜·기간 선택과 키보드 이동.

날짜 · 기간

입력 칸을 누르거나 ↓ 키로 엽니다. 달력에서 ↑↓←→(하루·한 주), PageUp/PageDown(한 달), Home/End(주의 처음·끝), Enter(선택), Esc(닫기). 범위 밖 날짜는 고를 수 없습니다.

옵션

datePicker 옵션
옵션설명
range · separator기간 선택 · 구분자(기본 ' ~ ')
min · max · disabled(date)'YYYY-MM-DD' 문자열 또는 Date로 정한 범위 · 막을 날짜
value · weekStart초깃값 · 주 시작(1=월)
shortcutstrue(기간: 최근 7일·최근 30일·이번 달·지난달) 또는 [{ text, value: () => Date | [Date, Date] }]. 허용 범위 밖이면 고르지 않음
키보드↑↓←→ 하루·한 주 · PageUp/PageDown 한 달(Shift와 함께면 한 해) · Home/End 주의 처음·끝 · Esc 닫기 · Tab으로 벗어나면 닫힘. 머리의 «» 버튼은 한 해 이동
done(value, date)선택 콜백 · 이벤트 done(f)
data-catui-date(="range") · data-catui-min/max선언형
