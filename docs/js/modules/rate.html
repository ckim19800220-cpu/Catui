    rate 별점

    radio 별점과 읽기 전용.

    별점

    radio 그룹이라 화살표 키로 고릅니다. 읽기 전용은 role="img"로 "5점 중 4점"만 읽힙니다.

    자주 쓰는 사용 예

    옵션

    rate 옵션
    옵션설명
    label · length · value · readonly이름 · 별 개수(기본 5) · 초깃값 · 읽기 전용
    text · texts[] · clearable점수 문구 표시 · 문구 목록 · 지우기 버튼
    choose(v)콜백 · 이벤트 choose(f) (마크업 .Catui_rating[data-catui-filter]도)
    inst.setValue(v) · inst.getValue() · rate.setValue(id, v) · rate.getValue(id)값 바꾸기·읽기 (0~length 범위로 맞춤)
    readonly + 소수 값3.6처럼 소수면 별은 반올림해 칠하고, 읽는 값은 "5점 중 3.6점"
