command 명령 팔레트

Ctrl/⌘+K로 여는 명령 검색 (그룹·단축키 표시·한글 초성 검색).

명령 팔레트

어디서든 Ctrl+K(Mac은 ⌘K)로 엽니다. 제목·키워드·그룹으로 찾고, 띄어쓰기는 무시하며, 한글 초성만 치거나(ㄷㅅㅂㄷ) 완성 글자와 섞어 쳐도(대ㅅ · ㄷ시) 찾습니다. ↑↓로 고르고(비활성 건너뜀) Enter로 실행, Esc·바깥 클릭으로 닫으면 포커스가 원래 자리로 돌아갑니다.
