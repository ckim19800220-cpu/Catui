catui.js · 모듈

autocomplete 자동완성

로컬·비동기 후보, 키보드 선택, combobox 접근성, 이전 요청 취소.

로컬 목록

↑↓로 고르고 Enter로 선택, Esc로 목록만 닫습니다(모달 안에서도 모달은 그대로). 맞는 부분은 굵게 보입니다. 한글은 조합 중에도 후보가 바뀌고, 조합 중 Enter는 선택하지 않습니다.

비동기 · 설명 붙은 항목

입력이 멈추면(delay) 요청하고, 새 글자를 치면 이전 요청은 signal로 취소하며 늦게 온 결과는 버립니다. 실패하면 목록 안에 다시 시도 안내를 보입니다.
