    catui.js모듈layer 팝업

    layer 팝업

    토스트·대화상자·드로어·iframe·말풍선·사진 보기·탭, 최대화·옮기기·크기 조절, Promise.

    메시지

    옵션: icon(success·info·warn·danger), body, time(ms, 0이면 수동), max(동시에 보일 개수, 기본 3). 영역은 aria-live="polite"로 읽힙니다.

    확인·입력·알림

    네이티브 <dialog>라 Esc 닫기·포커스 가두기·닫힌 뒤 포커스 복귀가 기본입니다. yes 콜백에서는 layer.close(index)로 직접 닫고(layui와 같음), false를 돌려주면 열린 채 둡니다.

    세로 탭 대화상자

    자주 쓰는 양식 (layer.form)

    await layer.form({ title, fields, submit })로 양식 대화상자를 만듭니다. 필수·형식·길이·범위 검사와 직접 검사(validate)를 하고, 오류는 칸 아래와 위쪽 요약에 함께 보이며 첫 오류 칸으로 포커스가 갑니다. 확인하면 값 객체, 취소하면 null을 돌려줍니다.

    관리 화면형 대화상자

    회색 머리·꼬리 띠, 회색 옆 패널의 세로 탭, 라벨이 왼쪽인 가로 양식, 테두리 카드형 탭으로 관리 화면에 맞춘 구성입니다.

    자주 쓰는 사용 예

    실무 화면에서 자주 만드는 흐름입니다. 서버 요청 자리는 setTimeout으로 흉내 냈으니 실제로는 await fetch(…)로 바꾸세요.

    옵션기본값설명
    type'dialog''dialog' · 'drawer' · 'iframe'
    title · content''내용: 문자열(글자) · html`` · Element
    btn[]버튼 글자 배열. 첫 버튼이 주 버튼(danger: true면 위험색)
    yes(index, dlg) · btn2 · cancel—버튼·닫기 콜백. yes가 있으면 그 안에서 layer.close(index)로 직접 닫음(layui와 같음). btn2·cancel은 false를 돌려주면 유지. 세 번째 버튼부터는 btn3·btn4…, 두 번째 버튼은 btn2가 없으면 cancel을 부름
    success(dlg, index) · end(index, reason)—열린 뒤 / 닫힌 뒤 (reason: 'yes'·'cancel'·'close'·'time')
    area'md''sm'·'md'·'lg'·'xl'·'full' 또는 ['너비', '높이']
    maxmin · move · resizefalse최대화 버튼 / 머리 끌어 옮기기 / 모서리 크기 조절
    time0ms 뒤 자동 닫힘 (end의 이유는 'time')
    type: 'drawer' + offset'r'드로어 방향 'l'·'r'·'b'
    type: 'iframe'—content에 주소 (같은 사이트·http·https만, javascript:·data: 차단)
    skin · full(index, on)—대화상자에 더할 클래스 / 최대화 전환 콜백
    msg: position · action · progress'br''tr'·'tc'·'bc'·'br' / { text, onClick } 동작 버튼(5초) / 남은 시간 막대
    msg: time · layer.msg(글, 옵션, end)3000보이는 시간(ms, 동작 버튼이 있으면 5000). end는 시간이 다 되거나 직접 닫을 때 호출 — 옵션 자리에 함수를 바로 넘겨도 됨
    shadeClose · closeBtntrue바깥 클릭으로 닫기 / 닫기 버튼

    함수: msg · alert · confirm · prompt · open · load · progress(index, %) · tips(내용, 대상, { side, time }) · photos({ items, start, change }) · tab({ tabs, start, change, vertical, card }) · form({ title, fields, submit, okText, layout: 'horizontal', labelWidth }) → Promise<값|null> (field: readonly·disabled·addon:{ icon, label, onClick }) · ask(내용) → Promise<boolean> · input(옵션) → Promise<값|null> · close(index) · closeAll(type) · closeLast(type) · title(index, 글자) · setContent(index, 내용) · style(index, { width, height }) · full(index) · restore(index) · getNode(index) · list(type) · count. type은 'msg'·'dialog'·'drawer'·'iframe'·'load'·'tips'·'photos'·'tab'·'form'.
