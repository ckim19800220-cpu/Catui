tree 트리

펼침·선택·체크 전파·키보드.

트리

접힘은 네이티브 <details>. 체크하면 자식에 전파되고, 일부만 체크된 부모는 indeterminate가 됩니다. 키보드: ↑↓ 이동, → 펼치기, ← 접기·부모로, Home/End.
