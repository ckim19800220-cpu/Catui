    tree 트리

    WAI-ARIA 트리: 펼침·선택·체크 전파·키보드.

    트리

    tree.render는 WAI-ARIA 트리 패턴(role="tree" · treeitem · group, aria-expanded·aria-selected·aria-level)으로 그립니다. 트리 전체가 Tab 정지점 하나이고, 안에서는 키보드로 움직입니다: ↑↓ 이동, → 펼치기·첫 자식으로, ← 접기·부모로, Home/End, Enter 선택, Space 체크(체크박스가 없으면 선택). 체크하면 자식에 전파되고, 일부만 체크된 부모는 aria-checked="mixed"(화면에는 indeterminate)가 됩니다. 막힌 항목(disabled)은 포커스는 받지만 선택·체크되지 않습니다. 스크립트 없이 쓰는 <details> 트리는 CSS 트리.
