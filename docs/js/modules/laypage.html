    laypage 페이지

    번호 묶음과 이동 콜백.

    페이지 이동

    현재 쪽을 가운데 둔 번호 묶음과 처음·끝 쪽 버튼을 두고, 사이가 비면 …을 보입니다. 처음 렌더할 때 jump가 first === true로 한 번 호출됩니다.

    총 건수 · 쪽 크기 · 바로 가기

    쪽 크기를 바꾸면 보던 첫 항목이 들어 있는 쪽으로 옮기고, 바로 가기는 1~끝 쪽 범위로 맞춥니다.

    자주 쓰는 사용 예

    옵션

    laypage 옵션
    옵션기본값설명
    count · limit · curr0 · 10 · 1전체 개수 · 쪽당 개수 · 현재 쪽
    groups5번호 버튼 개수
    jump(obj, first)—{ curr, limit, count, pages } · 이벤트 jump(f)
    label · alwaysShow'페이지' · falsenav 이름 · 한 쪽이어도 표시
    layout['prev','page','next']고른 순서대로: count 총 건수 · prev · page · next · limit 쪽 크기 고르기 · skip 쪽 번호 입력 후 이동
    limits[10, 20, 50, 100]limit 고르기 목록. 쪽 크기를 바꾸면 보던 첫 항목이 있는 쪽으로 이동하고 jump의 obj.limit에 새 값
