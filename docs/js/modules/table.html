    table 표

    정렬·선택·도구·페이지·원격 데이터·정적 표 향상.

    데이터 표

    정렬은 오름 → 내림 → 해제(aria-sort), 일부만 선택하면 머리 체크가 indeterminate 상태가 됩니다. templet이 돌려준 일반 문자열은 escape되고, 마크업은 catui.html``로 돌려줍니다.

    원격 데이터

    table.render({
  elem: '#t', id: 't', url: '/api/orders', method: 'GET', where: { status: '배송' }, page: true,
  parseData: function (res) { return { code: res.ok ? 0 : 1, msg: res.message, data: res.items, count: res.total }; },
  cols: [ … ],
});
// 요청: ?page=1&limit=10&field=amount&order=asc&status=배송
table.on('sort(t)', function (obj) { return true; });   // false면 기본 정렬 생략

    불러오는 동안 스켈레톤과 aria-busy를 보이고, 실패하면 오류 배너를 보이고, 새 요청이 오면 이전 요청은 취소합니다.

    table API
    이름설명
    cols[]field · title · sort · width · align('right') · type('checkbox'|'numbers') · templet(row, i) · toolbar[{event, text, icon, danger, showText}]
    data / url · method · where · headers · parseData로컬 / 원격
    page · limit · caption · initSort · text.none · labelField페이지·캡션·초기 정렬·빈 문구·도구 버튼 이름에 쓸 필드
    on('tool(f)'){ event, data, index, tr, del(), update(fields) }
    on('sort(f)') · on('checkbox(f)') · on('row(f)') · on('done(f)')정렬 / 선택 / 행 클릭 / 원격 로드 완료
    checkStatus(id) · getData(id) · reload(id, opts) · destroy(id)선택 상태 / 현재 행 데이터 / 다시 그리기 / 정리. reload로 where가 바뀌면 1쪽부터. 원격(url) 표는 새로 불러올 때마다(쪽 이동·정렬 포함) 선택이 비워짐
    exportFile(id, '파일.csv', { checked, rows })CSV 내보내기 — 로컬은 정렬된 전체, 원격은 현재 쪽. checked: true면 선택한 행만. 체크·동작 열 제외, 엑셀 한글 BOM, 수식 실행 방지(CSV 인젝션)
    clearChecked(id)선택 모두 해제
    table.bind()정적 표(table[data-catui-table])의 th[data-catui-sort] 정렬 버튼을 전역 위임으로 연결(="number"면 숫자 정렬, 이벤트 sort). catui.init이 자동으로 부르며 해제 함수를 돌려줍니다. 옛 이름 bindStatic()도 동작
    열 hide: true그 열을 표시·내보내기에서 뺌
    page: { layout, limits, limit, curr }페이지 바 설정을 laypage로 넘김 (예: layout: ['count','prev','page','next','limit']). 고른 쪽 크기는 원격 요청 limit에 반영
