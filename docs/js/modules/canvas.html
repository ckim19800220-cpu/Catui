    옵션 · 메서드

    canvas API
    이름설명
    ratio · label비율('16/9' 등, 빈 값이면 CSS 높이) · 그림 요약(aria-label)
    draw(ctx, s)s = { width, height, dpr, time, token, font, reduced } — 좌표는 CSS 픽셀, token('--Catui_…')로 현재 테마 색, font(크기, 굵기)로 페이지 글꼴
    animate · maxDpr매 프레임 그리기(모션 줄이기·숨은 탭에서 정지) · 선명도 상한(기본 2)
    inst.redraw() · canvas.redraw(id)다시 그리기 (데이터가 바뀌었을 때)
    inst.canvas · inst.ctx · inst.toBlob(cb, type)요소·컨텍스트 · 이미지 파일로 내보내기
    destroyResizeObserver·MutationObserver·rAF·이벤트를 모두 정리

    크기가 바뀌면(창 크기·사이드바 접기) 자동으로 해상도를 맞춰 다시 그리고, <html data-catui-theme>가 바뀌면 토큰 색으로 다시 그립니다.
