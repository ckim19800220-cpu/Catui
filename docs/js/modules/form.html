선언형 검증과 제출

제출하면 검증하고, 처음 틀린 칸에 포커스한 뒤 오류를 색 + 문장(aria-invalid, aria-describedby)으로 알립니다. 틀린 칸은 입력할 때마다 다시 검사합니다. 빈 값은 required만 검사합니다.

API

form API
API설명
data-catui-verify="required|email"내장: required · email · phone · url · number · date
data-catui-reqtext필수 오류 문구 바꾸기
data-catui-submit제출 버튼이 여러 개일 때 이 버튼만 처리
form.verify({ 이름: [정규식, 메시지] | fn(value, el) })규칙 추가 (fn은 오류 문장 또는 '' 반환)
form.on('submit(f)'){ field, form, elem }. false = 기본 제출 막기
form.on('switch|checkbox|radio|select(f)'){ elem, value, checked } — 필터는 컨트롤 또는 상위의 data-catui-filter
form.val(f, [값])값 읽기/쓰기 (같은 name은 배열)
form.validate(영역) · form.submit(f, [cb])직접 검증 / 프로그램 제출
form.render(영역) · form.setError(el, 문장)셀렉트 화살표 보충 / 오류 직접 표시
