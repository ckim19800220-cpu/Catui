    catui.js모듈tabs 탭

    tabs 탭

    WAI-ARIA 탭 생성, radio 탭 이벤트, 추가·닫기·전환.

    탭 이벤트와 추가·닫기

    마크업으로 쓴 radio 탭(CSS만으로 동작)에도 같은 API가 붙습니다. 화살표 키 이동은 radio 그룹 기본 동작입니다.

    tabs.render (WAI-ARIA 탭)

    tabs.render는 [role=tablist] > button[role=tab]과 [role=tabpanel]로 그립니다. 탭 묶음이 Tab 정지점 하나이고, ←→(세로 탭 vertical: true는 ↑↓)·Home·End로 옮기면 바로 그 탭이 열립니다. 패널은 Tab으로 들어갈 수 있습니다. 화면 낭독기가 묶음 이름을 읽도록 label을 꼭 주세요.

    자주 쓰는 사용 예

    tabs API
    API설명
    tabs.render({ elem, data: [{ title, content, id }], index, label, vertical })WAI-ARIA 탭 생성 (label 필수, 범위 밖 index는 처음·마지막으로)
    tabs.add(f, { title, content, change }) · close(f, i) · change(f, i)추가 / 닫기 / 전환
