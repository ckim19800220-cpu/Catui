    소개

    catui.js의 특징과 첫 예제.

    catui.js란

    catui.js는 Catui CSS 위에 얹는 의존성 없는 UI 프레임워크입니다. layui처럼 스크립트 한 줄로 쓰고, catui.use()로 모듈을 받아 모듈.render()·모듈.on('이벤트(필터)')로 다룹니다. 마크업에 data-catui-* 속성만 붙여도 자동으로 동작합니다.

    형식
    IIFE · ESM
    1. 선택 계층CSS만으로도 kit 마크업은 동작합니다. catui.js는 접근성(포커스·Esc)과 데이터 기능을 더합니다.
    2. 두 형식전역 dist/catui.js(window.catui)와 ESM dist/catui.esm.js.
    3. 안전한 기본값문자열은 글자로 들어가고(XSS 방지), 이벤트 등록은 해제 함수를 돌려줍니다.

    구성 계층

    아래 계층은 위 계층 없이도 동작합니다. 필요한 만큼만 불러옵니다.

    1. admin.css · catadmin.jscommunity.css · catcommunity.js관리자 · 커뮤니티 화면 확장
    2. catui.js접근성 · 데이터 · 선언형 속성 · 오버레이이 문서
    3. catui.css토큰 · 리셋 · 컴포넌트 — CSS만으로 동작
