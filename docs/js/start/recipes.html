모듈 조합 예제

주문 관리·검색 목록·가입 단계·대시보드 — 여러 모듈을 함께 쓰는 실전 예제.

주문 관리 — table + layer.form + confirm + msg

table의 tool 이벤트로 행 버튼을 받고, layer.form(Promise)으로 입력을 받아 obj.update()·table.reload()로 반영합니다. 토스트의 action으로 되돌리기를 제공합니다.

검색 조건 → 목록 — autocomplete + datePicker + form + table

입력은 autocomplete·datePicker가 돕고, 값은 form.val()로 한 번에 읽어 거른 뒤 table.reload()합니다. 원격 데이터라면 table.reload(id, { where: 값 })만 바꾸면 됩니다(1쪽부터 다시 요청).

가입 단계 — page.steps + form 검증 + field(otp·tags) + msg

page.steps의 before에서 form.validate(현재 패널)로 단계마다 검사하고, field.otp의 complete 이벤트로 다음 단계로 넘깁니다. 틀리면 setError()·clear()로 다시 입력받습니다.

대시보드 — tabs + canvas + dropdown + command

tabs의 tab 이벤트로 자료를 바꿔 canvas를 다시 그립니다. 차트 색은 s.token()으로 토큰을 읽어 다크 모드에서도 맞습니다. dropdown과 command가 같은 동작(exportCsv)을 공유합니다.

조합할 때 기억할 것

  • 필터 이름을 맞춘다 — 모듈.on('이벤트(필터)')의 필터는 id·data-catui-filter와 같아야 합니다.
  • Promise로 흐름을 잇는다 — layer.form·layer.ask·layer.input은 값(취소는 null·false)을 돌려줍니다.
  • 새로 그린 영역은 catui.init(영역) — Ajax로 넣은 마크업의 data-catui-*(날짜·태그·캐러셀…)를 연결합니다. 지운 영역의 인스턴스는 자동 정리됩니다.
  • 사용자 값은 글자로 — 문자열은 항상 escape되고, 마크업은 catui.html``로만 만듭니다.
