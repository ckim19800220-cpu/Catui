DOM과 템플릿

html · raw · escape · mount · $.

html · raw · escape

catui.html`<p>${name}</p>`          // { __raw } — 값은 escape
catui.html`<ul>${rows.map(r => catui.html`<li>${r}</li>`)}</ul>`   // 배열 이어 붙이기
catui.raw('<b>신뢰 마크업</b>')      // escape 없이
catui.escape('<b>')                    // '&lt;b&gt;'
catui.mount(el, catui.html`…`)          // html``은 마크업으로, 문자열은 글자로

$ — DOM 도우미

메서드: find · each · attr · addClass · removeClass · toggleClass · hasClass · text · html · on(type, [selector], fn). on은 해제 함수를 돌려주고, html()은 html``만 마크업으로 넣습니다. 선택자 위임은 버블링하지 않는 focus · blur · mouseenter · mouseleave도 캡처 단계로 받습니다. 요소 하나는 catui.el(선택자).
