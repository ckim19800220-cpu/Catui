    CatuiDocs는

    Catui(CSS 키트 + catui.js) 위에 얹는 문서·블로그 사이트 키트입니다. CatuiAdmin·CatuiCommunity·CatuiShop과 같은 구조로, 본체 컴포넌트(탭·코드 블록·콜아웃·쪽 번호·읽기 막대·공유)를 그대로 쓰고 문서 사이트에 필요한 것만 더합니다.

    catdocs.js

    catui.docs — 목차 자동 생성(스크롤 따라 현재 위치), 코드·제목 주소 복사, 초성 검색, 읽는 시간, 피드백 기억, 버전 이동, 태그 필터 ↔ 주소, 안전한 마크다운 일부

    templates/docskit/

    같은 머리·바닥글을 공유하는 전체 화면 HTML 12종 — 빌드가 링크·클래스·접근성을 검사

    저장소의 docs/는 이 문서 사이트의 출력 폴더이므로 키트의 소스·템플릿 폴더 이름은 docskit입니다. 배포 파일 이름과 JS 전역은 docs(docs.css · catdocs.js · catui.docs)입니다.

    접근성 · 반응형 기준

    • 현재 위치(메뉴·목차·태그 버튼)는 aria-current/aria-pressed + 막대·굵기·체크 아이콘으로 — 색만으로 알리지 않습니다. 변경 이력 종류는 배지 글자(추가·변경·고침)로.
    • 제목 앵커·쪽 이동 버튼의 뜻은 숨김 글자(.Catui_clip)나 aria-label(버튼·링크)로, 역할 없는 span에는 aria-label을 쓰지 않습니다(빌드가 검사).
    • 한글 조합 중 Enter는 검색을 제출하지 않고(catui.imeBusy), 입력하는 대로 찾는 검색은 조합이 끝난 뒤에 돕니다.
    • 320px 화면에서 쪽 가로 넘침 없음. 가로로 넘치는 상자(머리 메뉴·코드·표·태그 줄)는 position:relative 스크롤 상자이고 코드 블록은 Tab으로 들어가 밀 수 있습니다.
    • 모션은 앵커 나타남·카드 아이콘 확대·누름 피드백뿐이며 prefers-reduced-motion이면 끕니다.
