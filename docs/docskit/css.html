    규칙

    • 클래스는 Catui_dk-*, 토큰은 --Catui_dk-*(본체 토큰을 참조만). 새 색 값(hex)은 만들지 않습니다 — 빌드가 막습니다.
    • 본체 클래스에 스타일을 더할 때는 항상 .Catui_dk … 아래로 — docs.css를 불러와도 문서 사이트 밖은 바뀌지 않습니다. 코드 블록은 본체 .Catui_codeblock 위에 머리줄만 더합니다.
    • 현재 위치·눌림은 색 + 막대·굵기·체크 아이콘·aria-current/aria-pressed를 함께, 변경 이력 종류는 배지 글자로 — 색만으로 알리지 않습니다.
    • 반응형: 1199px 이하 오른쪽 목차를 본문 위로, 991px 이하 왼쪽 메뉴를 접는 상자로(한 단), 767px 이하 머리 메뉴를 둘째 줄 가로 스크롤 + 검색은 아이콘, 599px 이하 카드 한 열·이전/다음 세로.
    • 가로로 넘치는 상자(머리 메뉴·태그 줄·코드·표)는 position:relative 스크롤 상자이고, 본문은 word-break:keep-all + overflow-wrap:anywhere로 320px에서도 넘치지 않습니다.

    자주 쓰는 사용 예

    스크립트 없이 클래스만 쓴 정적 견본입니다. 토큰이 .Catui_dk 아래에 있으므로 셸 밖에서는 class="Catui_dk" 상자로 감쌉니다(data-catui-dk 속성 없이, 문서용으로 min-height만 풀었습니다). 같은 마크업을 스크립트로 만드는 방법은 catdocs.js API · 자주 쓰는 사용 예를 보세요.
