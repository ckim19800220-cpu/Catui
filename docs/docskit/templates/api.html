API 참조

catui.docs 함수

문서 사이트에서 자주 쓰는 세 함수의 시그니처·매개변수·반환 값·예제입니다. 모든 글자는 이스케이프해서 그립니다.

docs.toc()

본문의 h2·h3를 모아 목차 링크를 만들고, 스크롤하면 지나간 마지막 제목에 aria-current="location"을 붙입니다.

docs.toc(article, box?, { levels?, title? }) → { items, el }

매개변수

docs.toc 매개변수
이름형식기본값설명
articleElement | string—제목을 찾을 본문
boxElement | string없음목차를 그릴 상자. 없으면 id·앵커만 붙임
levelsstring"h2, h3"목차에 넣을 제목 선택자
titlestring"이 쪽에서"목차 제목 겸 nav 이름

반환

{ items: [{ id, text, level, el }], el } — 제목이 없으면 상자를 숨깁니다.

예제

catui.docs.toc('#article', '#toc', { levels: 'h2, h3' });
<aside id="toc"></aside>
<article data-catui-dk-toc="#toc"> … </article>

docs.search.find()

색인 JSON에서 검색어를 찾습니다. 본체 명령 팔레트와 같은 규칙으로 띄어쓰기·대소문자를 무시하고 한글 초성으로도 찾습니다.

docs.search.find(index, q, limit = 30) → Array<item & { score }>

매개변수

docs.search.find 매개변수
이름형식설명
index{ t, u, s?, x?, k? }[]제목·주소·분류·요약·키워드
qstring검색어 (예: 목차, ㅁㅊ, 다크모드)
limitnumber최대 결과 수 (rules.searchLimit)

반환

점수 순 배열 — 제목 그대로 4 · 제목 초성 3 · 키워드 2 · 요약 1.

예제

const index = await catui.docs.search.load();
catui.docs.search.find(index, 'ㅁㅊ');   // → [{ t: '목차 자동 생성', score: 3, … }]
<script type="application/json" data-catui-dk-index>
[{ "t": "목차 자동 생성", "u": "api.html#toc", "s": "API" }]
</script>

docs.readTime()

읽는 시간을 계산합니다. 분 = 올림(한글 음절 수 ÷ 500 + 그 밖의 단어 수 ÷ 200), 최소 1분이며 요소를 넘기면 코드 블록은 세지 않습니다.

docs.readTime(text | element) → { minutes, ko, words, label }

반환

docs.readTime 반환 값
속성뜻
minutes올림한 분 (1 이상)
ko · words센 한글 음절 수 · 단어 수
label"3분" — 화면에는 "3분 읽기"

예제

catui.docs.readTime('가'.repeat(1200)).label;   // '3분'
catui.docs.rules.readKo = 600;                     // 사이트 기준 바꾸기
<span data-catui-dk-readtime="#article"></span>   → "3분 읽기"
