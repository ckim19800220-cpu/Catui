버전 v2.1

마이그레이션 가이드

버전을 고르면 그 버전의 문서 주소로 이동합니다. 옛 버전을 보고 있으면 맨 위에 안내가 나옵니다.

옛 버전 문서를 보고 있습니다. 최신 내용은 v2.1 문서를 보세요.

2.0에서 2.1로

깨지는 변경은 없습니다. 확장 키트(CatuiAdmin·CatuiCommunity·CatuiShop·CatuiDocs)가 더해졌고, catui.imeBusy가 공개되었습니다.

올리는 순서

  • npm install @imcat-ckim/catui@2.1로 올립니다.
  • 확장을 쓸 때만 dist/docs.css·catdocs.js를 더 불러옵니다.
npm install @imcat-ckim/catui@2.1

1.x에서 2.0으로

클래스 접두가 Catui_로 통일되었습니다. 옛 이름은 찾아 바꾸기로 옮깁니다.

1.x → 2.0 이름 바꿈
1.x2.0
.cu-btn.Catui_btn
cu.layercatui.layer
