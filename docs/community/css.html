    규칙

    • 클래스는 Catui_cm-*, 토큰은 --Catui_cm-*(본체 토큰을 참조만). 새 색 값은 만들지 않습니다.
    • 본체 클래스에 스타일을 더할 때는 항상 .Catui_cm … 아래로 — community.css를 불러와도 커뮤니티 밖은 바뀌지 않습니다.
    • 강조(인기·추천·새 글)는 색 + 글자·숫자·아이콘을 함께 — 색만으로 알리지 않습니다.
    • 반응형: 991px 이하 옆줄을 본문 아래로, 767px 이하 게시판 메뉴 가로 스크롤 + 하단 탭.

    자주 쓰는 사용 예

    스크립트 없이 클래스만 쓴 정적 견본입니다. 행 간격·강조색 같은 토큰과 링크 색 규칙이 .Catui_cm 아래에 있으므로 셸 밖에서는 class="Catui_cm" 상자로 감쌉니다(data-catui-cm 속성 없이, 문서용으로 min-height만 풀었습니다). 같은 마크업을 스크립트로 만드는 방법은 catcommunity.js API · 자주 쓰는 사용 예를 보세요. 글 링크는 템플릿 쪽으로 이어집니다.

    인기 글(Catui_cm-hot)은 제목 굵기 + 강조색 점수 + 숨김 글자 "인기 글"로, 읽은 글(Catui_cm-read)은 흐린 제목 + "(읽음)"으로 — 색만으로 알리지 않습니다. 점수 칸은 Catui_cm-score-n(두 줄) 또는 Catui_cm-up(화살표 한 줄, Catui_cm-up-hot은 강조) 중 하나를 씁니다.

    1~3 회색, 4~6 파랑, 7~9 브랜드색 — 숫자가 항상 함께 보입니다. data-lv는 9까지(그 이상은 9로).

    눌린 추천은 [data-dir="up"][aria-pressed="true"]에 강조색 테두리·바탕, 비추천은 파랑입니다. 실제로 누르고 기억하는 동작은 data-catui-cm-vote가 붙은 상자에서 스크립트가 맡습니다(이 견본은 정적이라 누름 상태가 바뀌지 않습니다).

    끝난 핫딜은 [data-ended]로 제목에 취소선 + "종료" 글자 — 실제 화면에서는 [data-catui-cm-until] 시간이 지나면 스크립트가 붙입니다.
