    catui.community

    catcommunity.js가 catui.extend({ community })로 등록하고, 문서가 준비되면 [data-catui-cm] 루트를 찾아 연결합니다.

    catui.community API
    API설명
    init(scope?) · destroy() · ready연결 · 정리 · 바인딩이 끝나면 풀리는 Promise
    on(이벤트, fn)theme · vote { key, dir } · comment { item, parent } · draft · poll { name, choice } · data
    load()boards·posts·users를 합쳐 { boards, B, posts, users, U, byId } — 인기 글·레벨 계산 포함, 한 번만
    row(post, { board, rank }) · empty(text) · badge(user)목록 한 줄 · 빈 목록 · 레벨 배지 마크업 (글자는 모두 이스케이프)
    [data-catui-cm-list="list|card|gallery|deal|qna|hot"]게시판 목록: 주소 ?b=&cat=&sort=&page= ↔ 화면, 뒤로 가기 지원
    [data-catui-cm-vote="post:id"] · voteRequest추천/비추천 한 번(기억)·취소·바꾸기, 낙관적 갱신 후 실패 시 되돌림. 실서비스는 voteRequest = (key, dir) => fetch(…)
    [data-catui-cm-comments="파일"]댓글 트리·베스트·정렬·답글 펼침·쓰기(Ctrl+Enter, 한글 조합 중 무시)·신고
    form[data-catui-cm-editor] · md(text)글쓰기: 말머리 연동·서식 버튼·안전 미리보기·사진 미리보기·임시 저장·떠날 때 확인
    form[data-catui-cm-poll] · [data-catui-cm-until] · [data-catui-cm-ago]투표(한 번·비율 계산) · 핫딜 남은 시간 · 상대 시간 (1분마다)
    [data-catui-cm-top] · [data-catui-cm-fav="게시판"]맨 위로(600px 넘게 내리면 보임) · 즐겨찾기 토글(기억, aria-pressed)
    [data-catui-cm-score]추천 상자 안에서 추천 − 비추천 점수를 표시
    [data-catui-cm-saved] · [data-catui-cm-preview] · [data-catui-cm-pics]글쓰기 폼 안: 임시 저장 상태 · 미리보기 · 사진 미리보기 자리
    <html data-catui-cm-now="ISO">모의 데이터의 "지금" 고정(상대 시간·새 글·남은 시간 계산 기준). 없으면 실제 시각
    .Catui_cm[data-catui-cm-wide]옆줄 없이 본문 한 단
    fav · read · store · josa(단어, '을')즐겨찾기 게시판 · 읽은 글 · 저장소(localStorage "catui:community") · 조사
    data(name) · bind() · derive · format(v, 형식) · ago(iso)JSON 모의 데이터 (CatuiAdmin과 같은 API)

    자주 쓰는 사용 예

    목록·위젯·글 화면에서 자주 쓰는 조합입니다. 자료는 모두 예제 안의 배열이고, 시간은 "지금"에서 몇 분 전처럼 계산해 넣었습니다. 커뮤니티 토큰이 .Catui_cm에 정의되므로 예제는 class="Catui_cm" 상자로 감쌌습니다 — data-catui-cm 속성은 넣지 않아 셸 동작은 켜지지 않습니다(문서용으로 min-height만 풀었습니다).

    글 링크(post.html?id=…)는 템플릿 기준 주소라 이 문서에서는 누르면 안내만 띄웁니다.

    같은 버튼을 다시 누르면 취소, 반대 버튼을 누르면 바꾸기입니다. 고른 값은 catui:community 저장소의 votes에 기억되어 새로 고쳐도 눌린 상태로 보입니다.
