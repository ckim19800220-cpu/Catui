    CatuiCommunity는

    Catui(CSS 키트 + catui.js) 위에 얹는 커뮤니티(게시판) 확장입니다. CatuiAdmin과 같은 구조로, 본체 컴포넌트를 그대로 쓰고 게시판에 필요한 것만 더합니다.

    community.css

    사이트 머리·게시판 메뉴·2단 배치·하단 탭, 글 목록(한 줄·카드·갤러리·핫딜·질문), 글 보기·댓글 — 모든 규칙은 .Catui_cm 아래, 토큰만 사용

    catcommunity.js

    catui.community — 목록(주소 동기화)·추천/비추천·댓글 트리·글쓰기(임시 저장)·투표·핫딜 남은 시간·JSON 모의 데이터 바인딩

    templates/community/

    같은 머리·메뉴를 공유하는 전체 화면 HTML 24종 — 빌드가 링크·클래스·접근성을 검사

    구성은 국내 대형 커뮤니티(fmkorea)의 인기 글 올림·추천/비추천·베스트 댓글·회원 레벨·즐겨찾기 게시판 방식을 참고했고, 브랜드·문구·이미지는 쓰지 않았습니다. 모의 글·닉네임은 모두 가상입니다.

    구성 계층

    1. community.css · catcommunity.js게시판 셸 · 목록 · 글 보기 · 댓글이 문서
    2. catui.js접근성 · 데이터 · 선언형 속성 · 오버레이
    3. catui.css토큰 · 리셋 · 컴포넌트

    커뮤니티 규칙

    모든 값은 모의 데이터(templates/community/data/*.json)에서 계산합니다.

    인기 글
    추천 − 비추천 ≥ hotCut게시판 기준값은 boards.json의 hotCut. 공지·이벤트 말머리는 제외
    회원 레벨
    글 × 10 + 댓글 × 2 + 받은 추천 → 1~9활동 점수 구간으로 나눕니다
    베스트 댓글
    추천 ≥ 10 → 상위 3개댓글 맨 위에 한 번 더 보입니다
    추천 · 투표
    글마다 1회다시 누르면 취소, 이 브라우저에 기억

    국내 커뮤니티 자료와 디자인 보완

    2025~2026년 공개된 국내 서비스 발표·사례를 참고했습니다. 아래 적용은 CatuiCommunity의 설계 가설이며, 서비스의 성과 수치를 이 견본의 효과로 간주하지 않습니다.

    자료의 관찰과 견본에 적용한 범위
    자료관찰적용
    네이버 라운지 공식 발표
    2026.01.28    		주제별 게시판과 가벼운 참여를 통한 관심사 중심 탐색홈 상단의 게시판 바로가기, 글 옆 게시판명, 즐겨찾는 게시판의 최신 글 모아보기
    DAN25: 네이버 카페 경험 설계
    2025.11.07    		오래된 서비스의 익숙한 사용성을 유지하면서 경험 개선기존 목록·사진·질문 화면은 유지하고 24시간·주간·최신·즐겨찾기 선택을 제공
    kt nasmedia: 당근 카페 분석
    2026.01.21    		만남 중심 모임과 정보가 축적되는 게시글형 커뮤니티의 목적 구분단문 피드로 일괄 전환하지 않고 목록·갤러리·질문 등 콘텐츠별 형식을 구분
    • 홈의 모아보기는 ?feed=1|7|new|fav로 공유할 수 있고 마지막 선택은 이 브라우저에 기억합니다. 인기글은 해당 기간의 글만 표시하며 수가 적어도 오래된 글로 채우지 않습니다.
    • 모바일 게시판 제목은 최대 두 줄로 표시하고 말머리를 유지합니다. 말머리·정렬·페이지를 바꾸면 선택한 제어에 키보드 포커스가 유지됩니다.
    • 추천은 기존 점수 기준이며 AI 개인화가 아닙니다. 실시간 채팅·운영 정책·신고 처리의 실제 서버 구현이나 사용자 실험 효과를 보장하지 않습니다.
