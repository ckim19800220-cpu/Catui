사이트 셸

<div class="Catui_site Catui_cm" data-catui-cm>
  <header class="Catui_cm-head"> 로고 · 검색(form[data-catui-cm-search] → search.html?q=) · 글쓰기 · 알림 · 테마([data-catui-cm-theme]) · 내 정보
    <nav class="Catui_cm-gnb"> 게시판 메뉴 (767px 이하 가로 스크롤) + 더보기
  <div class="Catui_cm-wrap"> <main class="Catui_cm-main"> … </main> <aside class="Catui_cm-aside" data-catui-cm-aside>(인기 순위·즐겨찾기·공지)
  <footer class="Catui_cm-foot">
  <nav class="Catui_cm-tabs"> 767px 이하 하단 탭(홈·인기·글쓰기·알림·내 정보)
</div>

템플릿 · 메뉴

  • templates/community/pages/이름.html — 머리 주석 <!-- title: 핫딜 | nav: hotdeal | aside: none | layout: blank -->. nav는 상단 메뉴·하단 탭에서 현재 위치로 표시할 id, aside: none은 옆줄 없이 넓게.
  • templates/community/menu.json — gnb(상단 게시판), more(더보기), tabs(하단 탭). 아직 없는 화면은 메뉴에서 빠집니다.
  • npm run build → docs/community/templates/. 검사: 정의 안 된 클래스·없는 아이콘·id 중복·label·화면 링크·h1·안 쓰인 클래스·JSON 문법, CSS의 hex·없는 토큰·본체 클래스 재정의.

JSON 모의 데이터

templates/community/data/*.json → docs/community/templates/data/. 실서비스는 같은 모양의 API를 만들고 catui.community.dataBase = '/api/'만 바꿉니다.
