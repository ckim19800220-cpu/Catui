    CatuiCommunity시작모션 기준

    모션 기준

    어디에 움직임을 넣고 어디서 뺐는지, 수치와 이유.

    기준

    React Bits 에이전트 스킬(find-animation-opportunities · improve-animations · review-animations · apple-design, 원본 Emil Kowalski MIT)의 규칙을 따랐습니다. React 코드는 가져오지 않고 수치와 원칙만 Catui CSS로 새로 썼습니다.

    • 움직임은 이유가 있을 때만: 피드백 · 상태 변화 · 갑작스러운 변화 막기
    • 자주 보는 곳일수록 덜 움직인다 — 하루 수십 번 보는 목록·키보드 동작은 움직이지 않음
    • 들어오고 나가는 것은 ease-out, UI는 300ms 미만, transform·opacity만, 모션 줄이기면 즉시

    토큰

    모션 토큰
    토큰값쓰는 곳
    --Catui_cm-ease-outcubic-bezier(0.23, 1, 0.32, 1)모든 UI 전환
    --Catui_cm-dur-press · --Catui_cm-press160ms · 0.97누름 피드백
    --Catui_cm-dur-ui200ms추천 수 변화, 펼침 아이콘
    --Catui_cm-dur-expand250ms답글 펼침(높이)

    모션 적용 목록
    곳결정이유
    추천·비추천, 글쓰기 버튼, 하단 탭누를 때 scale(0.97) 160ms피드백 — 버튼이 눌렸음을 시각적으로 알림
    추천 수바뀔 때 아래에서 6px 올라오며 200ms피드백 — 숫자가 바뀐 것을 알림 (처음 그릴 때는 움직이지 않음)
    답글 펼치기높이 0 → 내용 250ms, 다시 누르면 그 자리에서 되돌아감상태 변화 — 내용이 갑자기 나타나지 않게
    글 목록 등장뺌하루 수십 번 보는 화면 — 스태거가 느려 보임
    검색·키보드 이동·페이지 이동뺌키보드·고빈도 동작
    조회 수·추천 같은 데이터 숫자뺌(바뀔 때 제외)읽는 데이터는 장식하지 않음
    맨 위로부드럽게 스크롤, 모션 줄이기면 즉시위치 이동을 보여 줌
