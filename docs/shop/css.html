    규칙

    • 클래스는 Catui_sh-*, 토큰은 --Catui_sh-*(본체 토큰을 참조만). 새 색 값(hex)은 만들지 않습니다 — 빌드가 막습니다.
    • 본체 클래스에 스타일을 더할 때는 항상 .Catui_sh … 아래로 — shop.css를 불러와도 쇼핑몰 밖은 바뀌지 않습니다.
    • 할인율·품절·남은 재고·무료배송은 색 + 글자를 함께 — 색만으로 알리지 않습니다. 숫자 배지는 숨김 글자(.Catui_clip)로 뜻을 보충합니다.
    • 반응형: 991px 이하 필터·주문 요약·마이페이지 메뉴를 위로/아래로, 767px 이하 하단 탭 + 상세 한 단, 599px 이하 장바구니 줄 2단, 399px 이하(320px 포함) 머리·카드 여백 축소.
    • 가로로 넘치는 상자(카테고리 메뉴·칩·작은 사진·표)는 position:relative 스크롤 상자입니다.

    --Catui_sh-sale · --Catui_sh-price할인율(--Catui_color-danger, 늘 “%”·숨김 글자 “할인”과 함께) · 판매가
    --Catui_sh-accent · --Catui_sh-accent-soft · --Catui_sh-warn혜택·선택 강조(--Catui_color-brand-strong) · 바탕 · 남은 재고 적음(--Catui_color-orange)
    --Catui_sh-ease-out · --Catui_sh-dur-* · --Catui_sh-press누름 피드백 160ms · 작은 변화 200ms · 누를 때 0.97배

    자주 쓰는 사용 예

    스크립트 없이 클래스만 쓴 정적 견본입니다. 토큰이 .Catui_sh 아래에 있으므로 셸 밖에서는 class="Catui_sh" 상자로 감쌉니다(data-catui-sh 속성 없이, 문서용으로 min-height만 풀었습니다). 같은 마크업을 스크립트로 만드는 방법은 catshop.js API · 자주 쓰는 사용 예를 보세요.
