    사이트 셸

    <html lang="ko" data-catui-sh-now="2026-11-02T10:00:00+09:00">   ← 모의 데이터 "지금"(없으면 실제 시각)
<div class="Catui_site Catui_sh" data-catui-sh>
  <header class="Catui_sh-head"> 로고(.Catui_logo) · 검색(form[data-catui-sh-search] → search.html?q=) · 찜 · 장바구니([data-catui-sh-cart-count]) · 테마([data-catui-sh-theme]) · 마이
    <nav class="Catui_sh-gnb"> 카테고리 메뉴 — 본체 .Catui_hnav.Catui_hnav-line.Catui_hnav-scroll (좁으면 가로 스크롤)
  <main class="Catui_sh-main"> … </main>
  <footer class="Catui_sh-foot"> 사업자 정보 · 고객센터
  <nav class="Catui_sh-tabs"> 767px 이하 하단 탭(홈·카테고리·검색·장바구니·마이)
</div>

    테마는 커뮤니티와 같은 규칙(저장값이 없으면 시스템)이고, <html data-catui-theme-lock>이 있으면 건드리지 않습니다(이 문서 사이트가 그렇습니다).

    템플릿 · 메뉴

    • templates/shop/pages/이름.html — 머리 주석 <!-- title: 주문 내역 | nav: my | my: orders | layout: blank -->. nav는 상단 메뉴·하단 탭의 현재 위치, my는 마이페이지 옆 메뉴({{mynav}} 자리)의 현재 위치입니다.
    • templates/shop/menu.json — gnb(카테고리), tabs(하단 탭, count: true면 장바구니 배지), my(마이페이지 메뉴). 없는 화면은 메뉴에서 빠집니다.
    • npm run build → docs/shop/templates/. 검사: 정의 안 된 클래스·없는 아이콘·id 중복·label·화면 링크·h1·안 쓰인 클래스·역할 없는 span의 aria-label·JSON 문법, CSS의 hex·없는 토큰·본체 클래스 재정의.

    JSON 모의 데이터

    templates/shop/data/*.json → docs/shop/templates/data/. 실서비스는 같은 모양의 API를 만들고 catui.shop.dataBase = '/api/'만 바꿉니다. 화면에 보이는 할인가·별점 평균·품절·적립금 잔액은 저장하지 않고 원자료에서 계산합니다(shop.enrich).

    데이터 파일
    파일내용 · 계산
    products.json상품 24개 — 정가·할인율·옵션(색상·사이즈·추가금)·조합별 재고·배송 종류. 판매가·품절·베스트(판매 수 상위 6)·신상품(14일)은 계산
    categories.json · promos.json분류 8개(아이콘) · 기획전(마감 시각·묶음 상품)
    reviews.json · qna.json리뷰 → 상품별 별점 평균·리뷰 수·분포 · 상품 문의(비밀글·답변)
    coupons.json정률(최대 할인)·정액·배송비 쿠폰, 최소 주문 금액·분류 제한·만료 시각
    user.json회원·배송지·적립 내역(잔액 = 합) · 처음 여는 브라우저에 채울 장바구니·찜·최근 본 상품
    orders.json주문 5건 — 상태·결제 수단·택배 이동 기록. 결제 금액은 상품 × 수량 + 배송비 − 쿠폰 − 적립금으로 계산

    기억하는 상태

    모두 catui.data('shop')(localStorage "catui:shop") 한 곳에 있습니다: cart · wish · recent · now(바로 구매) · lastOrder · orders · view(바둑판/목록) · helped(도움돼요) · theme. 다른 탭에서 바뀌면 장바구니 배지와 장바구니 화면이 따라 바뀝니다(storage 이벤트).
