    CatuiShop은

    Catui(CSS 키트 + catui.js) 위에 얹는 한국형 쇼핑몰 앞단(스토어프런트) 확장입니다. CatuiAdmin·CatuiCommunity와 같은 구조로, 본체 컴포넌트(캐러셀·견본·수량·단계·옵션 카드·쪽 번호)를 그대로 쓰고 쇼핑에 필요한 것만 더합니다.

    접근성 · 반응형 기준

    • 할인율·품절·남은 재고·무료배송은 색 + 글자로 함께 알립니다(“30% 할인”, “품절”, “3개 남음”). 품절 색상 견본은 빗금 무늬 + 숨김 글자 “(품절)”.
    • 장바구니 배지는 숫자 뒤에 숨김 글자(“개 담김”)를 붙이고, 역할 없는 span에는 aria-label을 쓰지 않습니다(빌드가 검사).
    • 수량·옵션·장바구니를 다시 그려도 포커스는 같은 자리로 돌아오고, 경계에서 잠긴 버튼 대신 반대 버튼으로 옮겨 갑니다.
    • 320px 화면에서 가로 넘침 없음(상품 2열, 장바구니 줄 2단), 가로로 넘치는 줄(카테고리·칩·작은 사진)은 position:relative 스크롤 상자입니다.
    • 모션은 누름 피드백·사진 확대·구매 막대 올라오기뿐이며 prefers-reduced-motion이면 끕니다.
