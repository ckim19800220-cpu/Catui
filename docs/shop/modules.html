    price · cart · picker · wish · recent · coupon · order · 선언형 속성.

    catui.shop

    catshop.js가 catui.extend({ shop })로 등록하고, 문서가 준비되면 [data-catui-sh] 루트를 찾아 연결합니다. 루트가 없는 화면(이 문서처럼)에서는 데이터를 읽지 않으므로, 금액 계산·카드·옵션 고르기 같은 함수는 직접 넘긴 자료로 씁니다. 전체 타입은 dist/catshop.d.ts.

    catui.shop API

    stock(p, 색, 사이즈) · stockTotal(p) · optionState(p, 색) · optLabel · extra · optReady조합 재고(없는 조합 0) · 합계 · 색상별·사이즈별 남은 수와 품절·적음 · “블랙 / M” · 옵션 추가금 · 옵션을 다 골랐는지

    선언형 속성

    data-catui-sh 속성
    속성동작
    [data-catui-sh] · <html data-catui-sh-now>화면 루트(이 안의 속성을 연결) · 모의 데이터 기준 시각
    [data-catui-sh-add-cart="상품"] (+ data-color · data-size · data-qty)장바구니 담기(재고까지). 옵션이 필요한데 없으면 상세 화면으로 안내
    [data-catui-sh-wish="상품"]찜 토글, aria-pressed 기억
    [data-catui-sh-cart-count]담긴 줄 수 + 숨김 글자 “개 담김”, 0이면 숨김
    [data-catui-sh-products="best|new|sale|cat:food|ids:a,b|related:{id}"]상품 묶음(data-size, data-rank면 순위)
    [data-catui-sh-cats] · [data-catui-sh-promos]카테고리 바로가기 · 기획전 카드
    [data-catui-sh-list="list|search"]목록·검색: 주소 ?c=&q=&sort=&price=&free=&today=&instock=&brand=&page= ↔ 화면, 뒤로 가기
    [data-catui-sh-product] · [data-catui-sh-cart] · form[data-catui-sh-checkout] · [data-catui-sh-complete]상세 · 장바구니 · 주문서 · 주문 완료
    [data-catui-sh-my] · -orders · -track · -wishlist · -recent · -coupons · -points · form[-profile] · form[-review]마이페이지 화면들
    [data-catui-sh-until="ISO"] · [data-catui-sh-won="12900"] · [data-catui-sh-top] · [data-catui-sh-theme] · form[data-catui-sh-search]남은 시간(1초마다) · 금액 글자 · 맨 위로 · 테마 · 머리 검색(빈 값 막음)

    자주 쓰는 사용 예

    자료는 모두 예제 안의 배열입니다. 쇼핑몰 토큰이 .Catui_sh에 정의되므로 예제는 class="Catui_sh" 상자로 감쌌습니다 — data-catui-sh 속성은 넣지 않아 셸 동작은 켜지지 않습니다(문서용으로 min-height만 풀었습니다). 상품 링크는 템플릿 기준 주소라 이 문서에서는 누르면 안내만 띄웁니다.

    판매가(20,300원)·할인율·BEST(판매 수 상위)·NEW(14일 이내)·별점 평균·품절 띠·쿠폰 태그는 모두 원자료에서 계산했습니다. 품절 상품에는 담기 버튼이 없습니다.

    화이트는 모든 사이즈 재고가 0이라 빗금 견본 + “(품절)”로 고를 수 없습니다. 블랙을 고르면 L은 “품절”, S·XL은 “N개 남음”, XL은 “+2,000원”이 글자로 붙습니다. 수량은 그 조합의 재고까지만 늘어납니다.

    이벤트 · 실서비스 연결

    catui.shop.on('cart', ({ lines }) => fetch('/api/cart', { method: 'PUT', body: JSON.stringify(lines) }));
catui.shop.on('order', ({ order }) => analytics.purchase(order.total));
catui.shop.rules.freeOver = 50000;        // 무료배송 기준 바꾸기
catui.shop.dataBase = '/api/shop/';      // 같은 모양의 JSON API

    결제는 예제에서 실제로 하지 않습니다. 주문서의 submit은 주문 객체를 만들어 기억한 뒤 완료 화면으로 넘어가므로, 실서비스에서는 이 자리에서 PG 결제창을 띄우고 성공 응답 뒤에 이동하면 됩니다.
