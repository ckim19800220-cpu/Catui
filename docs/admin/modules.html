    catadmin.js API

    shell · theme · notify · widgets · form · list · chat · kanban · auth.

    catui.admin

    catadmin.js가 catui.extend({ admin })로 등록합니다. 셸이 있으면 자동으로 연결되고, 없어도(로그인 화면 등) 테마·위젯·폼 보조는 동작합니다.

    catui.admin API
    API설명
    admin.init(scope?) · admin.destroy()연결 · 모든 리스너·차트·팝업 정리 (SPA 화면 전환 시)
    admin.on(이벤트, fn)theme { value, saved } · data { name, data, box } · collapse { collapsed } · drawer { open } · notify { unread } · dirty { form, dirty } · chat { text } · kanban { card, from, to }
    admin.store.get(k) · set(k, v) · clear()기억한 상태 (localStorage "catui:admin")
    admin.shell.collapse(bool) · open() · close()사이드바 접기(992px↑, 기억) · 서랍 열기/닫기(991px↓, Esc·가림막·Tab 가두기·포커스 복귀)
    admin.theme.set('light'|'dark'|'system') · get() · saved()테마 (저장값이 없으면 시스템 설정을 따름) · 버튼 [data-catui-adm-theme]. 다른 쪽이 테마를 관리하는 화면(예: 문서 사이트)은 <html data-catui-theme-lock>로 덮어쓰기를 막습니다
    admin.notify.add({ text, who?, icon? }) · markRead(id) · markAll() · count()상단 바 알림 패널·배지 · 데이터 #adm-notify-data
    admin.widgets.chart(el, { type, labels, series | data, label }) · update(el, data)캔버스 차트 area·line·bar·donut·spark — 토큰 색, 다크 전환 재그림, 화면 낭독기 요약
    admin.form.saved(form) · isDirty(form)form[data-catui-adm-form] 변경 감지 · 떠날 때 확인 · 저장 바 [data-catui-adm-savebar]
    admin.list({ table, form, data, match, bulkbar, change })필터 폼 ↔ 주소 동기화, 로컬 거르기, 일괄 작업 바 — 반환 { apply, values, rows, reset }
    admin.split(el) · admin.chat({ log, form, me }) · admin.kanban(el)목록↔본문 2단(767px↓ 한 단) · 채팅(한글 조합 Enter 무시) · 칸반(끌기 + ←→↑↓)
    admin.auth.score(비밀번호)0~4 강도 — 선언형 [data-catui-adm-pwtoggle] · [data-catui-adm-caps] · [data-catui-adm-strength]

    선언형 속성

    CatuiAdmin 선언형 속성
    속성설명
    data-catui-adm-count · data-catui-adm-ago="ISO"보이면 0부터 세어 올라감(쉼표·소수·앞뒤 글자 유지) · "5분 전" 형식, 1분마다 갱신
    data-catui-adm-chart="area|line|bar|donut|spark" · -label · -data캔버스 차트. -data는 JSON, -src와 -key를 주면 JSON 모의 데이터에서 채움
    ul.Catui_legend[data-catui-adm-legend]차트 바로 다음에 두면 차트 자료로 범례를 만듦
    input[type=checkbox][data-catui-adm-pref="키"]켬/끔을 기억하고 바꿀 때 알림
    details[data-catui-adm-key="이름"]사이드바 묶음의 열림 상태를 기억
    form[data-catui-adm-form] · [data-catui-adm-savebar] · [data-catui-adm-savenote]변경 감지(떠날 때 확인) · 저장 막대 · 막대 안 상태 문구
    [data-catui-adm-count-sel] · [data-catui-adm-clear-sel]목록 화면 일괄 작업 막대: 선택한 행 수 · 선택 해제 버튼
    data-catui-adm-pane="list|detail" · [data-catui-adm-back]나눔 화면(767px 이하 한 단씩) · 목록으로 돌아가기 버튼
    [data-catui-adm-empty]칸반 열이 비면 보이는 안내
    [data-catui-adm-pwtoggle] · -caps="#입력" · -strength="#입력"비밀번호 보기 · Caps Lock 알림 · 강도 막대

    차트 높이 토큰(--Catui_adm-chart-h)은 .Catui_adm에 정의됩니다. 관리 셸 밖(이 문서처럼)에 차트를 둘 때는 class="Catui_adm" 상자로 감싸거나 높이를 직접 주세요. 클래스만 쓰고 data-catui-adm 속성은 넣지 않으므로 셸 동작은 켜지지 않습니다.

    자주 쓰는 사용 예

    대시보드·목록·설정 화면에서 자주 쓰는 조합입니다. 자료는 모두 마크업 안(인라인 JSON·배열)에 두었습니다 — 실서비스에서는 admin.data('이름')이나 API 응답으로 바꾸면 됩니다.

    입력을 바꾸면 막대 문구가 "저장하지 않은 변경 사항이 있습니다"로 바뀌고, 저장하지 않은 채 쪽을 떠나면 브라우저가 확인을 묻습니다.
