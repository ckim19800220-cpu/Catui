admin.css 클래스

Catui_adm-* 클래스와 토큰.

규칙

  • 클래스는 Catui_adm-*, 토큰은 --Catui_adm-*(본체 토큰을 참조만). 새 색 값은 만들지 않습니다.
  • 본체 클래스를 덮어쓰지 않습니다 — 본체 클래스에 스타일을 더할 때는 항상 .Catui_adm … 아래로 한정합니다. 그래서 admin.css를 불러와도 관리 화면 밖은 바뀌지 않습니다.
  • 반응형 기준은 본체와 같습니다: 1199 · 991 · 767 · 479px.

토큰

admin 토큰
토큰기본값
--Catui_adm-bg--Catui_color-surface-muted (본문 배경)
--Catui_adm-side-w · --Catui_adm-rail-w사이드바 폭 · 접힌 폭
--Catui_adm-gap · --Catui_adm-pad카드 간격 · 본문 여백
--Catui_adm-chart-h차트 높이 (Catui_adm-chart-lg 1.5배 · -sm 0.7배)
--Catui_adm-dur · --Catui_adm-drawer-shadow · --Catui_adm-scrim전환 시간 · 서랍 그림자 · 가림막

예: 사이드바를 넓히려면 .Catui_adm{--Catui_adm-side-w:260px}.
