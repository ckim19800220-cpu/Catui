    구조 · 새 화면 만들기

    셸 마크업, 메뉴(menu.json), 템플릿 머리 주석, 빌드 검사.

    셸 마크업

    본체 관리 셸(.Catui_app) 그대로에 .Catui_adm와 data-catui-adm만 더합니다.

    <div class="Catui_app Catui_adm" data-catui-adm>
  <aside class="Catui_side" id="adm-side" aria-label="주 메뉴"> … 메뉴 (그룹·하위 메뉴는 details.Catui_nest.Catui_adm-nest) … </aside>
  <div class="Catui_adm-scrim" hidden></div>                    ← 991px 이하 서랍 가림막
  <div class="Catui_main">
    <header class="Catui_topbar Catui_adm-top">
      <button data-catui-adm-toggle aria-controls="adm-side">   ← 접기(992px↑) · 서랍 열기(991px↓)
      <nav class="Catui_crumb"> … </nav>
      <button data-catui-adm-cmd>  <button data-catui-adm-theme>  <button data-catui-adm-notify="알림 주소">  <button data-catui-adm-user>
    </header>
    <main class="Catui_content Catui_adm-content" id="adm-main"> … </main>
    <footer class="Catui_adm-foot"> … </footer>
  </div>
</div>
<script type="application/json" id="adm-cmd-data">[{ "group", "title", "href", "icon" }]</script>     ← 명령 팔레트 화면 목록
<script type="application/json" id="adm-notify-data">[{ "who", "text", "time", "unread" }]</script>  ← 알림
<script type="application/json" id="adm-user-data">[{ "title", "href", "icon" } | { "type": "-" }]</script>  ← 사용자 메뉴

    상태(사이드바 접힘·하위 메뉴·테마·스위치)는 localStorage의 catui:admin에 기억합니다.

    새 화면 만들기

    templates/admin/pages/이름.html 맨 위에 머리 주석을 두고 본문만 씁니다.

    <!-- title: 재고 현황 | crumb: 커머스 / 재고 | layout: shell | root: data-catui-adm-fixed-foot -->
<div class="Catui_adm-head"><div><h1 class="Catui_h1">재고 현황</h1></div></div>
…
<script> catui.use(['table'], function (table) { … }); </script>   ← catui.js·catadmin.js 뒤로 자동으로 옮겨짐
    • layout: blank면 셸 없이(로그인·오류 화면).
    • 메뉴는 templates/admin/menu.json — 그룹 › 항목 › 하위 항목. 아직 만들지 않은 화면은 메뉴에 나오지 않습니다.
    • {{icon:이름:크기}}로 아이콘을 넣습니다.

    JSON 모의 데이터

    템플릿의 샘플 값은 templates/admin/data/*.json에 있고, 빌드가 문법을 검사해 docs/admin/templates/data/로 복사합니다. 화면은 이 파일을 읽어 그립니다 — 실서비스는 같은 모양의 API로 바꾸면 됩니다.

    catui.admin.dataBase = '/api/';                 // 기본은 화면 옆 data/
catui.admin.data('orders').then(function (rows) { … });   // data/orders.json (한 번만 읽고 캐시)

<section data-catui-adm-src="dashboard-ops">   ← 선언형: 이 영역의 값을 JSON에서 채움
  <b data-catui-adm-text="kpi.users.value" data-catui-adm-format="number">12,480</b>
  <div data-catui-adm-chart="area" data-catui-adm-key="charts.network"></div>
</section>

    목록·표는 행 바인딩으로 그립니다. 값은 글자로만 넣으므로 데이터가 마크업으로 끼어들지 않습니다.

    <tbody data-catui-adm-src="dashboard-sales" data-catui-adm-rows="topProducts">
  <template><tr>
    <td data-catui-adm-field="name"></td>                               ← 글자
    <td data-catui-adm-field="revenue" data-catui-adm-format="man"></td>  ← 형식
    <td><span class="Catui_pill" data-catui-adm-class="Catui_pill-:tone">…  ← 값으로 클래스
    <i data-catui-adm-attr="style:width:{pct}%;aria-label:{name}">       ← 속성 치환
    <input type="checkbox" data-catui-adm-bool="checked:done">          ← 참·거짓 속성
    <ul data-catui-adm-rows="features"><template>…</template></ul>      ← 행 안의 하위 목록
  </tr></template>
</tbody>

// 합계·비율은 원자료에서 계산 (바인딩 전에 호출)
catui.admin.derive['page-charts'] = function (j) { … return j; };

<div data-catui-adm-chart="donut" …></div><ul class="Catui_legend" data-catui-adm-legend></ul>   ← 범례를 차트 자료에서

    형식: number · won · man(만 원) · percent · delta(▲▼) · ms · initial(첫 글자). 파일: 대시보드(dashboard-ops·analytics·sales·health) · 주문(orders · order-1044 · invoice-1102) · 상품(products · page-product · pricing) · 사람(users · contacts) · 앱(notifications · chat-rooms · mails · kanban · files · events · stores · projects · project-promo · faq) · 화면별(page-*).

    빌드 검사

    npm run build는 다음 중 하나라도 있으면 실패합니다.

    • admin.css가 본체 클래스를 단독 선택자로 다시 정의(.Catui_side{…}) · 직접 쓴 색(hex) · 없는 토큰
    • 템플릿의 정의 안 된 클래스 · 없는 아이콘 · id 중복 · label for 불일치 · 없는 화면 링크 · h1이 한 개가 아님
    • 템플릿·catadmin.js 어디에도 쓰이지 않은 admin 클래스

    npm test는 템플릿 전체의 콘솔 오류 0건과 셸·폼·목록·채팅·칸반·로그인 동작을 헤드리스 Chrome으로 확인합니다.
