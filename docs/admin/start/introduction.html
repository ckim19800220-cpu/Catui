    CatuiAdmin은

    Catui(CSS 키트 + catui.js) 위에 얹는 관리자 대시보드 확장입니다. 본체 컴포넌트를 그대로 쓰고, 관리 화면에 필요한 것만 더합니다.

    catadmin.js

    catui.admin — 사이드바·테마·알림·명령 팔레트·위젯·폼 변경 감지·목록 주소 동기화·채팅·칸반·로그인 보조

    templates/admin/

    복사해서 쓰는 전체 화면 HTML 52종 — 같은 셸·메뉴를 공유하고, 빌드가 링크·클래스·접근성을 검사

    화면 구성은 Gentelella v4 대시보드를 참고했고, 코드·문구·이미지는 Catui 토큰·컴포넌트로 새로 작성했습니다 (MIT).

    구성 계층

    1. admin.css · catadmin.js관리 셸 · 위젯 · 화면별 보조이 문서
    2. catui.js접근성 · 데이터 · 선언형 속성 · 오버레이
    3. catui.css토큰 · 리셋 · 컴포넌트

    공통 계정 화면 조각

    templates/shared/account-password.html·account-links.html·account-denied.html을 Admin·Community·Shop·Booking 빌드가 함께 사용합니다. 각 확장의 기존 로그인 검증·프로필 저장 방식은 유지하고 비밀번호 입력·계정 안내·403 표시를 통일합니다.

    data-catui-password-toggle은 같은 폼의 비밀번호 표시와 가림을 전환합니다. 폼 초기화·탭 비활성화·모듈 해제 시 다시 가리며 값을 저장하거나 서버로 보내지 않습니다. 폼 사용법에 선언형 예제가 있습니다. 이 조합은 실제 세션·통합 로그인·RBAC 구현이 아닙니다.

    채팅·파일의 확장 경계

    현재는 독립 확장을 추가하지 않고 기존 Admin·Community 화면을 재사용합니다. 현재 구현과 서버 연동이 필요한 범위를 구분합니다.

    채팅·파일의 구현 범위와 독립 확장 조건
    기능현재 예제독립 확장 전에 필요한 계약
    Admin 상담 채팅대화 목록·검색·모바일 전환·한글 입력 보호·메모리 기록·시간 지연 모의 답장대화 참여 권한·전달 확인·재연결·메시지 보관·실시간 전송 API
    Community 공개 대화방게시판별 방·대화 로그·반복 메시지 제한·가상 접속자·모의 답장회원·방 접근 정책·신고·차단·서버 속도 제한·실제 접속 상태
    Admin 파일 목록폴더·검색·보기 전환·이름과 크기 추가·메모리 목록 삭제. 실제 업로드·다운로드는 없음저장소·파일별 인가·업로드 제한·형식 검증·보관·공유 만료 정책

    위 계약 없이 이름과 화면만 분리한 CatuiChat·CatuiFiles는 만들지 않습니다. 목록·로그·분할 화면·파일 컴포넌트는 기존 본체와 Admin 자산을 우선 사용합니다.
