    설치

    admin.css · catadmin.js 로드 순서, npm · ES 모듈, 템플릿으로 시작하기.

    배포 파일

    CatuiAdmin은 @imcat-ckim/catui 패키지 안에 함께 들어 있습니다. 본체 다음에 불러옵니다.

    CatuiAdmin 파일
    파일내용
    dist/admin.min.css (admin.css)관리 화면 확장 스타일 — catui.min.css 다음
    dist/catadmin.min.js (+ .map)전역 catui.admin — catui.js 다음 (순서가 틀리면 콘솔에 안내)
    dist/catadmin.esm.js · catadmin.esm.min.jsES 모듈 (./catui.esm.js를 가져옴)
    dist/catadmin.d.tsTypeScript 타입

    전역 스크립트

    <link rel="stylesheet" href="dist/catui.min.css">
<link rel="stylesheet" href="dist/admin.min.css">
…
<script src="dist/catui.min.js"></script>
<script src="dist/catadmin.min.js"></script>
<script>
catui.use(function () {
  catui.admin.on('theme', function (d) { console.log('테마', d.value); });
});
</script>

    문서가 준비되면 [data-catui-adm] 셸을 찾아 자동으로 연결합니다 (catui.config({ autoInit: false })면 catui.admin.init()을 직접 부르세요).

    npm · ES 모듈

    npm install @imcat-ckim/catui

import catui from '@imcat-ckim/catui';
import admin from '@imcat-ckim/catui/admin';     // catui.admin 등록 + 자동 초기화
import '@imcat-ckim/catui/css';
import '@imcat-ckim/catui/admin.css';

    템플릿으로 시작

    1. 화면 지도에서 만들려는 화면과 비슷한 화면을 고릅니다.
    2. 저장소의 templates/admin/pages/화면.html을 복사하고 머리 주석(제목·경로)과 본문을 바꿉니다.
    3. npm run build — 사이드바·상단 바·바닥글을 붙여 docs/admin/templates/에 만들고 검사합니다.

    빌드를 쓰지 않는다면 만들어진 docs/admin/templates/*.html을 그대로 서버 템플릿으로 옮겨 쓰면 됩니다.
