2.0에서 2.1로

깨지는 변경은 없습니다. 확장 키트(CatuiAdmin·CatuiCommunity·CatuiShop·CatuiDocs)가 더해졌고, catui.imeBusy가 공개되었습니다.

올리는 순서

  • npm install @imcat-ckim/catui@2.1로 올립니다.
  • 확장을 쓸 때만 dist/docs.css·catdocs.js를 더 불러옵니다.
npm install @imcat-ckim/catui@2.1
