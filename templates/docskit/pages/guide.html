준비물

Node.js 20 이상(npm으로 설치할 때만)과 최신 Chrome·Edge·Safari·Firefox. 빌드 도구 없이 CDN 태그로도 됩니다.

  1. 설치하기

    npm으로 받거나, dist 폴더를 그대로 복사합니다.

    npm install @imcat-ckim/catui

  2. CSS와 스크립트 불러오기

    문서 사이트라면 docs.css와 catdocs.js를 본체 다음에 불러옵니다. 순서가 틀리면 콘솔에 안내가 나옵니다.

    <link rel="stylesheet" href="dist/catui.min.css">
<link rel="stylesheet" href="dist/docs.min.css">
<script src="dist/catui.min.js"></script>
<script src="dist/catdocs.min.js"></script>

  3. 셸 마크업 붙이기

    루트에 data-catui-dk를 달면 메뉴·목차·검색·피드백이 자동으로 연결됩니다.

    <div class="Catui_site Catui_dk" data-catui-dk>
  <aside id="toc"></aside>
  <article data-catui-dk-toc="#toc">
    <h2>설치</h2> …
  </article>
</div>

  4. 스크립트로 더하기

    이벤트를 받아 분석 도구나 서버로 보낼 수 있습니다. 함수 목록은 API 참조에 있습니다.

    catui.docs.on('feedback', ({ key, value }) => {
  fetch('/api/feedback', { method: 'POST', body: JSON.stringify({ key, value }) });
});
