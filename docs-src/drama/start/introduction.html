한국어 숏드라마 탐색 확장

CatuiDrama는 Catui 본체 위에 얹는 독립 확장입니다. 참고 사이트의 작품 진열·분류·랭킹·상세 흐름을 한국어 탐색과 찜 보관함으로 구성했습니다. 해당 사이트의 상표·작품·포스터·영상은 복제하지 않았습니다.

가상의 작품 16편과 기존 공개 API 사진을 재사용합니다. 포스터 사진은 실제 작품 사진이 아닌 연출 이미지입니다. 사진별 작가·출처·사용 조건은 출처·라이선스에서 확인할 수 있습니다.

파일 연결

catui.min.css 다음 drama.min.css, catui.min.js 다음 catdrama.min.js를 연결합니다. 다른 확장은 필요하지 않습니다. ESM은 @imcat-ckim/catui/drama, CSS는 @imcat-ckim/catui/drama.css입니다.

루트는 class="Catui_site Catui_dr" data-catui-dr data-page="catalog"입니다. 내부에 data-view 목록 상자와 data-status 상태 문구를 둡니다. 완전한 예제는 templates/drama/의 레이아웃·페이지를 복사해 사용하세요.

이미지와 JSON은 배포 패키지에 포함되지 않습니다. 자신의 정적 파일 경로에 복사하고 자동 초기화 전에 catui.drama.dataBase와 catui.drama.photoBase를 설정하세요. 기본값은 data/와 ../../../assets/photos/입니다.

공개 API와 데이터 계약

API설명
drama.init(scope)루트 한 번 연결. 다른 루트로 옮기면 이전 이벤트 해제
drama.ready데이터 요청과 화면 처리가 끝나는 Promise. 재시도 때 갱신
drama.load()dataBase + series.json을 읽어 캐시. 실패 캐시는 지워 재시도
drama.state() / filtered()주소의 검색·장르·형식·정렬·페이지와 필터 결과
drama.destroy()이벤트·루트 연결 해제. 늦게 도착한 응답은 화면을 변경하지 않음

작품 배열에는 고유 id, title, desc, genre(로맨스/스릴러/판타지/일상), format(실사/애니/AI), episodes, minutes, status(완결/연재 중), date(YYYY-MM-DD), photo(jpg/png 파일명)가 필요합니다. 타입 선언은 src/types/catdrama.d.ts입니다.

선택 조건은 q·g·t·sort·page, 작품은 id 주소로 공유합니다. 찜과 테마는 catui:drama에만 저장하며 계정 동기화는 하지 않습니다.

접근성·실패·반응형

기존 Catui 버튼·입력·선택·배지·빈 상태·알림·포커스 토큰을 재사용합니다. 한글 조합 중 Enter를 검색 제출로 처리하지 않습니다. 결과·찜 변경을 낭독기에 알리고, 없는 작품·빈 검색·빈 보관함·JSON 실패·재시도를 구분합니다. 이미지가 실패해도 작품 제목과 상세 링크가 남습니다.

320px에서는 2열 포스터와 전체 폭 소개를 사용하고, 넓은 화면은 6열 목록입니다. 밝은·어두운 테마를 지원하고 자동 재생·스크롤을 가로채는 모션은 사용하지 않습니다.

운영 연동 경계

실제 영상 스트리밍·DRM·결제·광고·회원 인증·시청 이력·실시간 랭킹·앱 설치는 구현하지 않았습니다. 회차는 정보 목록이며 재생 버튼으로 위장하지 않습니다. 운영 서비스는 작품·이미지·영상 권리, 등급 심의, 개인정보와 보관 기간, 접근 제어 및 재생 API를 별도로 정의해야 합니다.
