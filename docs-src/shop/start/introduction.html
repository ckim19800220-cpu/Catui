업종별 편집숍 템플릿

템플릿 팩에서 식품 편집숍과 리빙 스토어를 고릅니다. 상품 분류와 안내를 바꿀 뿐 상품·가격·옵션·장바구니·주문서를 복제하지 않습니다.

data-catui-sh-products="cat:food" 또는 cat:living으로 기존 상품 묶음을 표시합니다. 로딩 실패 시 목록 안의 재시도 안내를 사용하고 복구 후 같은 분류를 그립니다. 카드의 예상 금액과 실제 장바구니 계산 규칙도 기존 Shop 규칙을 유지합니다.

Booking 식당·숙박 소개로 가는 링크는 선택적인 연결 예제이며 Shop에서 Booking JS를 불러오지 않습니다. 식품 보관·알레르기·냉장 배송, 가구 설치·지역별 추가 배송비 등은 실서비스의 원자료와 정책이 필요합니다.

비밀번호 입력·계정 안내·권한 없음은 Admin·Community·Booking과 templates/shared/ 마크업을 공유합니다. 공통 화면은 인증·인가 서버나 통합 로그인 기능을 대신하지 않습니다.

접근성 · 반응형 기준

  • 할인율·품절·남은 재고·무료배송은 색 + 글자로 함께 알립니다(“30% 할인”, “품절”, “3개 남음”). 품절 색상 견본은 빗금 무늬 + 숨김 글자 “(품절)”.
  • 장바구니 배지는 숫자 뒤에 숨김 글자(“개 담김”)를 붙이고, 역할 없는 span에는 aria-label을 쓰지 않습니다(빌드가 검사).
  • 수량·옵션·장바구니를 다시 그려도 포커스는 같은 자리로 돌아오고, 경계에서 잠긴 버튼 대신 반대 버튼으로 옮겨 갑니다.
  • 320px 화면에서 가로 넘침 없음(상품 2열, 장바구니 줄 2단), 가로로 넘치는 줄(카테고리·칩·작은 사진)은 position:relative 스크롤 상자입니다.
  • 모션은 누름 피드백·사진 확대·구매 막대 올라오기뿐이며 prefers-reduced-motion이면 끕니다.
