규칙

  • 클래스는 Catui_sh-*, 토큰은 --Catui_sh-*(본체 토큰을 참조만). 새 색 값(hex)은 만들지 않습니다 — 빌드가 막습니다.
  • 본체 클래스에 스타일을 더할 때는 항상 .Catui_sh … 아래로 — shop.css를 불러와도 쇼핑몰 밖은 바뀌지 않습니다.
  • 할인율·품절·남은 재고·무료배송은 색 + 글자를 함께 — 색만으로 알리지 않습니다. 숫자 배지는 숨김 글자(.Catui_clip)로 뜻을 보충합니다.
  • 반응형: 991px 이하 필터·주문 요약·마이페이지 메뉴를 위로/아래로, 767px 이하 하단 탭 + 상세 한 단, 599px 이하 장바구니 줄 2단, 399px 이하(320px 포함) 머리·카드 여백 축소.
  • 가로로 넘치는 상자(카테고리 메뉴·칩·작은 사진·표)는 position:relative 스크롤 상자입니다.
