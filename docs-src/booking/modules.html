catui.booking

catbooking.js가 catui.extend({ booking })로 등록하고, 문서가 준비되면 [data-catui-bk] 루트를 찾아 연결합니다. 루트가 없는 화면(이 문서처럼)에서는 데이터를 읽지 않으므로 계산 함수와 부품(seats.mount·calendar.mount)을 직접 씁니다. 날짜는 "YYYY-MM-DD", 시각은 "HH:MM" 한국 시간 글자입니다. 전체 타입은 dist/catbooking.d.ts.

자주 쓰는 사용 예

예약 토큰이 .Catui_bk에 정의되므로 예제는 class="Catui_bk" 상자로 감쌌습니다 — data-catui-bk 속성은 넣지 않아 화면 부품(데이터 읽기)은 켜지지 않습니다(문서용으로 min-height만 풀었습니다). “지금”은 2026-11-04 13:10 KST로 넘깁니다.

11월 4일 (수) · 도자기 클래스 90분 · 정원 6

    11:30~13:00 시작은 90분 이용이 휴게(12:30~13:30)와 겹쳐 닫히고, 13:30은 “지금 + 30분”보다 이르므로 지난 시간입니다.

    어른 45,000원

    2

    어린이 30,000원

    1

    11/5(목)은 평일, 11/6(금)·11/7(토)은 주말(143,000원)입니다. 기준 2명을 넘는 1명은 밤마다 20,000원. 12/24(목) 밤은 다음 날이 공휴일이라 주말 요금입니다.

    Tab으로 배치도에 들어가 화살표로 움직이고 Space로 고릅니다. 4번째 좌석을 누르면 “최대 3석” 안내가 나오고, 예약된 좌석(빗금 ×)은 초점은 받지만 고를 수 없습니다.

      14:00·14:30·15:00 세 블록은 이어서 겹치는 한 묶음(칸 2개 — 15:00 블록은 14:00 블록이 끝난 첫 칸을 다시 씀), 17:00은 따로입니다.

      이벤트 · 실서비스 연결

      catui.booking.on('save', ({ reservation }) => fetch('/api/reservations', { method: 'POST', body: JSON.stringify(reservation) }));
catui.booking.on('cancel', ({ no, refund }) => fetch(`/api/reservations/${no}/cancel`, { method: 'POST', body: JSON.stringify(refund) }));
catui.booking.rules.refund = [{ days: 3, rate: 100 }, { days: 1, rate: 50 }, { days: 0, rate: 0 }];   // 규정 바꾸기
catui.booking.rules.weekendRate = 20;          // 주말 할증 20%
catui.booking.dataBase = '/api/booking/';      // 같은 모양의 JSON API
catui.booking.go = (url) => router.push(url);  // SPA 라우터로 단계 이동

      금액·남은 자리·환불은 화면에서 계산해 보여 주지만, 실서비스에서는 서버가 같은 규칙으로 다시 계산해 확정해야 합니다 — 계산 함수는 화면과 무관한 순수 함수라 Node에서도 그대로 쓸 수 있습니다.
