규칙

  • 클래스는 Catui_bk-*, 토큰은 --Catui_bk-*(본체 토큰을 참조만). 새 색 값(hex)은 만들지 않습니다 — 빌드가 막습니다.
  • 본체 클래스에 스타일을 더할 때는 항상 .Catui_bk … 아래로 — booking.css를 불러와도 예약 화면 밖은 바뀌지 않습니다. 단계 표시·인원 증감·표·배지는 본체(.Catui_steps·.Catui_stepper·.Catui_tbl·.Catui_badge)를 그대로 씁니다.
  • 상태는 색 + 글자 + 모양을 함께: 고름 = 채움 + 체크 아이콘 + aria-pressed, 마감·예약됨 = 빗금(--Catui_bk-hatch) + 점선 + × 아이콘 + “마감/예약됨” 글자, 임박 = 경고 아이콘 + “임박”, 지난 시간·날짜 = 취소선 + 글자, 장애인석 = 휠체어 아이콘 + 굵은 테두리 + 숨김 글자.
  • 반응형: 991px 이하 옆줄(예약 내용)을 본문 아래로, 767px 이하 머리 메뉴를 둘째 줄 가로 스크롤, 599px 이하 객실 카드 금액을 아래로·기간 입력 한 열, 399px 이하 좌석 칸·달력 칸을 줄입니다. 좌석 배치도·일정표·표는 position:relative 스크롤 상자 안에서만 가로로 밀립니다.
  • 모든 초점은 :focus-visible 외곽선(--Catui_color-focus-ring), 모션은 prefers-reduced-motion: reduce면 끕니다.
