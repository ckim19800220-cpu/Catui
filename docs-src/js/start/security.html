문자열은 글자로

layer의 content, table의 templet, 탭·접기 내용에 일반 문자열을 넘기면 항상 글자(textContent)로 들어갑니다. 서버나 사용자 입력을 그대로 넘겨도 스크립트가 실행되지 않습니다.

마크업은 catui.html``

  • catui.html`…${값}` — 템플릿의 ${} 값은 escape됩니다. 배열은 이어 붙고, false·null은 출력하지 않습니다.
  • catui.raw(문자열) — 직접 만든 신뢰 마크업에만 씁니다. 외부 값을 raw로 감싸면 XSS가 됩니다.
  • 신뢰 표식은 raw()·html``·icon()이 만든 객체에만 붙습니다. 서버 JSON의 { "__raw": "…" }처럼 모양만 같은 객체는 글자로 escape됩니다.
  • 인라인 스크립트·on* 속성을 만들지 않으므로 script-src 'self' CSP와 함께 쓸 수 있습니다.

정리

SPA처럼 화면을 바꾸는 앱에서는 on()이 돌려준 해제 함수를 호출하고 인스턴스를 destroy()하세요. 레이어는 layer.closeAll(), 전역 연결은 catui.destroy()로 정리합니다. 컴포넌트 모듈은 모듈.destroyAll()(전부) · 모듈.destroyDetached()(DOM에서 빠진 대상만)로 한 번에 정리할 수 있습니다.
