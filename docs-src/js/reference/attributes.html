data-catui-errtext="문장"입력 칸필수 외 오류 문구

data-catui-date(="range") · data-catui-min/max입력 칸날짜·기간 선택기
data-catui-collapse(="accordion")details.Catui_faq 묶음하나만 열기 + collapse(필터)

details.Catui_dd · .Catui_mega마크업 메뉴하나만 열기·바깥 클릭·Esc 닫기 (자동)
.Catui_modal-toggle · .Catui_drawer-toggleCSS 체크박스 모달포커스 이동·Tab 가두기·Esc·복귀 (자동)
.Catui_select-wrap셀렉트화살표 아이콘이 없으면 보충

data-catui-carousel (+ data-catui-autoplay="ms" · data-catui-loop="false").Catui_carousel이전·다음·점·정지 버튼, 키보드 (carousel)
data-catui-tags="초기,값" (+ data-catui-max)입력 칸태그 입력 (field)

data-catui-counter[="최대"]입력·여러 줄글자 수 (없으면 maxlength)
data-catui-otp[="alnum"] (+ data-catui-name)fieldset.Catui_otp인증 코드 칸 이동·붙여넣기
data-catui-copy[="#id|글자"]버튼복사 (비우면 가까운 코드 블록) (page)
data-catui-tip="설명" (+ data-catui-tip-side)아무 요소툴팁 (마우스·포커스)
data-catui-src · data-catui-srcsetimg · iframe · source화면 가까이 오면 로드
data-catui-totop="px" (+ data-catui-totop-target).Catui_totop스크롤 후 표시, 맨 위로 + 포커스 이동
data-catui-header[="hide"] · data-catui-spy.Catui_site-header · 내비게이션스크롤 그림자·숨김·모바일 메뉴 닫기 / 현재 섹션 표시 (site)
data-catui-dismiss="키" (+ data-catui-days).Catui_announce공지 닫기 기억
data-catui-cookie + data-catui-consent.Catui_cookie · 버튼쿠키 동의 저장
data-catui-countdown="날짜" (+ data-catui-done · data-catui-unit)아무 요소카운트다운
data-catui-billing (+ data-catui-monthly/yearly · -billing-show)요금 영역월간·연간 전환
