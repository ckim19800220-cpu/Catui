선언형 속성
속성붙이는 곳동작
data-catui-filter="이름"폼·탭·표·버튼·컨트롤모듈.on('이벤트(이름)')의 필터
data-catui-form<form>제출 시 검증 + submit(필터)
data-catui-verify="required|email"입력 칸검증 규칙 (|로 여러 개)
data-catui-reqtext="문장"입력 칸필수 오류 문구
data-catui-submit제출 버튼이 버튼으로 제출할 때만 처리
data-catui-table + th[data-catui-sort="number|text"]정적 표열 정렬
data-catui-date(="range") · data-catui-min/max입력 칸날짜·기간 선택기
data-catui-collapse(="accordion")details.Catui_faq 묶음하나만 열기 + collapse(필터)
input.Catui_range[data-catui-filter]마크업 rangeslider.on('change(필터)')
.Catui_rating[data-catui-filter]마크업 별점rate.on('choose(필터)')
details.Catui_dd · .Catui_mega마크업 메뉴하나만 열기·바깥 클릭·Esc 닫기 (자동)
.Catui_modal-toggle · .Catui_drawer-toggleCSS 체크박스 모달포커스 이동·Tab 가두기·Esc·복귀 (자동)
.Catui_select-wrap셀렉트화살표 아이콘이 없으면 보충
data-catui-theme="dark"<html>다크 테마 (CSS만으로 동작, 다크 모드). canvas는 바뀌면 다시 그림

동적으로 넣은 영역은 catui.init(영역)을 호출하면 같은 준비를 합니다.
