기본 API
API설명
catui.use(mods, fn)문서 준비 후 모듈을 인자로 넘겨 콜백. Promise도 돌려줌. 없는 모듈은 경고
catui.config(options)icons(스프라이트 경로), autoInit(자동 연결), debug
catui.extend({ 이름: 모듈 })사용자 모듈 추가 → catui.use('이름'), catui.이름
catui.define(이름, [의존], 팩토리)의존 모듈을 받아 만드는 정의형 추가
catui.init(영역)새로 그린 영역의 data-catui-* 준비(셀렉트 화살표·정적 표·날짜 입력 등)
catui.destroy()전역 위임 해제 + 레이어 모두 닫기 (테스트·SPA 정리용)
catui.version · catui.cache버전, 현재 설정·모듈 목록
