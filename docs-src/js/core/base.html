기본 API
API설명
catui.use(mods, fn)문서 준비 후 모듈을 인자로 넘겨 콜백. Promise도 돌려줌. 없는 모듈은 경고
catui.config(options)설정 바꾸기 — 아래 설정 표
catui.extend({ 이름: 모듈 })사용자 모듈 추가 → catui.use('이름'), catui.이름
catui.define(이름, [의존], 팩토리)의존 모듈을 받아 만드는 정의형 추가
catui.init(영역)영역은 요소·선택자·document. 새로 그린 영역의 data-catui-* 준비(셀렉트 화살표·정적 표·날짜 입력 등)
catui.destroy()전역 위임 해제 + 렌더한 인스턴스 정리(destroyAll) + 레이어 모두 닫기 (테스트·SPA 정리용)
catui.version · catui.cache버전(빌드가 package.json 값을 넣음, 빌드 안 한 소스는 "dev"), 현재 설정·모듈 목록
catui.csrfHeaders(주소, method)직접 fetch할 때 붙일 CSRF 헤더 객체 (조건이 안 맞으면 {})

설정

catui.config({ debug: false, csrf: { meta: 'csrf-token', header: 'X-CSRF-Token' } });   // 스크립트 바로 다음에
catui.config 설정
키기본값설명
iconscatui.js 옆 icons.svg아이콘 스프라이트 경로
autoInittrue문서 준비 시 data-catui-* 자동 연결
debugtrue콘솔 출력 — true 경고·오류 / false 오류만(운영 권장) / "silent" 모두 끔
autoDestroytrueDOM에서 빠진 요소의 컴포넌트 인스턴스를 다음 틱에 자동 정리(destroyDetached). 떼었다 다시 붙일 요소는 렌더 옵션 keep: true. 첫 init 전에 설정
csrf{ meta: 'csrf-token', header: 'X-CSRF-Token' }<meta name="csrf-token" content="…"> 값을 form Ajax·table url·upload 요청 헤더로. 같은 출처이면서 GET·HEAD·OPTIONS가 아닐 때만 붙여 토큰이 외부로 새지 않습니다. 모듈 옵션 headers가 우선. false = 끔
