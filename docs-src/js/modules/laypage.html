페이지 이동

현재 쪽을 가운데 둔 번호 묶음과 처음·끝 쪽 버튼을 두고, 사이가 비면 …을 보입니다. 처음 렌더할 때 jump가 first === true로 한 번 호출됩니다.

총 건수 · 쪽 크기 · 바로 가기

쪽 크기를 바꾸면 보던 첫 항목이 들어 있는 쪽으로 옮기고, 바로 가기는 1~끝 쪽 범위로 맞춥니다.
