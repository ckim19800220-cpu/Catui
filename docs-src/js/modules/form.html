선언형 검증과 제출

제출하면 검증하고, 처음 틀린 칸에 포커스한 뒤 오류를 색 + 문장(aria-invalid, aria-describedby)으로 알립니다. 틀린 칸은 입력할 때마다 다시 검사합니다. 빈 값은 required만 검사합니다.

매개변수 규칙 · 확인 칸 · 그룹 필수

요금제 필수

규칙은 이름:값으로 매개변수를 받습니다. same:pw는 원본 칸을 고치면 확인 칸도 다시 검사합니다. 같은 name의 라디오·체크박스는 첫 칸에만 required를 달면 "하나 이상 선택"으로 검사합니다(그룹은 .Catui_field로 감싸 오류 문장 자리를 줍니다).

Ajax 제출

검증과 submit(f) 이벤트를 통과하면 fetch로 보냅니다(submit에서 false를 돌려주면 보내지 않음). 보내는 동안 제출 버튼은 disabled + aria-busy로 이중 제출을 막습니다. 응답이 JSON이면 객체로, 아니면 글자로 res에 담깁니다.

API설명
data-catui-verify="required|email"형식: required · email · phone · tel · zip · url · number · int · date · id · password · hangul · alpha · alnum
data-catui-verify="min:1|max:9|minlen:2|maxlen:40|len:6|same:이름"매개변수 규칙 — 숫자 범위 / 글자 수 / 다른 칸과 같은 값
data-catui-reqtext · data-catui-errtext필수 오류 문구 / 그 밖의 오류 문구 바꾸기
data-catui-submit제출 버튼이 여러 개일 때 이 버튼만 처리
data-catui-ajax[="주소"]fetch로 제출 (주소 없으면 action). method 속성 따름, 기본 POST
data-catui-timeout="30000"Ajax 시간 제한(ms, 기본 30초, 0 = 없음). 넘기면 fail에 error.timeout = true
form.verify({ 이름: [정규식, 메시지] | fn(value, el, arg, root) })규칙 추가 (fn은 오류 문장 또는 '' 반환, arg는 이름:값의 값)
form.on('submit(f)'){ field, form, elem }. false = 기본 제출(·Ajax) 막기
form.on('done(f)') · form.on('fail(f)')Ajax 결과 { res, status, field, form, elem } / { error, field, form, elem }
form.on('input(f)')글자 입력마다 { elem, value, name }
form.on('switch|checkbox|radio|select(f)'){ elem, value, checked } — 필터는 컨트롤 또는 상위의 data-catui-filter
form.val(f, [값]) · form.serialize(f)값 읽기/쓰기 (같은 name은 배열) / 쿼리 문자열
form.reset(f)기본값으로 되돌리고 오류 표시 지우기
form.validate(영역) · form.submit(f, [cb])직접 검증 / 프로그램 제출
form.render(영역) · form.setError(el, 문장) · form.clearError(el)셀렉트 화살표 보충 / 오류 직접 표시 / 지우기 (clearError는 칸 하나를 받습니다 — 폼 전체는 form.reset(f))
