효과 모음

텍스트·스크롤·커서·배경 효과를 의존성 없이 붙입니다. 함수로 부르거나 data-catui-fx 속성만 붙여도 되고, 모두 { destroy() }로 원래대로 돌아갑니다. 모션 줄이기 설정에서는 최종 상태를 바로 보입니다. 효과의 종류는 React Bits 같은 애니메이션 모음이 다루는 범주를 참고했고, 코드는 Catui용으로 새로 작성했습니다.

API

fx API
함수 · 속성옵션설명
fx.reveal(el) · revealy · delay · once화면에 들어오면 아래에서 떠오르며 나타남 (data-catui-delay)
fx.split(el) · splitby: 'char'|'word' · stagger글자·단어가 흐림에서 차례로 또렷해짐 (data-catui-by)
fx.count(el) · countto · from · duration · decimals · prefix/suffix숫자가 올라감, 천 단위 구분 (data-catui-to)
fx.type(el) · typewords · speed · pause · loop타자기로 단어를 차례로 쓰고 지움 (글자에 |로 구분 가능)
fx.scramble(el) · scrambleduration · chars · hover무작위 글자에서 원문으로 해독
fx.tilt(el) · tiltmax커서 쪽 3D 기울기 (마우스 환경만)
fx.spotlight(el) · spotlight—커서 따라 브랜드 빛, 포커스에도 켜짐
fx.magnet(el) · magnetstrength커서 쪽으로 살짝 끌림 (마우스 환경만)
fx.spark(el) · sparkcount클릭 위치에 불꽃 조각
fx.particles(el) · particlescount · link점과 선 배경 (canvas 사용)
