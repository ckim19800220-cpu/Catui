파일 올리기

끌어 놓기와 선택을 모두 받고, 형식·용량·개수를 검사해 오류를 문장(role=alert)으로 알립니다. url을 주면 XHR로 진행률과 함께 올리고 목록에서 취소·다시 시도할 수 있습니다.

자주 쓰는 사용 예
첨부 파일 (최대 5개)같은 이름의 파일은 한 번만 붙습니다

옵션 · 이벤트

upload 옵션
이름설명
url · method · field · data · headers · withCredentials서버 전송 (url이 없으면 고른 파일만 관리)
accept · size(KB) · number · multiple · auto검사와 자동 업로드
list파일 목록을 그릴 요소
before(file) · choose(files) · progress(%, file) · done(res, file) · error(msg, file)콜백 — 같은 이름 이벤트 + remove(f)
inst.upload() · inst.clear() · inst.files수동 업로드 / 비우기 / 목록
disabled · inst.setDisabled(bool)비활성 (선택·끌어 놓기·키보드 모두 막음)
guardtrue — 영역 밖에 파일을 잘못 놓아도 브라우저가 파일을 열어 페이지를 떠나지 못하게 막음
CSRFcatui.config({ csrf }) 설정대로 같은 출처 요청에 토큰 헤더를 붙임 (headers가 우선)
