복사 버튼

설치
npm install @imcat-ckim/catui

값을 비우면 가장 가까운 .Catui_codeblock의 코드를, #id면 그 요소(입력은 값)를, 그 밖은 적힌 글자를 복사합니다. 글자 버튼은 잠시 "복사됨"으로 바뀌고, 결과는 화면 낭독기에도 알립니다. http 환경에서도 대체 방식으로 복사합니다.

툴팁

마우스는 0.3초 뒤, 키보드 포커스는 바로 보이고 aria-describedby로 연결됩니다. Esc·스크롤·벗어나면 사라집니다. 아이콘 버튼은 툴팁과 별개로 aria-label을 주세요.

이미지 지연 로딩

화면에서 300px 안으로 들어오면 data-catui-src(·data-catui-srcset, <picture> 안 source, iframe)를 실제 주소로 바꿉니다. 자리가 흔들리지 않게 width·height를 꼭 주세요. 새로 넣은 영역은 catui.init(영역) 또는 page.lazy(영역).

무한 스크롤 · 더 보기

    목록 끝의 막대가 화면 가까이 오면 다음 쪽을 부르고, 키보드·화면 낭독기 사용자를 위해 "더 보기" 버튼을 항상 둡니다. 불러오는 동안 aria-busy, 실패하면 "다시 시도" 버튼을 보입니다.

page.totop({ offset: 400, target: '#main' });                                     // 없으면 버튼을 만들어 붙임

      400px 넘게 내려가면 보이고, 누르면 부드럽게 올라간 뒤 포커스도 대상(또는 main·h1)으로 옮깁니다. 모션 줄이기에서는 바로 이동합니다.
