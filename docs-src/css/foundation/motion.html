사용법

시간은 --Catui_dur-fast(120ms)의 배수, 곡선은 --Catui_ease입니다. 진입은 Catui_anim-fade/up/scale, 지연은 Catui_delay-1/2/3, 색·그림자 전환은 Catui_transition, 링크 카드 강조는 Catui_hover-lift.

접근성

  • prefers-reduced-motion: reduce에서는 진입 애니메이션과 들어 올리기를 모두 끕니다.
  • 정보를 움직임으로만 전하지 않습니다. 애니메이션은 꾸밈입니다.
