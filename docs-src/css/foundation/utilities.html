시각 숨김 (clip)

새 글 3건, 마지막 확인 이후

.Catui_clip은 화면에는 보이지 않지만 자리를 1px로 줄여 남겨 두므로 화면 낭독기는 그대로 읽습니다. 위 예제의 "알림 3건", "주문 검색", "건, 마지막 확인 이후"는 눈에 보이지 않고 낭독기만 읽습니다. display:none·hidden은 낭독기도 읽지 않으니, 읽혀야 할 이름·보충 설명에는 .Catui_clip을 씁니다.

본문 건너뛰기 (skip)

본문으로 이동

이 상자 안을 클릭한 뒤 Tab 키를 누르면 왼쪽 위에 링크가 나타납니다.

홈버튼표

여기가 본문입니다.

.Catui_skip은 평소 위로 밀려 보이지 않다가 키보드 포커스를 받으면 나타납니다. .Catui_app·.Catui_site 안 첫 요소로 두고, 대상 본문(main)에 id를 줍니다. 위치는 가장 가까운 position 조상 기준이므로 실제 화면에서는 페이지 왼쪽 위에 뜹니다.
