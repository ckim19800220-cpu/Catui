반응형 리셋

.Catui_app·.Catui_site·.Catui_layer 안의 img·video·canvas·picture는 display:block; max-width:100%; height:auto, iframe은 테두리 없이 최대 폭 100%입니다. 큰 그림을 넣어도 컨테이너 밖으로 넘치지 않습니다.

이미지 모양

비율 상자

그림 + 캡션

사용법

img에는 항상 width·height(레이아웃 흔들림 방지)와 alt를 줍니다. 잘라서 맞춰야 하면 .Catui_ratio(-1x1/4x3/16x9) 안에 넣고, 영상·지도는 임베드를 씁니다.

접근성

  • 의미 있는 그림은 내용을 설명하는 alt, 장식 그림은 alt="".
  • 그림 안 글자로 정보를 전하지 않습니다 — 캡션이나 본문에 같은 내용을 씁니다.
