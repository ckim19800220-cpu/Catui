사용법

도우미 클래스는 결합 순서 맨 끝(src/css/index.json)에 있어 컴포넌트 스타일을 덮어씁니다. 값은 모두 토큰이므로 새 색·크기를 만들지 않습니다. 같은 조합을 여러 곳에서 반복하면 도우미 대신 컴포넌트 클래스로 묶는 것이 관리하기 쉽습니다.
