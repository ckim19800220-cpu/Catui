사용법

.Catui_cmdk(폭 560) 안에 검색 줄 .Catui_cmdk-search, 그룹 details.Catui_cmdk-grp, 행 .Catui_cmdk-row(36px), 선택 행 .Catui_cmdk-row-on(하나만), 하단 힌트 .Catui_cmdk-hint. 키는 .Catui_kbd. 열기·필터·키보드 이동은 스크립트로 붙입니다(예: layer.open 안에 넣기).
