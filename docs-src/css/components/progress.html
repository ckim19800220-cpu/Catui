막대 조각이 왼쪽에서 오른쪽으로 계속 흐릅니다. 모션 줄이기 설정에서는 흐름을 멈추고 줄무늬가 있는 전체 막대로 바뀝니다. 진행률을 알게 되면 클래스를 지우고 aria-valuenow를 붙여 일반 막대로 바꿉니다.

사용법

.Catui_prog 트랙(6px) 안에 <i class="Catui_pc1~6">를 넣고 진행률만큼 너비를 지정합니다. 색은 pc1부터 순서대로 쓰고, 그라디언트나 새 색을 만들지 않습니다.

  • .Catui_ring-lg — 72px 큰 원형 진행. 가운데 글자가 본문 크기라 "3/5"처럼 짧은 분수도 들어갑니다.
  • .Catui_prog-indeterminate — 진행률을 모를 때. 트랙 안에 <i class="Catui_pc1"> 하나만 두고 width는 지정하지 않습니다(조각 폭 40% 자동).
  • .Catui_prog-striped — 막대 위에 정지된 비스듬한 줄무늬. 굵은 Catui_prog-lg와 함께 쓰고, 구간 막대에도 겹칠 수 있습니다.

접근성

  • 값이 바뀌는 진행은 role="progressbar" + aria-valuenow/min/max, 고정 표시는 role="img" + aria-label.
  • 퍼센트 글자를 막대 옆에 함께 보입니다.
  • 불확정 진행은 role="progressbar"와 이름(aria-label/aria-labelledby)만 주고 aria-valuenow는 빼서 "값을 알 수 없음"을 알립니다. 흐르는 움직임은 prefers-reduced-motion: reduce에서 멈춥니다.
  • 값이 숫자로 읽기 어려우면(단계 등) aria-valuetext로 "5단계 중 3단계 완료"처럼 문장을 줍니다.
