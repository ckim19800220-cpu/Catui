인라인 코드 · 키 표시

버튼은 .Catui_btn에 변형 클래스를 겹칩니다. 검색은 Ctrl + K.

코드 블록

catui.css
/* 버튼 높이 */
--Catui_btn-h-md: 34px;
--Catui_btn-radius: var(--Catui_radius-sm);
 
catui.use(['layer'], function (layer) {  layer.msg('안녕하세요');   // 토스트});

사용법

문장 속 코드는 code.Catui_code, 키는 kbd.Catui_kbd. 블록은 .Catui_codeblock > (선택 .Catui_codeblock-h) + pre > code. 구문 색은 Catui_tk-k(키·키워드)·tk-v(값·문자열)·tk-c(주석). 줄 번호는 code.Catui_lines 안에서 줄마다 <span>으로 감쌉니다 — 번호는 복사되지 않습니다. 복사 버튼은 data-catui-copy만 달면 catui.js page가 동작시킵니다.

접근성

  • 코드 블록 배경과 글자 대비는 AA를 넘습니다. 구문 색만으로 의미를 전하지 않습니다.
  • 긴 줄은 블록 안에서 가로 스크롤되며 페이지를 넘치지 않습니다.
