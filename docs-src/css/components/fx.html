상태 클래스 (정적 표시)

움직임은 catui.js fx가 붙이고, 아래 클래스는 그 상태를 그립니다. 여기서는 최종 상태를 고정해 모양만 보입니다.

fx-reveal + fx-in — 화면에 들어온 뒤 상태

한 글자씩

타자기
fx-tilt (기울어진 상태)
fx-spot (빛이 켜진 상태)
fx-bg: 내용 뒤에 캔버스 배경이 깔리는 틀

사용법

보통은 클래스를 직접 쓰지 않고 data-catui-fx="reveal"처럼 속성만 붙입니다. 직접 제어할 때 쓰는 변수: 나타나기 --Catui_fx-y·--Catui_fx-delay, 글자 간격 --Catui_fx-stagger, 기울기 --Catui_fx-rx/ry, 빛 위치 --Catui_fx-x/y/o, 자석 --Catui_fx-mx/my.

접근성

  • 모션 줄이기 설정에서는 모든 움직임이 꺼지고 최종 상태가 바로 보입니다. 불꽃은 아예 그리지 않습니다.
  • 나눈 글자·바뀌는 글자는 aria-hidden이고 원문은 aria-label·숨김 글자로 한 번에 읽힙니다. 효과는 꾸밈이며 정보를 움직임으로만 전하지 않습니다.
