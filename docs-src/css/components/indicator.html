알림 표시

3

온라인 상태

김
김하늘 접속 중 이준 자리 비움 박서연 방해 금지 최민 오프라인

사용법

대상을 .Catui_indicator로 감싸고 모서리에 .Catui_indicator-dot(점)·.Catui_count(숫자)·.Catui_status(상태)를 둡니다. 상태 색은 Catui_status-on(접속)·-away(자리 비움)·-busy(방해 금지)·기본(오프라인).

접근성

  • 점·숫자는 장식으로 숨기고, 같은 정보를 버튼 이름에 넣습니다 (예: "메일, 읽지 않은 메일 3개").
  • 상태는 색 점과 함께 "접속 중" 같은 글자를 씁니다.
