불러오는 중…

.Catui_layer-load는 layer.load()가 작은 모달(sm) 안에 넣는 스피너 + 문구 줄입니다. 위 예제는 모양만 보이려고 카드 안에 둔 것입니다.

사용법

숨긴 input.Catui_modal-toggle 바로 뒤에 여는 label, .Catui_scrim, .Catui_modal을 둡니다. 체크되면 스크림과 모달이 보입니다. 너비는 Catui_modal-sm/md/lg 세 단계만 씁니다.

접근성

  • CSS만으로는 Esc 닫기·포커스 가두기가 안 됩니다. catui.js를 불러오면 같은 마크업에 포커스 이동·Tab 가두기·Esc·포커스 복귀가 자동으로 붙고, layer.open은 네이티브 dialog로 이를 기본 제공합니다.
  • role="dialog" + aria-modal="true" + 제목 aria-labelledby, 닫기 버튼(24px)은 생략하지 않습니다.
  • 푸터 버튼은 오른쪽 정렬, 파괴적 행동은 danger.
