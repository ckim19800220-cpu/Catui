참고

토큰 값은 assets/spec/design_m.html이 원본입니다.

팁

예제의 코드 블록에서 바로 복사할 수 있습니다.

주의

dist 폴더는 빌드할 때 덮어써집니다. 원본은 src를 고치세요.

위험

외부 값을 catui.raw()로 감싸면 스크립트 주입이 생길 수 있습니다.

사용법

.Catui_callout = 아이콘 + .Catui_callout-title + 내용. 색은 기본(참고)·-tip·-warn·-danger. 화면 위쪽에 잠깐 알리는 상태 메시지는 배너, 사라지는 알림은 토스트를 씁니다.

접근성

  • 본문 속 보조 정보이므로 role="note". 종류는 색과 함께 제목 글자(참고·주의 등)로 알립니다.
