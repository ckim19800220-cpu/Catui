읽지 않은 알림이 없으면 머리의 카운트를 빼고 "모두 읽음" 버튼을 disabled로 둡니다. 항목에 .Catui_notif-unread가 없으므로 점·배경도 사라집니다.

사용법

.Catui_notifs = 머리 -h + 목록 -list(높이 320px 넘으면 스크롤) + 꼬리 -f. 항목 .Catui_notif, 읽지 않은 항목은 .Catui_notif-unread(왼쪽 점·연한 배경). 상단바 종 버튼의 드롭다운 안에 넣어 씁니다.

접근성

  • 읽지 않음은 점·배경과 함께 숨김 글자로 알립니다.
  • 종 버튼 이름에 개수를 넣습니다 (알림·상태 표시).
