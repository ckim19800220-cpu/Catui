간결 페이저

현재 12 / 12쪽

좁은 카드 꼬리나 모바일 목록에서는 번호 대신 "현재 / 전체" 글자와 이전·다음 버튼만 둡니다. 첫 쪽에서는 이전, 마지막 쪽에서는 다음을 disabled로 막습니다.

사용법

.Catui_pager 안에 .Catui_pg 버튼, 현재 쪽은 .Catui_pg-active + aria-current="page". 이전 화살표는 오른쪽 화살표에 .Catui_pg-prev(180° 회전)를 붙입니다. 번호 계산·이동은 catui.js laypage.

접근성

  • nav aria-label="페이지", 현재 쪽은 aria-current="page".
  • 이전·다음 아이콘 버튼에 aria-label, 끝에서는 disabled.
