그리기 판

서명을 그리려면 캔버스를 지원하는 브라우저가 필요합니다.

여기에 서명하세요

그리기를 받는 상자에 .Catui_canvas-draw를 붙이면 캔버스 위 커서가 십자로 바뀝니다. 펜·지우개처럼 고르는 도구는 aria-pressed로 상태를 알립니다. 첫 획이 그려지면 .Catui_canvas-empty 안내를 지웁니다.

사용법

.Catui_canvas(기본 16:9, -1x1/4x3/21x9) 안의 canvas는 상자를 꽉 채웁니다. 도구 막대 .Catui_canvas-tools(오른쪽 위), 범례 .Catui_canvas-legend(왼쪽 위), 빈 상태 .Catui_canvas-empty, 아래 캡션 .Catui_canvas-cap. 그리는 쪽에서 .Catui_canvas-draw를 붙이면 커서가 십자로 바뀝니다. 고해상도 보정·다시 그리기·토큰 색은 catui.js canvas가 처리합니다.

접근성

  • 캔버스는 그림이므로 role="img" + 내용을 요약한 aria-label을 주고, 숫자가 중요하면 표도 함께 제공합니다.
  • <canvas> 안의 글자는 캔버스를 못 그리는 환경에서 보이는 대체 문구입니다.
