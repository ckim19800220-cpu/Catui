떠 있는 메뉴 (dd-float)

편집

.Catui_dd-float는 dropdown.render()·datePicker가 body > .Catui_layer에 붙이는 화면 고정(position:fixed, z-index 60) 메뉴입니다. 위치는 스크립트가 버튼 아래(공간이 없으면 위)에 메뉴가 놓이도록 계산합니다. 예제는 모양만 보이려고 position:static으로 두었습니다.

사용법

details.Catui_dd > summary(버튼) + .Catui_dd-menu > .Catui_dd-item. 구분선 .Catui_dd-sep, 그룹 라벨 .Catui_dd-group, 너비 .Catui_dd-sm/lg. 메뉴는 흐름 안에 있으므로 겹쳐 띄우려면 감싼 요소에 위치를 주거나 catui.js dropdown을 씁니다.

접근성

  • summary 안에 버튼·링크를 넣지 않습니다.
  • catui.js가 있으면 바깥 클릭·Esc로 닫히고 summary로 포커스가 돌아갑니다. 키보드 메뉴(↑↓)가 필요하면 dropdown.render.
  • 위험 항목은 구분선 아래 맨 끝, 비활성 항목은 disabled와 이유를 글자로.
