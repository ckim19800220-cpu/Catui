사용법

ol.Catui_steps 안에 .Catui_step과 연결선 .Catui_step-line을 번갈아 둡니다. 상태는 Catui_step-done(체크)·Catui_step-current(번호)·기본(미도달). 단계 내용은 .Catui_step-panel.

접근성

  • 단계 목록은 ol, 현재 단계에 aria-current="step".
  • 완료 단계에만 체크 아이콘, 완료 여부는 숨김 글자로도 알립니다. 연결선은 aria-hidden.
