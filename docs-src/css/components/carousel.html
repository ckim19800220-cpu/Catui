사용법

.Catui_carousel-track(가로 스크롤 스냅) 안에 .Catui_carousel-slide를 둡니다. 터치·트랙패드로 넘기고, 점 .Catui_carousel-dot은 #슬라이드id 링크라 스크립트 없이 이동합니다. 현재 점 표시(aria-current)와 자동 넘김은 스크립트로 붙입니다. 다음 장을 살짝 보이려면 .Catui_carousel-peek.

접근성

  • 자동으로 넘기지 않는 것이 기본입니다. 자동 넘김을 쓰면 정지 버튼을 둡니다.
  • aria-roledescription으로 캐러셀·슬라이드임을, 슬라이드마다 "1 / 3" 위치를 알립니다. 모션 줄이기에서는 부드러운 스크롤을 끕니다.
