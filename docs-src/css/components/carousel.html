캐러셀

페이드 · 세로 · 미리보기 줄

.Catui_carousel-fade는 슬라이드를 한 칸에 겹쳐 두고 data-catui-active가 붙은 장만 보입니다(나머지는 visibility:hidden이라 낭독기도 읽지 않음). 예제는 첫 장에 속성을 직접 달아 정적으로 보였습니다. 장을 바꾸는 일은 스크립트(effect:'fade')가 하고, 모션 줄이기에서는 전환 효과가 꺼집니다.

.Catui_carousel-vertical은 트랙을 높이 320px의 세로 스크롤 스냅으로 바꿉니다. 휠·터치로 위아래로 넘기고, 점은 기본 예제처럼 #슬라이드id 링크입니다. 높이는 스크립트 옵션 height로 바꿉니다.

.Catui_carousel-thumbs는 가로로 넘치면 스크롤되는 작은 그림 줄, .Catui_carousel-thumb는 64×40 칸이며 현재 장에 aria-current="true"를 주면 테두리가 강조됩니다. 예제는 #슬라이드id 링크라 스크립트 없이도 이동하고, 현재 표시 갱신·페이드·세로·자동 넘김 같은 동작은 catui.js carousel이 맡습니다.

사용법

.Catui_carousel-track(가로 스크롤 스냅) 안에 .Catui_carousel-slide를 둡니다. 터치·트랙패드로 넘기고, 점 .Catui_carousel-dot은 #슬라이드id 링크라 스크립트 없이 이동합니다. 현재 점 표시(aria-current)와 자동 넘김은 스크립트로 붙입니다. 다음 장을 살짝 보이려면 .Catui_carousel-peek. 이전·다음·정지 버튼과 키보드는 catui.js carousel(data-catui-carousel)이 붙입니다.

접근성

  • 자동으로 넘기지 않는 것이 기본입니다. 자동 넘김을 쓰면 정지 버튼을 둡니다.
  • aria-roledescription으로 캐러셀·슬라이드임을, 슬라이드마다 "1 / 3" 위치를 알립니다. 모션 줄이기에서는 부드러운 스크롤을 끕니다.
