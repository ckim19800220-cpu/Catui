사용법

.Catui_fields 안에 .Catui_field(라벨·입력·도움말·오류)를 쌓습니다. 셀렉트는 .Catui_select-wrap으로 감싸고 화살표 아이콘을 둡니다(catui.js가 있으면 자동 보충). 검증을 스크립트로 붙이려면 catui.js form을 쓰세요.

접근성

  • 모든 입력에 label for↔id. 도움말·오류는 aria-describedby로 연결합니다.
  • 오류는 색과 함께 문장으로 알리고 aria-invalid="true"를 줍니다.
  • 포커스는 테두리 + 3px 링을 함께 표시합니다. 적절한 autocomplete를 붙입니다.
