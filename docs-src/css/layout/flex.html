사용법

.Catui_hstack(가로, 세로 가운데)·.Catui_vstack(세로)는 기본 간격 8px, Catui_gap-1/3/4/6으로 바꿉니다. .Catui_spacer는 남는 공간을 채워 뒤 요소를 끝으로 밀고, .Catui_between은 양 끝 정렬, .Catui_center는 가로·세로 가운데, .Catui_wrap-row는 줄바꿈입니다. 페이지 큰 틀은 그리드를 씁니다.
