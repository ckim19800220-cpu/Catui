관리 셸·표·차트를 조립해 바로 씁니다.

관리 셸 보기

.Catui_hero-center는 글·버튼을 가운데로, .Catui_hero-media는 .Catui_wrap에 붙여 글과 그림을 2열로 둡니다. 대표 제목은 문서당 하나입니다.

사용법

.Catui_site-header > .Catui_wrap + .Catui_brand + .Catui_site-nav. 모바일에서는 .Catui_site-menu(details)가 메뉴를 접습니다.

접근성

  • 대표 제목(h1)은 문서당 하나, 히어로 버튼은 primary 다음 secondary.
  • 모바일 메뉴는 details/summary이며 summary에 aria-label을 줍니다.
  • 섹션 이동 앵커는 sticky 헤더에 가리지 않도록 scroll-margin이 적용됩니다.
