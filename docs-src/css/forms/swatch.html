색상 고르기

색상 · 초록
테마 색

사용법

fieldset.Catui_swatches 안에 input.Catui_clip + label.Catui_swatch. 색은 style="--Catui_swatch:var(--Catui_color-…)"로 넘기고, 색 이름은 라벨 안 숨김 글자로 씁니다. 품절은 disabled(빗금 표시). 현재 선택 이름은 .Catui_swatch-value로 보입니다(갱신은 스크립트).

접근성

  • 색만 보이므로 색 이름을 숨김 글자로 반드시 넣습니다.
  • 선택은 바깥 링(2중 테두리)으로 표시해 밝은 색에서도 보입니다.
