인증 코드 –

문자로 받은 6자리 숫자를 입력하세요. 3분 안에 입력해야 합니다.

사용법

.Catui_otp 안에 한 글자 입력 칸 .Catui_input(maxlength="1", inputmode="numeric")을 나열하고, 필요하면 구분 .Catui_otp-sep. 입력하면 다음 칸으로 이동, 붙여넣기 분배, 오류 표시는 catui.js field.otp(data-catui-otp)가 붙입니다. 첫 칸에 autocomplete="one-time-code"를 주면 휴대폰이 문자 코드를 제안합니다.

접근성

  • 칸마다 "n번째 숫자" 이름을 주고, 묶음 이름은 legend, 안내는 aria-describedby.
  • 남은 시간 같은 제한은 글자로 미리 알립니다.
