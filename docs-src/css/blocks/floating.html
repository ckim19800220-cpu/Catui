.Catui_readbar는 화면 맨 위에 고정(position:fixed, 높이 3px)되는 막대이고, 안의 i가 --Catui_read(0~1) 비율만큼 가로로 찹니다. 예제는 미리보기 안에 보이도록 position:static과 옅은 바탕을 주고 값을 style로 고정했습니다. 실제로는 <div class="Catui_readbar" data-catui-readbar="#본문-id" aria-hidden="true"><i></i></div>를 body 가까이에 두면 catui.js site 읽기 막대가 스크롤에 맞춰 값을 바꿉니다(맨 위로 버튼 등 다른 화면 도구는 catui.js page). 장식이므로 aria-hidden="true"를 줍니다.

사용법

둘 다 실제로는 화면에 고정(position:fixed)됩니다. 예제는 미리보기 안에 보이도록 position:static으로 두었습니다. 맨 위로 버튼은 href="#본문-id" 링크로 만들면 스크립트 없이 동작하고, 스크롤 후에만 보이게 하려면 data-catui-totop="400"을 달면 catui.js page가 처리합니다. 쿠키 띠는 동의 후 스크립트로 닫습니다.

접근성

  • 맨 위로 버튼에 aria-label, 쿠키 띠는 role="region" + 이름.
  • 고정 요소가 본문 마지막 내용이나 다른 버튼을 가리지 않도록 아래 여백을 둡니다.
