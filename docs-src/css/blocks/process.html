이용 방법

  1. 설치

    스타일시트와 스크립트를 한 줄씩 연결합니다.

  2. 조립

    문서의 예제를 복사해 화면을 만듭니다.

  3. 배포

    빌드 검사를 통과하면 그대로 배포합니다.

세로 단계

  1. 계정 만들기

    이메일로 1분 안에 가입합니다.

  2. 팀 초대

    동료에게 초대 메일을 보냅니다.

  3. 첫 화면 만들기

    템플릿에서 시작합니다.

단계 설명이 길거나 좁은 영역에서는 .Catui_process-v로 세로로 쌓습니다.

사용법

ol.Catui_process 안의 li마다 번호가 자동으로 붙고, 항목 사이에 점선이 이어집니다. 진행 상태를 보여 주어야 하면 마법사를 씁니다.

접근성

  • ol이라 순서가 읽힙니다. 번호는 CSS가 그리므로 글자로 다시 쓰지 않습니다.
