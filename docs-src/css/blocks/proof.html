.Catui_logos-track은 내용 폭(max-content)만큼 늘어난 줄을 30초에 한 번 왼쪽으로 절반(-50%)만큼 옮기고 처음으로 돌아갑니다. 그래서 로고를 똑같이 두 벌 넣어야 이음매 없이 이어지고, 복제한 벌에는 aria-hidden="true"를 줘 낭독기가 두 번 읽지 않게 합니다. 바깥 .Catui_logos-marquee는 넘친 부분을 자르고 양 끝을 흐리게 가립니다. 마우스를 올리거나 안에 포커스가 들어오면 멈추고, 운영체제의 모션 줄이기(prefers-reduced-motion:reduce)가 켜져 있으면 애니메이션을 아예 끕니다(이때 복제 벌도 그대로 보이므로 실제 화면에서는 스크립트 방식을 권합니다). 5초 넘게 움직이는 내용에는 정지 버튼이 있어야 하므로(WCAG 2.2.2), 실제 화면에서는 .Catui_logos에 data-catui-marquee="30"만 달아 catui.js site 로고 흐름이 트랙·복제·정지 버튼을 만들게 하세요(모션 줄이기면 흐르지 않는 원래 배치 그대로).
