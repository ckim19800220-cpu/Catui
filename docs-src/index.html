빠른 시작

불러오고, 쓰고, 움직이고, 넓힌다.

  1. 불러오기CSS 한 줄, 스크립트 한 줄.
    <link rel="stylesheet" href="dist/catui.min.css">
<script src="dist/catui.js"></script>
  2. 마크업클래스만 붙이면 모양이 갖춰집니다.
    <button class="Catui_btn Catui_btn-md
  Catui_btn-primary" id="hello">저장</button>
  3. 동작모듈을 받아 이벤트를 연결합니다.
    catui.use(['layer'], (layer) =>
  hello.onclick = () => layer.msg('저장했습니다'));
  4. 확장관리자·커뮤니티 템플릿을 그대로 복사해 씁니다.
    <link rel="stylesheet" href="dist/admin.css">
<script src="dist/catadmin.js"></script>
