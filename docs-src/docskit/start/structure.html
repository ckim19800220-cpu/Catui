목차 · 현재 위치

  1. 본문 안 h2·h3(rules.tocLevels)를 순서대로 모읍니다. [data-catui-dk-notoc] 안의 제목(피드백 상자 등)은 뺍니다.
  2. id가 없으면 제목 글자로 만듭니다 — 한글은 그대로, 공백·기호는 -, 쪽 안에서 겹치면 -2·-3.
  3. 가장 큰 제목 단계 아래에 다음 단계를 한 겹(ol ol) 넣고, 목차 nav의 이름은 “이 쪽에서”.
  4. 스크롤할 때 화면 위 30% 선을 지난 마지막 제목의 링크가 aria-current="location". 쪽 끝까지 내리면 마지막 제목.

본체 site의 [data-catui-spy]는 <section> 단위로 판단하므로, 섹션 없이 h3까지 따라가야 하는 문서 본문은 제목 위치로 따로 계산합니다.

검색 일치 · 점수

일치 규칙은 본체 명령 팔레트(catui.command)와 같습니다 — 띄어쓰기·대소문자를 무시하고, 검색어의 자음은 그 자리 글자의 초성과 맞춥니다(ㅁㅊ · 목ㅊ · ㅁ차 → 목차).

마크다운 일부 (안전)

  1. 먼저 & < > "를 모두 이스케이프합니다 — 이 단계 뒤에는 어떤 태그도 들어올 수 없습니다.
  2. `코드` 구간을 떼어 두고, 나머지에서만 **굵게**와 [글자](https://…)를 바꿉니다.
  3. 링크는 https만(javascript:·http:·상대 주소는 글자 그대로), rel="noopener nofollow" · 새 창 + 숨김 글자 “(새 창)”.
  4. 여러 줄(docs.md)은 빈 줄로 문단, 모든 줄이 - 로 시작하면 목록.

블로그 태그 필터 ↔ 주소

  • 주소 blog.html?tag=a11y&page=2 ↔ 화면(태그 버튼 aria-pressed · 쪽 번호 aria-current="page"). 첫 쪽·전체 태그는 주소에서 뺍니다.
  • 태그를 바꾸면 1쪽으로. 쪽 수 = 올림(글 수 ÷ rules.perPage(6)), 범위를 벗어난 쪽은 끝 쪽으로 맞춥니다. 없는 태그는 전체로.
  • 바꿀 때마다 history.pushState — 뒤로 가기(popstate)로 이전 거르기로 돌아갑니다. 다시 그린 뒤 포커스는 누른 버튼 자리로.
