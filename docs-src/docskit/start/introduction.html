접근성 · 반응형 기준

  • 현재 위치(메뉴·목차·태그 버튼)는 aria-current/aria-pressed + 막대·굵기·체크 아이콘으로 — 색만으로 알리지 않습니다. 변경 이력 종류는 배지 글자(추가·변경·고침)로.
  • 제목 앵커·쪽 이동 버튼의 뜻은 숨김 글자(.Catui_clip)나 aria-label(버튼·링크)로, 역할 없는 span에는 aria-label을 쓰지 않습니다(빌드가 검사).
  • 한글 조합 중 Enter는 검색을 제출하지 않고(catui.imeBusy), 입력하는 대로 찾는 검색은 조합이 끝난 뒤에 돕니다.
  • 320px 화면에서 쪽 가로 넘침 없음. 가로로 넘치는 상자(머리 메뉴·코드·표·태그 줄)는 position:relative 스크롤 상자이고 코드 블록은 Tab으로 들어가 밀 수 있습니다.
  • 모션은 앵커 나타남·카드 아이콘 확대·누름 피드백뿐이며 prefers-reduced-motion이면 끕니다.
