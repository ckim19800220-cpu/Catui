catui.docs

catdocs.js가 catui.extend({ docs })로 등록하고, 문서가 준비되면 [data-catui-dk] 루트를 찾아 연결합니다. 루트가 없는 화면(이 문서처럼)에서는 데이터를 읽지 않으므로, 목차·코드 복사·검색·읽는 시간 같은 함수는 직접 넘긴 요소와 자료로 씁니다. 전체 타입은 dist/catdocs.d.ts.

선언형 속성

data-catui-dk 속성
속성동작
[data-catui-dk]화면 루트(이 안의 속성을 연결)
<article data-catui-dk-toc="#상자"> · [data-catui-dk-notoc]목차·제목 앵커·코드 복사 · 목차에서 뺄 영역
[data-catui-dk-nav] · [data-catui-dk-pager] · [data-catui-dk-page="id"]왼쪽 문서 메뉴(nav.json) · 이전/다음 · 문서 본문(pages.json, ?p= 우선)
[data-catui-dk-readtime="#본문"]“3분 읽기”
[data-catui-dk-feedback="키"] 안 [data-vote="yes|no"] · [data-msg]도움 되었나요 — aria-pressed, 같은 답을 다시 누르면 취소, 키마다 기억
select[data-catui-dk-version] · [data-catui-dk-old]버전 이동(option value = 주소) · 옛 버전 안내
form[data-catui-dk-search] · ="live" · [data-catui-dk-results] · [data-catui-dk-count]머리 검색(빈 값·조합 중 Enter 막음) · 입력하는 대로 결과 + 주소 ?q= · 결과 · 결과 수
script[type="application/json"][data-catui-dk-index]인라인 검색 색인 (있으면 search-index.json보다 먼저)
[data-catui-dk-blog] · [data-catui-dk-post] · [data-catui-dk-tagpage] · [data-catui-dk-author] · [data-catui-dk-posts="recent"] · [data-catui-dk-changelog]블로그 목록(?tag=&page=) · 글(?id=) · 태그(?t=) · 저자(?a=) · 최근 글 · 변경 이력
[data-catui-dk-theme] · [data-catui-dk-nocopy]테마 전환 · 복사 버튼을 붙이지 않을 pre(시그니처 등)

자주 쓰는 사용 예

문서 키트 토큰이 .Catui_dk에 정의되므로 예제는 class="Catui_dk" 상자로 감쌌습니다 — data-catui-dk 속성은 넣지 않아 셸 동작(데이터 읽기)은 켜지지 않습니다(문서용으로 min-height만 풀었습니다).

설치

npm이나 CDN 태그로 불러옵니다.

CDN

dist 폴더의 파일을 그대로 씁니다.

목차 붙이기

본문과 상자를 넘기면 끝입니다. 제목에 마우스를 올리면 주소 복사 버튼이 보입니다.

현재 위치

스크롤하면 지나간 마지막 제목의 링크가 강조됩니다.

한글 제목이 그대로 id(설치·cdn·목차-붙이기)가 됩니다. 쪽 안에 같은 id가 이미 있으면 -2가 붙습니다. 좁은 화면에서는 목차가 위로 올라갑니다.

catui.docs.on('copy', ({ kind, ok }) => console.log(kind, ok));

    ‘ㅁㅊ’은 제목 초성(목차)으로 3점, ‘클립보드’는 키워드로 2점입니다. 화면 안 <script type="application/json" data-catui-dk-index>가 있으면 JSON 파일을 받지 않습니다.

    javascript: 링크와 <img> 태그는 글자 그대로 보입니다 — 이스케이프가 먼저이고 https 링크만 바꾸기 때문입니다.

      이벤트 · 실서비스 연결

      catui.docs.on('feedback', ({ key, value }) => fetch('/api/feedback', { method: 'POST', body: JSON.stringify({ key, value }) }));
catui.docs.on('search', ({ q, count }) => { if (!count) analytics.track('search-miss', q); });   // 못 찾은 검색어 모으기
catui.docs.rules.readKo = 600;            // 읽는 시간 기준 바꾸기
catui.docs.dataBase = '/api/docs/';       // 같은 모양의 JSON API
catui.docs.version.go = (href) => router.push(href);   // SPA 라우터로 버전 이동
