규칙

  • 클래스는 Catui_adm-*, 토큰은 --Catui_adm-*(본체 토큰을 참조만). 새 색 값은 만들지 않습니다.
  • 본체 클래스를 단독 선택자로 재정의하지 않습니다 — 본체 클래스에 스타일을 더할 때는 항상 .Catui_adm … 아래로 한정합니다. 그래서 admin.css를 불러와도 관리 화면 밖은 바뀌지 않습니다.
  • 반응형 기준은 본체와 같습니다: 1199 · 991 · 767 · 479px.

자주 쓰는 사용 예

아래는 스크립트 없이 클래스만 쓴 정적 견본입니다. 토큰이 .Catui_adm에 정의되므로 셸 밖에서 보여 줄 때는 class="Catui_adm" 상자로 감쌉니다(문서용으로 min-height만 풀었습니다). 실제 화면에서는 셸 루트가 이미 .Catui_adm이므로 감쌀 필요가 없습니다.
