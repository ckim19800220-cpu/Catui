catui.admin

catadmin.js가 catui.extend({ admin })로 등록합니다. 셸이 있으면 자동으로 연결되고, 없어도(로그인 화면 등) 테마·위젯·폼 보조는 동작합니다.

catui.admin API
API설명
admin.init(scope?) · admin.destroy()연결 · 모든 리스너·차트·팝업 정리 (SPA 화면 전환 시)
admin.on(이벤트, fn)theme { value, saved } · data { name, data, box } · collapse { collapsed } · drawer { open } · notify { unread } · dirty { form, dirty } · chat { text } · kanban { card, from, to }

admin.theme.set('light'|'dark'|'system') · get() · saved()테마 (저장값이 없으면 시스템 설정을 따름) · 버튼 [data-catui-adm-theme]. 다른 쪽이 테마를 관리하는 화면(예: 문서 사이트)은 <html data-catui-theme-lock>로 덮어쓰기를 막습니다

admin.form.saved(form) · isDirty(form)form[data-catui-adm-form] 변경 감지 · 떠날 때 확인 · 저장 바 [data-catui-adm-savebar]
