templates/admin/

복사해서 쓰는 전체 화면 HTML {{stat:adminTpl}}종 — 같은 셸·메뉴를 공유하고, 빌드가 링크·클래스·접근성을 검사

화면 구성은 Gentelella v4 대시보드를 참고했고, 코드·문구·이미지는 Catui 토큰·컴포넌트로 새로 작성했습니다 (MIT).
