규칙

  • 클래스는 Catui_cm-*, 토큰은 --Catui_cm-*(본체 토큰을 참조만). 새 색 값은 만들지 않습니다.
  • 본체 클래스에 스타일을 더할 때는 항상 .Catui_cm … 아래로 — community.css를 불러와도 커뮤니티 밖은 바뀌지 않습니다.
  • 강조(인기·추천·새 글)는 색 + 글자·숫자·아이콘을 함께 — 색만으로 알리지 않습니다.
  • 반응형: 991px 이하 옆줄을 본문 아래로, 767px 이하 게시판 메뉴 가로 스크롤 + 하단 탭.
